## 1. 戦略コンサルタント向け案件ブリーフ

```text
対象組織は「東雲県産業DX推進機構」です。県内企業の業務改善支援と、誘致企業との共創プロジェクト創出を担当しています。

# 現状課題
- 生成AI活用支援プログラムの受講は進んだが、現場利用が定着しない
- 県外から誘致したSaaS企業と地場企業のPoCが単発で終わる
- 相談案件が増え、担当者6名では個別伴走が追いつかない

# 既知データ
- 会員企業146社のうち製造業54社、小売32社、物流18社、その他42社
- 2026年度予算: 1.8億円
- 支援メニュー別満足度: 研修4.3/5、個別伴走3.5/5、導入後フォロー2.8/5
- 県外テック企業18社のうち、県内企業と継続案件化したのは4社

# 経営陣の要望
- 2027年度までに、実利用率50%、継続案件12件、県内雇用創出40名を目指したい
- ただし新規採用は最大2名、外部委託費は年間3,000万円以内

# 曖昧な点
- 実利用率の定義が「月1回以上」か「業務成果物作成あり」か未統一
- 会員企業ごとのIT成熟度指標が未整備

# 期待する出力
- 現状分析の要約
- SWOT / PEST / 5フォースのうち必要なもの

- KPI とリスク
- 実行体制案
```
