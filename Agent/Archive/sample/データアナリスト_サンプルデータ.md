# データアナリスト — サンプルデータ

> 注意: このファイルに記載する会社名、製品名、顧客属性、件数、日付、数値はすべて架空です。個人を識別できる情報は含みません。

## 共通シナリオ

- 会社名: 空色モバイル株式会社
- 製品: `SoraPhone X2` `SoraPhone Mini` `SoraTab Air`
- 目的: コールセンター問い合わせ傾向を分析し、FAQ改訂と品質改善テーマを決めたい
- 事情:
  - 2026年7月にOS更新を実施
  - 2026年8月中旬から修理受付遅延が発生
  - 高齢者向けサポート窓口を新設したが評価が割れている

## 1. データアナリスト向け案件ブリーフ

```text
あなたに分析してほしいテーマは「スマートフォン製造メーカーのコールセンター問い合わせ傾向の把握」です。

# 想定データ
- 期間: 2026-07-01 〜 2026-09-15
- 件数: 100件程度から開始し、必要なら追加生成
- 列候補:
  - inquiry_id
  - date
  - product_name
  - customer_segment
  - issue_category
  - contact_channel
  - wait_minutes
  - resolution_days
  - cs_score
  - free_comment

# 分析で知りたいこと
- OS更新後に問い合わせが増えたカテゴリは何か
- 待ち時間と満足度の関係
- 製品別・顧客層別の違い
- 自由記述コメントから追加で分類できる不満の型

# 出力に求めること
- ITに詳しくない役員にも分かる説明
- 主要グラフの提案
- データ不足やバイアスの指摘
- 次に集めるべき列の提案
```

## 2. Starter Prompt 例1として使う入力

```text
スマートフォン製造メーカーの、コールセンターへ寄せられたお客様の声のサンプルデータを100件、日本語で作成してください。

# 条件
- 期間は2026年7月1日から2026年9月15日
- 製品は SoraPhone X2、SoraPhone Mini、SoraTab Air の3種類
- 問い合わせカテゴリは、バッテリー、OS更新、画面破損、配送遅延、初期設定、修理対応、請求/保証 から選ぶ
- 自由記述コメントは日本語
- 高齢者向け窓口の利用者を全体の25%程度含める
- 待ち時間が長いほど満足度が下がる傾向は入れるが、例外も少し混ぜる
```

## 3. Starter Prompt 例2として使う入力

```text
これまでのデータから分析に最適なグラフを作成してください。

# 特に見たい観点
- 日付ごとの問い合わせ件数の推移
- issue_category 別の構成比
- wait_minutes と cs_score の関係
- customer_segment 別の平均 resolution_days
- free_comment の分類結果の割合

# 補足
- 外れ値があれば理由の仮説も添えてください
- グラフだけでなく、経営向けに3つの示唆を付けてください
```
