# 国内外事例収集エージェント — サンプルデータ

> 注意: このファイルに記載する会社名、製品名、国名ごとの検討テーマ、日付、KPI、体制条件はすべて架空です。参照先として求める情報源種別は実在し得ますが、ここで示す固有名詞は研修用です。

## 共通シナリオ

- 依頼元: 東雲メディカルデバイス株式会社
- 目的: 生成AI導入と内製開発体制見直しの投資判断材料を集めたい
- レポート提出先: 経営会議、品質保証本部、DX推進室
- 制約:
  - 医療・製造の規制産業に近い信頼性が必要
  - 宣伝資料だけでなく、効果指標や失敗要因も見たい
  - できれば2023年以降の情報を優先

## 1. 事例収集エージェントに渡す調査ブリーフ

```text
以下の条件で、国内外の公開事例を収集してください。

# 対象テーマ
生成AIを活用した製造業・規制産業における業務改善

# レポート目的
- 経営会議向けに、導入余地と再現性の高いパターンを把握したい
- 品質保証本部向けに、誤回答や規制上のリスクをどう抑えているか知りたい
- DX推進室向けに、PoC止まりを避ける運営条件を整理したい

# 収集条件
- 国内5件、海外5件
- 事例名、国/地域、概要、成功要因、成果・効果、情報源を必須
- 数値KPIがある事例を優先
- うまくいかなかった要素や注意点が読み取れる場合は補足する

# 期待する出力形式
- 国内事例と海外事例を分ける
- 各事例は見出し+箇条書き
- 最後に横断的な示唆を5点まとめる
```

## 2. Starter Prompt 例1として使う入力

```text
Azure OpenAI Serviceを工場の現場で活用している事例を調べてください。対象は、設備保全、品質記録の要約、作業標準書検索、引継ぎメモ作成などの現場業務です。できれば、投資対効果、現場定着の工夫、権限制御、オフラインや騒音環境などの制約にも触れてください。
```

## 3. Starter Prompt 例2として使う入力

```text
Microsoft 365 Copilotを管理職の人が意思決定で使用している事例を調べてください。特に、会議要約、リスク整理、複数部門の調整、未読メールや資料の圧縮、意思決定スピードの改善などに使っている事例を優先してください。日本企業か、少なくとも日本企業が参考にしやすい組織文化の事例だとうれしいです。
```

## 4. Starter Prompt 例3として使う入力

```text
内製化がうまくいっていない事例もよく聞きます。IT専業会社ではない製造業で、ソフトウェアエンジニアが活躍している体制や企業風土作りなどの事例を調査してください。報酬制度、評価制度、現場部門との関係、プロダクトオーナーの置き方、子会社化の有無、採用ブランドづくりまで分かると助かります。
```
