# サービス・システムの比較評価エージェント — サンプルデータ

> 注意: このファイルに記載する会社名、組織案、金額、工数、評価条件、導入候補サービスはすべて架空です。実在の個人・企業・価格とは関係ありません。

## 共通シナリオ

- 会社名: 白嶺物流株式会社
- 事業: 医療機器・精密部品の保管配送
- 従業員数: 860名
- DX課題:
  - 配車調整、問い合わせ対応、事故報告書作成が属人化
  - 現場は忙しく、IT部門は12名しかいない
  - 2027年度までに間接業務時間を20%削減したい

## 1. 比較評価エージェントに渡す案件ブリーフ

```text
以下の案件について、サービス・システムの比較評価をしてください。

# 評価テーマ
生成AI活用と内製開発体制の組み合わせによって、白嶺物流株式会社の間接業務をどこまで効率化できるか

# 評価したい候補
- 候補A: Microsoft 365 Copilot を全社展開
- 候補B: Azure OpenAI を使って問い合わせ要約・報告書ドラフトの個別アプリを作る
- 候補C: 部門限定でChat型AIを導入し、PoC後に拡大判断
- 候補D: 当面は導入せず、既存RPAとテンプレート整備を優先

# 比較に入れたい観点
- 心理的負担
- 投資時間
- 金額
- 変更度合い
- 生成AIの活用効果
- 可能ならセキュリティ統制、現場定着性、運用負荷も追加

# 前提
- M365は既に導入済み
- 現場端末は共用PCが多い
- 個人情報と配送先情報を扱う
- 全社予算上限は初年度4,000万円
```
