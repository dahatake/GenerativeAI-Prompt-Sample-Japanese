# Task Contract（承認済み）: monthly_work_hours(path)

承認根拠: answers.md の回答（Q1〜Q4）。回答に具体値が揃っているため追加質問なし。

## 確認できた事実（shifts.csv）
- 列: `employee,date,type,start,end`。UTF-8、6データ行、改行は `\n` と最終行のみ `\r\n` の混在。
- `type` は `work` / `paid_leave`。`paid_leave` 行は start/end が空。
- 日跨ぎ行あり（E002 22:00-06:00）。分の端数あり（09:00-14:50、08:30-17:45）。
- データは 2026-10 のみ。休憩の列はない。

## 回答で確定した仕様
- Q1 休憩: 1シフトの拘束時間が 6時間(360分)を**超える**場合、一律 60分を控除。ちょうど 6時間は控除しない。
- Q2 月: 引数は `path` のみ。CSV 内の全行を合計（月での絞り込みなし）。
  丸め: 各シフトの実労働時間（拘束 − 休憩）を 15分単位で切り捨て。
- Q3 `paid_leave` 行: 7.5時間として計上（丸め対象外、休憩控除なし）。
  不正行: `ValueError`（行番号付き）を送出（推奨案A）。
- Q4 `end < start` は翌日終了の日跨ぎ勤務として扱う。その他の仮定はそのまま。

## Outcome
`solution.py` に `monthly_work_hours(path) -> dict[str, float]` を実装し、従業員ごとの労働時間（時間, float）を返す。

## Scope / Out of scope
- Scope: CSV 読込、work 行の拘束時間・休憩控除・15分切り捨て、paid_leave の 7.5h 計上、従業員別合計、検証テスト。
- Out of scope: 残業・深夜区分、給与計算、タイムゾーン、月別出力、CSV 以外の形式、月跨ぎ分割。

## Data sources
- `shifts.csv`（引数 `path` のファイルのみ）。

## Constraints
- 標準ライブラリのみ。分単位の整数計算で、最後に 60 で割る。
- 作業ディレクトリ内のみ。

## Definition of Done（検証できる条件）
shifts.csv で期待値:
- E001: 9:00-18:00 → 540−60=480分=8.0h、09:00-14:50 → 350分（6h以下で控除なし）→切捨て345分=5.75h、paid_leave 7.5h → **21.25**
- E002: 22:00-06:00 → 480−60=420分=7.0h、13:00-19:00 → 360分（ちょうど6h、控除なし）=6.0h → **13.0**
- E003: 08:30-17:45 → 555−60=495分=8.25h → **8.25**

条件:
1. `monthly_work_hours("shifts.csv") == {"E001": 21.25, "E002": 13.0, "E003": 8.25}`
2. キーは str、値は float。
3. 日跨ぎ行 22:00-06:00 が 7.0h（休憩控除後）になる。
4. 拘束ちょうど 6h は休憩控除なし、6h超（例 6h01m）は 60分控除。
5. 実労働の 15分未満切り捨て（例 09:00-14:50 → 5.75h）。
6. paid_leave は 7.5h として加算される（有給のみの従業員も 7.5h の倍数で dict に入る）。
7. 最終行が `\r\n` / 末尾改行なし のどちらでも同じ結果。
8. 不正行（work で時刻欠落・形式不正、未知の type）は `ValueError`。

## Evidence
- 検証テストのコマンドと出力（report.md に記載）、timing.txt。

## Open questions / 採用する仮定（この仮定で進めます）
- 列名で参照（並び順不問）。`end == start` は 0 時間。同日複数 work 行は単純合算。
- 従業員IDは前後空白除去、空行は無視、dict は初出順。ファイルなしは `FileNotFoundError`。
- 休憩控除は日跨ぎ後の拘束時間で判定。月への帰属は日付に関係なく全行合計。
- paid_leave 行に start/end が入っていても無視。date は形式検証（YYYY-MM-DD）のみ行う。
