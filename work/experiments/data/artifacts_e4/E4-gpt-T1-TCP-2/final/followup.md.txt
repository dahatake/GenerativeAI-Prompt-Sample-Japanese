# 追加確認 — Q2: 集計対象の `status`

`cancelled` を除外する点は確定しています。`sales.csv` のステータスは `completed` と `cancelled` のみなので、`pending` などが別の CSV に現れた場合の扱いはサンプルから判定できません。

**`completed` と `cancelled` 以外のステータスは集計に含めますか？**

- **A（推奨・契約案の既定値）:** `status == "completed"` の行だけを集計する。`pending`、`refunded`、空欄を含め、それ以外は除外する。
- **B:** `status == "cancelled"` の行だけを除外する。`pending`、`refunded`、空欄を含め、それ以外は集計する。

A・B のどちらでもなければ、集計に含める、または除外する `status` の文字列を具体的に列挙し、列挙外の値と空欄を集計するか指定してください。いずれの案も大文字・小文字を区別して完全一致で判定します。
