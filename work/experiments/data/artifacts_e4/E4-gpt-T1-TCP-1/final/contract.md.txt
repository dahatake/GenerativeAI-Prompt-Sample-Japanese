# Task Contract：売上の月次集計（承認済み）

## Outcome
`solution.py` の `monthly_sales(path)` は、指定されたCSVの集計対象行をJSTの暦月ごとに合計し、`{"YYYY-MM": 金額(int)}` の `dict` を返す。`answers.md` の Q1=A、Q2=A、Q3=B に基づき、実装・検証する。

## Scope・Out of scope
- UTCで記録された `ordered_at` をJST（固定 UTC+09:00）に変換してから暦月を判定する。`completed` の `amount_incl_tax` のみを加算し、`cancelled` は加算しない。
- 対象行の最初の月から最後の月まで両端を含めて返し、その範囲の対象行がない月を `0` で補完する。範囲外は補完しない。対象行がなければ `{}`。
- 対象外：税額の再計算、通貨換算、注文IDによる重複排除、CLIやファイルへの集計結果の出力。

## Data sources
### 確認できた事実
- `sales.csv` はカンマ区切りで、ヘッダーは `order_id,ordered_at,amount_incl_tax,status`。データは10行で、全バイトがASCIIの範囲にある。
- `ordered_at` は全行 `Z` 付き（UTC）。`amount_incl_tax` は全行で整数表記。`completed` が8行、`cancelled` が2行で、`completed` の `A-1006` に `-1100` がある。通貨名は記載されていない。
- `A-1004` は UTC の1月末から JST の2月初めに、`A-1010` は UTC の4月末から JST の5月初めに移る。JSTの3月の行がない。
- `answers.md` は集計仕様の選択と、その他の仮定に推奨案を使う指示の出典。

## Constraints
- 作業ファイルの読み書きは指定作業ディレクトリ内に限る。Python標準ライブラリのみを使う。
- 集計値は入力と同じ単位で、丸め・税計算・通貨換算なしの Python `int`。出力キーの並び順は契約に含めない。

## Definition of Done
1. **D1 — API と型**：`from solution import monthly_sales` で読み込め、渡されたパスのCSVを読み取る。戻り値は `dict`、キーは4桁年・2桁月の `YYYY-MM`、値は `int`。
2. **D2 — 実データ**：`monthly_sales("sales.csv")` は厳密に `{"2026-01": 16500, "2026-02": 11000, "2026-03": 0, "2026-04": 18700, "2026-05": 7700}` を返す。
3. **D3 — 集計規則**：JSTの月境界2件、取消2件、負額1件、3月欠落が上記ルールどおり。年をまたぐ空白月も補完し、取消行は補完の範囲を広げない。対象行がある月に金額 `100` と `-100` だけがあれば、その月は `0` で残る。
4. **D4 — 空・不正入力**：ヘッダーのみ、またはフィルター適用後に対象が0行なら `{}`。必須列の欠落、不正な日付や金額、未定義のステータスは、取消行も含めて `ValueError`。ファイルを開けない場合はI/O例外をそのまま送出する。

## Evidence
- 仕様検討時に、`sales.csv` の列名・件数と、JST・`completed` のみで月別に `16500`、`11000`、`18700`、`7700` になることをPython標準ライブラリで確認した。承認された補完規則により `2026-03: 0` を加える。
- 実装検証は `python -B -m unittest -v test_solution` で行い、テスト出力と各条件の判定を `report.md` に記録する。

## Open questions
未解決の質問なし。`answers.md` により月の境界（Q1=A）、対象ステータス（Q2=A）、補完方法（Q3=B）は確定済み。

### 採用した仮定
- 各対象行の金額を符号付き整数としてそのまま足し、負額は差し引く。`order_id` で行を統合しない。対象行がある月の合計がゼロになってもキーは残す。
- 入力はUTF-8のカンマ区切りヘッダー付きCSV（UTF-8 BOMは許容）。`ordered_at`、`amount_incl_tax`、`status` は列名で特定し、その他の列は使わない。日時は `YYYY-MM-DDTHH:MM:SSZ` の実在するUTC日時、金額は `-?[0-9]+`、ステータスは大文字・小文字を区別して `completed` または `cancelled`。
- 必須列名は各1回必要で、欠落や曖昧な重複、必須値の不正、構文不正のCSVを黙って無視せず `ValueError` とする。取消行でも必須値は検証する。対象行の日時をJSTに変換して4桁の年で表せない場合も `ValueError` とする。有効なヘッダーだけなら `{}` とし、ファイルが開けない場合は通常のI/O例外をそのまま送出する。
