# Task Contract 案（Spec Mode）— monthly_sales(path)

## 1. 確認できた事実（sales.csv を実際に確認）
- 作業ディレクトリには `sales.csv`（10行＋ヘッダ）のみ。`solution.py` は未作成。
- 列: `order_id, ordered_at, amount_incl_tax, status`
- `ordered_at` は UTC（末尾 `Z`）の ISO 8601。
- 列名が `amount_incl_tax` ＝ **税込**金額。全金額が 1.1 で割り切れる（10% 税率と整合）。
- `status` は `completed` / `cancelled`（cancelled: A-1003=22000, A-1007=4400）。
- 負の金額あり（A-1006: -1100, completed。返品/値引の可能性）。
- 3月のデータは存在しない（1, 2, 4月のみ）。
- **境界ケース**: A-1004 `2026-01-31T16:20:00Z` は JST では 2026-02-01 01:20。A-1010 `2026-04-30T15:30:00Z` は JST では 2026-05-01 00:30。タイムゾーンで月が変わる。A-1008 `2026-04-02T00:30Z`などは変わらない。

## 2. 仮定
- A. 金額は円の整数で、`int` に変換できる（小数・カンマ・空欄なし）。
- B. 負の金額（completed）は返品として**そのまま合算**（除外しない）。
- C. データのない月（3月）はキーを出力しない。
- D. 戻り値は月キーの昇順（挿入順）の dict。
- E. 標準ライブラリのみ（csv, datetime）で実装。ファイルは UTF-8。
- F. 重複 order_id・不正行は今回のデータに無いため特別扱いしない（要件外）。

## 3. 不足情報 / 質問（結果が変わり手戻りが大きいもの・最大3問）

**Q1. 月の判定に使うタイムゾーンは？**（結果: 1月・2月・4月・5月の値が変わる）
- (a) UTC のまま（`ordered_at` の先頭7文字）
- (b) JST（Asia/Tokyo, UTC+9）に変換してから月を判定 ← **推奨**（日本の売上集計で、データ言語・依頼が日本語のため）
- (c) その他（指定してください）

**Q2. `cancelled` の注文は集計に含めるか？**
- (a) 除外（`completed` のみ集計）← **推奨**（キャンセルは売上でないため）
- (b) 含める（全行）

**Q3. 金額は税込のまま集計するか、税抜に換算するか？**
- (a) 税込のまま（`amount_incl_tax` の合計）← **推奨**（依頼文に「税抜」の指定がなく、列をそのまま使うのが最小驚き）
- (b) 税抜（÷1.1、10%固定。端数処理の指定も必要）

## 4. Task Contract（確定・承認済み: Q1=b JST / Q2=a completed のみ / Q3=a 税込）

### Outcome
`solution.py` に `monthly_sales(path) -> dict[str, int]` があり、`sales.csv` を月次集計した `{"YYYY-MM": 金額(int)}` を返す。

### Scope / Out of scope
- Scope: CSV 読込、月判定（JST）、status フィルタ（completed のみ）、税込金額の合計、`solution.py` の作成（検証用に `test_solution.py` と `report.md` も作成）。
- Out of scope: CLI/出力ファイル、pandas 等の外部依存、為替・通貨、重複排除、不正行の修復、`sales.csv` の変更。

### Data sources
- `sales.csv`（作業ディレクトリ直下）。引数 `path` で渡されたファイルのみ。

### Constraints
- 標準ライブラリのみ。戻り値の金額は `int`、キーは `YYYY-MM` 文字列。
- 作業ディレクトリ外のファイルを読み書きしない。
- Q1〜Q3 の回答が未確定の場合は推奨案（JST / completed のみ / 税込）で実装する。

### Definition of Done（検証できる条件）
推奨案（Q1=b, Q2=a, Q3=a）を採用した場合の期待値:
- `monthly_sales("sales.csv")` が次の月別内訳と一致:

- 他の回答の場合は、同じ手順で期待値を再計算（例: UTC・completed のみ・税込 → `{"2026-01": 19800, "2026-02": 7700, "2026-04": 26400}`）。
