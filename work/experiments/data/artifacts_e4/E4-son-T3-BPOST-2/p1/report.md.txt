# 実装レポート

## 実装
`solution.py` の `validate_invoice_id(value) -> bool`。形式 `INV-YYYYMM-NNNN` を厳密に判定します。

- `str` 以外は False
- 大文字 `INV-` + 西暦4桁 + 月2桁(01–12) + `-` + 連番4桁（ASCII数字のみ）
- 前後の空白・改行・小文字・全角数字は不可（`fullmatch`）

## 前提（samples.txt は正しい例のみで、仕様書がないため推測）
- 形式は例から `INV-YYYYMM-NNNN` と判断
- 月は 01–12 のみ有効（例: `INV-202613-0001` は False）
- 連番 `0000` は無効（例は 0001 始まりのため）。有効にするなら `seq >= 1` を外す
- 年は4桁で 0000 以外なら許容（範囲上限は設けていない）
- 空白の自動除去（trim）はしない

samples.txt の4件はすべて True になります。
