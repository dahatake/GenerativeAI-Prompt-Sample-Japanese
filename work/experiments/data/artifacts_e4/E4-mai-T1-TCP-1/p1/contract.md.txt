# Task Contract

## 確認できた事実

- 作業ディレクトリには `sales.csv` と現在の `timing.txt` のみがあります。
- `sales.csv` のヘッダーは `order_id,ordered_at,amount_incl_tax,status` です。
- データは10行あり、値は `completed` または `cancelled` のステータスです。
- 日時は ISO 8601 UTC形式（例: `2026-01-05T02:15:00Z`）です。
- 金額は整数文字列で、負数も存在します（例: `-1100`）。
- データ上の出現月は1月・2月・4月です。
- ディレクトリ内に既存の `solution.py`、テスト、仕様書はありません。

## 仮定

- 月キーは `YYYY-MM` とします。
- `ordered_at` のUTC日付部分から月を決定します。
- 出力は販売レコードが存在する月のみを返します。
- `completed` を売上対象とし、負数は返金として符号付き合算します。
- 金額は正確な整数として解析します。

## 不足情報

- `cancelled` を売上集計から除外するか、金額を含めるか。
- 欠落月を `0` として出力するか。
- 不正な日時・金額・CSV構造をどう扱うか（既定案は明示的な例外）。

## Outcome

作業ディレクトリ内の `solution.py` に、指定されたCSVパスから月次売上を集計する `monthly_sales(path)` を実装します。戻り値は `{"YYYY-MM": int}` のdictです。

## Scope・Out of scope

### Scope

- 標準ライブラリの `csv` を使用したCSV読み込み。
- `ordered_at` から月を抽出し、対象ステータスの `amount_incl_tax` を月ごと合算。
- 戻り値の型をdictとし、金額をintにする。

### Out of scope

- CSV以外の入力形式。
- 請求、税計算、通貨換算、外部データ連携。
- CLIや他モジュールへの統合。

## Data sources

- 入力データ: 引数 `path` が示すCSV。
- 確認対象のサンプル: 作業ディレクトリの `sales.csv`。

## Constraints

- 作業ディレクトリ外のファイルは読まない・変更しない。
- このフェーズでは `contract.md` と `timing.txt` 以外を作成・変更しない。
- 変更は作業ディレクトリ内に限定する。

## Definition of Done（検証できる条件）

- 推奨既定案を採用した場合、サンプルで `{"2026-01": 19800, "2026-02": 7700, "2026-04": 26400}` を返す。
- 戻り値の各キーが `YYYY-MM` に一致し、各値が `int` である。
- `cancelled` 行を除外し、`completed` 行の負数を符号付きで合算する。
- 不正なヘッダー、日時、または金額は明確な例外で失敗させる。

## Evidence

- 2026-01: 11000 + 5500 + 3300 = 19800
- 2026-02: 8800 + (-1100) = 7700
- 2026-04: 16500 + 2200 + 7700 = 26400
- cancelled行: A-1003、A-1007

## Open questions

### Q1. cancelled行の扱い

- 選択肢A（推奨既定案）: `status == "completed"` の行だけを集計し、`cancelled` 行は除外します。
- 選択肢B: `status == "completed"` と `cancelled` を問わず全行を金額に含めます。
- 選択肢C: `status == "completed"` と金額が負数の行だけを集計し、正数の `cancelled` 行は除外します。
- 上記以外のルールが必要な場合は、具体的なステータス名と包含方法を答えてください。

### Q2. 欠落月の扱い

- 選択肢A（推奨既定案）: レコードが存在する月だけをdictに含めます（この場合、2026-03は含めません）。
- 選択肢B: データ内の最小月から最大月まで連続する全月を含め、欠落月は `0` にします（1月〜4月なら2026-03も含めます）。
- 選択肢C: カレンダー上の固定期間（例: 2026-01〜2026-12）を指定して全月を含め、欠落月を `0` にします。
- 上記以外の期間ルールが必要な場合は、具体的な開始月・終了月を答えてください。

### 未質問の重要な仮定

- この仮定で進めます: 不正なヘッダー、日時、または金額は明確な例外として失敗させます。
- この仮定で進めます: Q1=A、Q2=A。
