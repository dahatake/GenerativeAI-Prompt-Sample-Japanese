## 0. 確認したいこと（最大 3 問）

外れたときに全請求書の金額が変わる点だけに絞りました。選択肢にない場合は、**具体的な値**（例: 「UTC+9」「7%」「四捨五入」）でお答えください。

### Q1. 「月」と単価の適用日は、どのタイムゾーンで判定しますか？
`orders.csv` の `ordered_at` は UTC（末尾 `Z`）です。境界付近の注文が複数あり、選ぶタイムゾーンによって 2026-10 の結果が大きく変わります。
- O1021 `2026-10-31T16:00Z` → JST では 11/01 01:00（10 月の請求から外れる）
- O1002 `2026-09-30T15:30Z` → JST では 10/01 00:30（10 月の請求に入る）
- O1008 `2026-10-09T15:10Z` → JST では 10/10。F100 の単価が 1580 円から 1680 円に変わる
- O1012 `2026-10-15T15:20Z` → JST では 10/16。A100 の単価が 1200 円から 1300 円に変わる

| 選択肢 | 内容 |
|---|---|
| **A（推奨）** | **JST（UTC+9）** に変換してから、`YYYY-MM` の月判定と、単価適用日（`effective_from <= JSTの注文日` を満たす最新の行）の判定を行う |
| B | UTC のまま、月判定と単価適用日の判定を行う |
| C | 月判定は JST、単価適用日は UTC（またはその逆）。どちらをどちらにするか指定してください |

### Q2. 値引き（discount）のルールを教えてください
`customers.csv` には `tier`（`gold` / `standard`）がありますが、値引き率や条件を示すデータはどこにもありません。

| 選択肢 | 内容 |
|---|---|
| **A（推奨）** | `gold` は税抜小計の **5%** を値引き（1 円未満切り捨て）。`standard` は 0 円 |
| B | `gold` は税抜小計の **10%** を値引き（1 円未満切り捨て）。`standard` は 0 円 |
| C | 金額条件で値引きする。例: 税抜小計が **10,000 円以上** なら **3%**（切り捨て）。閾値と率を指定してください |
| D | 値引きはしない（常に 0 円） |

値引きは税抜金額から差し引き、消費税は値引き後の金額に対して計算します。

### Q3. 消費税率と端数処理はどうしますか？
`products.csv` の `category` は `general` と `food` です。

| 選択肢 | 内容 |
|---|---|
| **A（推奨）** | `general` は **10%**、`food` は **8%**（軽減税率）。請求書ごと・税率ごとに「（税抜額 − その税率区分の値引き）× 税率」を計算し、**1 円未満切り捨て**。値引きは税率区分ごとに算出し（各区分の税抜額 × 値引き率を切り捨て）、`discount` はその合計 |
| B | 一律 **10%**。請求書単位で「（subtotal − discount）× 10%」を計算し、1 円未満切り捨て |
| C | A と同じ税率で、端数処理だけ **四捨五入** または **切り上げ** にする。どちらか指定してください |

## 2. 仮定（質問にしなかった点。この仮定で進めます）

1. **請求対象の status**: `completed` と `shipped` だけを請求します。`returned` と `cancelled` は請求書に載せません（マイナス行も作りません）。
2. **請求書の単位**: 1 顧客 1 か月につき 1 通です。請求できる明細が 1 件もない顧客（例: 10 月の C005）の請求書は作りません。
3. **invoice_id**: `INV-{YYYYMM}-{customer_id}` とします（例: `INV-202610-C001`）。
4. **単価の決め方**: 注文日（Q1 で決めたタイムゾーン）以前で、`effective_from` が最も新しい行の単価を使います。該当する単価がない SKU や、マスタにない customer_id / sku は `ValueError` にします。
5. **明細**: `amount = unit_price × qty` です。注文 1 行を明細 1 行にし、同じ SKU でもまとめません。並びは `ordered_at` 昇順、同時刻なら `order_id` 昇順です。
6. **金額**: `subtotal` は明細の amount の合計（税抜）、`total = subtotal − discount + tax` です。値はすべて Python の `int` です。
7. **戻り値の並び**: `customer_id` の昇順です。対象月の請求がない場合は空リストを返します。
8. **CSV 出力**: UTF-8（BOM なし）、ヘッダーは `invoice_id,customer_id,subtotal,discount,tax,total` です。並びは戻り値と同じです。対象が 0 件でもヘッダーだけのファイルを出力します。
9. **入力チェック**: `month` が `YYYY-MM` 形式でない場合は `ValueError` にします。`ordered_at` に `Z` やオフセットがない場合は UTC とみなします。
10. **実装方式**: 標準ライブラリ（`csv`、`datetime`、`decimal` は不要の見込み）だけを使い、外部パッケージは使いません。

## Task Contract

### Outcome
`solution.py` に `make_invoices(data_dir, month)` を実装します。指定した月の顧客別請求書（dict のリスト）を返します。また、`python solution.py <data_dir> <YYYY-MM> <out.csv>` で請求書一覧を CSV に書き出せるようにします。

### Scope / Out of scope
- **Scope**
  - 4 つの CSV を読み込む
  - 月で絞り込む（Q1）
  - 請求対象の status で絞り込む
  - 適用日に応じて単価を決める
  - 明細を作る
  - 値引き（Q2）、消費税（Q3）、合計を計算する

- **Out of scope**
  - 返品・キャンセルの赤伝や過去請求の訂正

  - 通貨換算
  - 請求書番号の永続的な採番

`<data_dir>/customers.csv`、`<data_dir>/products.csv`、`<data_dir>/prices.csv`、`<data_dir>/orders.csv`（UTF-8、ヘッダーあり）。このほかの情報源は使いません。
