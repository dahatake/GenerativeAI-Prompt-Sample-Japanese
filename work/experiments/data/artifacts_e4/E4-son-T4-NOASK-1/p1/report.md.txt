## 採用した仮定

1. 休憩は控除しない（end − start をそのまま採用）。
2. 日跨ぎ（end < start）は end に24時間を加算。夜勤は開始日側に全時間を計上し、月またぎの按分はしない。
3. CSV の全行を月で区別せず従業員ごとに合計する（月絞り込み引数なし）。
4. `type == "work"` 以外（paid_leave 等）は 0 時間。ただし従業員キーは 0.0 で結果に含める。
5. work 行の start/end が欠損・`HH:MM` 形式でない場合、および employee が空の行は ValueError。
6. 入力は UTF-8（BOM 許容）、ヘッダあり、値の前後空白は除去。
7. 丸めは行わない（分単位の float）。start == end は 0 時間（24時間ではない）。
8. 同一従業員・同一日の複数行は単純合算。
9. 標準ライブラリのみ使用。`shifts.csv` は変更していない。
