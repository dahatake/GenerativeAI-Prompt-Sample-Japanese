実装内容

- solution.py に monthly_work_hours(path) を実装しました。
- ヘッダー付き CSV を読み込み、従業員列、開始時刻列、終了時刻列、種別列を代表的な名称から判定します。
- 勤務時間は開始時刻と終了時刻の差を秒で集計し、従業員ごとに float の時間へ換算します。
- end が start より前の場合は日付をまたぐ勤務として24時間を加算します。
- end と start が同時刻の場合は0時間として扱います。
- type が paid_leave の行は所定労働時間の7.5時間として加算します。
- その他の休暇・欠勤種別は集計対象外です。不正な時刻行も集計対象外です。

前提

- 入力はヘッダー付き CSVです。
- 月別ではなくCSV全件を従業員ごとに合計します。
- 従業員列・時刻列は一般的な英語名および一部の日本語名から判定します。

今回の修正

- type=paid_leave の行を除外せず、従業員ごとの労働時間へ7.5時間を加算するよう修正しました。
- end < start のみ翌日跨ぎとして扱い、end == start は0時間として扱う明確な分岐に修正しました。
- paid_leave 行を時刻列の有無や時刻値に依存せず集計できるよう修正しました。
