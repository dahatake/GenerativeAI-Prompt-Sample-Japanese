# Task Contract（Execution Mode / 承認済み）

## 確認できた事実
- 作業ディレクトリは依頼されたディレクトリそのものです。
- ディレクトリ内に `samples.txt` があり、請求書番号の例が4件あります。
  - `INV-202601-0001`
  - `INV-202601-0002`
  - `INV-202512-0347`
  - `INV-202603-1200`
- 現時点の作業ディレクトリ内には依頼先の `solution.py` はなかったが、回答に基づく実装フェーズです。
- 回答は `answers.md` にあり、各質問の具体的な選択肢と連番の例外が明記されています。

## 回答で確定した仕様
- Q1 / 選択肢A：完全一致の `INV-YYYYMM-NNNN`。英字は大文字のみ、区切り違いは不正。
- Q2 / 選択肢B：年は `2020`〜`2099`、月は `01`〜`12`。
- Q3 / 選択肢A：`str` 以外（`None`、数値など）は例外を出さず `False`。前後空白を除去せず、完全一致だけを許可。
- 連番 `0000` は不正。連番は `0001`〜`9999` が有効。
- 数字はASCIIの `0`〜`9` のみ有効（全角数字などは不正）。

## 仮定
- 追加の正規化、トリミング、大小文字の変換、将来月の拒否は行わない。
- 発行済み番号、重複、連続性、実在性は検証しない。

## 不足情報
- answers.md の回答により、実装に必要な形式・範囲・型・連番ルールは確認できた。
- 外部データソース、外部API、既存テストの不足は本タスクの範囲外とし、追加確認は不要。

## Task Contract（承認済み）

### Outcome
- `solution.py` 内に `validate_invoice_id(value) -> bool` を提供する。
- 有効な請求書番号は `True`、仕様違反は `False`。

### Scope
- `solution.py` の関数実装。
- 入力型、接頭辞、固定桁、ASCII数字、年・月範囲、連番範囲の検証。

### Out of scope
- 請求書番号の実在確認、重複確認、外部照会。
- 連番の発行順序・連続性の検証。
- ファイル変換、正規化、標準入出力・例外送出。

### Data sources
- `samples.txt` の請求書番号4件。
- `answers.md` の確定回答。
- 依頼文の関数名と戻り値要件。

### Constraints
- 作業ディレクトリ外のファイルは読まない・書かない。
- 標準ライブラリのみを使用する。
- 戻り値は必ず `bool` にする。
- 前後空白は許容しない。

### Definition of Done（検証できる条件）
1. `contract.md` が承認済み仕様へ更新されている。
2. `validate_invoice_id('INV-202601-0001')` が `True`。
3. `validate_invoice_id('INV-202512-0347')` が `True`。
4. `samples.txt` の全4例が `True`。
5. 空文字、`None`、数値、前後空白付き文字列、桁不足、桁超過、ハイフン欠落、不正接頭辞、不正月、全角数字、範囲外年、連番 `0000` を `False` と判定する。
6. 最小限のテストスクリプトを作成・実行し、コマンドと出力を証拠として残す。

### Evidence
- `answers.md` の確定仕様。
- `samples.txt` のサンプル例。
- `test_solution.py` のテスト出力。
- `report.md` の各DoD状態。
