## 採用した仮定
1. 「実労働時間」= 拘束時間 − 休憩（控除後）。その値を 15 分単位で切り捨てる。
2. 6 時間超 = 360 分を超える場合（360 分ちょうどは控除なし）。
3. end < start は翌日終了（24 時間加算）。
4. 月での絞り込み・月別分割はしない。全行を合算する。
5. `work` 以外の未知の type は 0 時間。start/end が空・不正な work 行は 0 時間（例外なし）。
6. 勤務が 0 時間でも行のある従業員は `0.0` で戻り値に含める。
7. paid_leave は 1 行 7.5 時間で、休憩控除・切り捨ての対象外。
8. CSV は UTF-8（BOM 可）。内部では分の整数で計算し、最後に時間へ変換する。
9. 同一従業員・同一日の重複行は重複排除せず、そのまま加算する。
