# report

## 実装
`solution.py` の `monthly_sales(path)` が `sales.csv` を月次集計し `{"YYYY-MM": int}` を返します。

## 確定した仕様（answers.md 反映済み）
1. 月の境界は JST (UTC+9)。`ordered_at` (UTC) を JST に変換して判定。
2. `status == cancelled` は除外。
3. 負の金額（返金）は売上から相殺（回答なし・推奨案のまま）。
4. 売上は税抜（税込 ÷ 1.1、整数）。月合計を 1.1 で割って四捨五入（回答に端数規定なし・現状のまま）。
5. 最初の月〜最後の月の間は、注文がない月も 0 で含める。

## 今回修正した点
- 注文のない月（2026-03）を 0 として出力するようにした（Q5）。最初・最後の月は、集計対象の注文がある月で決める。
- Q1〜Q4 は既存実装が回答と一致していたため変更なし。

## 結果
`{'2026-01': 15000, '2026-02': 10000, '2026-03': 0, '2026-04': 17000, '2026-05': 7000}`

## 備考
- 対象行が 1 件もない場合は `{}` を返す。
- 税込のまま集計したい場合は `tax_rate_percent=0` を渡す。
