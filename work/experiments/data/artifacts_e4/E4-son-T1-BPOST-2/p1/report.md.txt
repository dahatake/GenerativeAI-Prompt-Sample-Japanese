# report

## 実装
`solution.py` の `monthly_sales(path)` が `sales.csv` を月次集計し `{"YYYY-MM": int}` を返します。

## 前提（仕様が不明だったため私が決めたもの）
1. **月の境界は JST (UTC+9)**。`ordered_at` は UTC なので JST に変換して月を決める。例: `2026-01-31T16:20Z` は 2026-02 に入る。`tz` 引数で変更可。
2. **`status == cancelled` は除外**。
3. **負の金額（返金）は売上から相殺**（A-1006 の -1100）。
4. **売上は税抜**。列名が `amount_incl_tax` (税込) のため、消費税 10% を引く。月合計を 1.1 で割り、四捨五入で int にする。`tax_rate_percent=0` を渡すと税込のまま集計する。
5. 取引のない月（3月）はキーに含めない。

## 結果（既定設定）
`{'2026-01': 15000, '2026-02': 10000, '2026-04': 17000, '2026-05': 7000}`

税込で集計する場合は `{'2026-01': 16500, '2026-02': 11000, '2026-04': 18700, '2026-05': 7700}`。

## 要確認
税抜か税込か、JST か UTC か、取消・返金の扱いは、業務の定義と違う場合は引数または既定値の変更が必要です。
