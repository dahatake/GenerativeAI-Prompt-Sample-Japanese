# 月次売上集計：実行報告

`contract.md` を推奨既定値で確定し、`solution.py` に `monthly_sales(path)` を実装した。検証は指定作業ディレクトリで実施した。

## 採用した仮定

- 日時は UTC の `YYYY-MM-DDTHH:MM:SSZ`。月は JST（UTC+09:00）への変換後に決める。
- ステータスが `completed` に完全一致する行だけを計上する。取消やその他のステータスは除外する。
- `amount_incl_tax` はファイル内の単位のまま、符号付き 10 進整数として足す。負額を含め、税額再計算、通貨換算、丸め、重複排除はしない。
- 対象行のない月は省略する。対象行があり合計 0 の月は保持する。対象行がなければ空の辞書を返す。キー順は要件外。
- 入力はヘッダー付きのカンマ区切り UTF-8（BOM は任意）。集計に必須なのは `ordered_at`、`amount_incl_tax`、`status` で、`order_id` は不要。必須列の欠落、集計対象行の日付・金額の欠損や不正は `ValueError`。読込時の OS エラーは伝播する。

### D7：原本の SHA-256

開始時：

```powershell
Get-FileHash -LiteralPath '.\sales.csv' -Algorithm SHA256 | Select-Object -ExpandProperty Hash
```

```text
C6D43F26291C5523E093222EF4167EFC5F3E1CD037D5852E3DA0B4EDB9BD94EA
```

テスト後：

```powershell
$expected = 'C6D43F26291C5523E093222EF4167EFC5F3E1CD037D5852E3DA0B4EDB9BD94EA'
$actual = (Get-FileHash -LiteralPath '.\sales.csv' -Algorithm SHA256 -ErrorAction Stop).Hash
if ($actual -ne $expected) { throw "sales.csv SHA256 mismatch: $actual" }
Write-Output "sales.csv SHA256 unchanged: $actual"
```

