# Task Contract：従業員別の月間労働時間（承認済み）

## Outcome

`solution.py` に `monthly_work_hours(path)` を実装し、指定の勤怠 CSV から対象月の労働時間を従業員ごとに集計して `{従業員ID（str）: 時間（float）}` を返す。`answers.md` の回答を反映し、Execution Mode に移行する。

## Scope・Out of scope

- Scope: CSV の読込・検証、対象月の判定、日をまたぐ勤務の処理、休憩控除、勤務ごとの丸め、有給休暇の計上、従業員別の集計。
- Out of scope: 給与・残業・深夜割増の計算、休憩実績の推定、複数月分の結果を一度に返すこと、CLI・外部依存の追加、入力 CSV の変更。

## Data sources — 確認できた事実

- `shifts.csv` はヘッダー `employee,date,type,start,end` を持つ。データは 2026 年 10 月の 6 行（3 人、`work` 5 行と `paid_leave` 1 行）。`E002` に `22:00` → `06:00` と `13:00` → `19:00` の勤務がある。有給行の開始・終了は空欄で、CSV に休憩時間の列はない。
- `answers.md` の Q1–Q6 を集計ルールの根拠とする。関数には年月引数がなく、戻り値にも年月のキーはない。

## Constraints — 確定仕様

- **勤務（Q1、Q4、Q5）:** `end < start` は翌日の終了、`end == start` は開始と同日の終了（0 分）。日またぎ・月またぎでも全時間を `date`（開始日）に計上する。1 シフトの拘束時間が 360 分以下なら休憩控除なし、361 分以上なら 60 分を控除する。その後、その行の実労働分数を 15 分単位で切り捨てる。
- **有給（Q2）:** `paid_leave` は 1 行あたり 7.5 時間（450 分）を加算する。休憩控除・丸めの対象外とする。
- **対象月・集計（Q3、Q5）:** 全データ行の `date` が同じ暦年・月に属すること。複数の年月が混在すれば `ValueError`。1 行を 1 勤務または 1 休暇として加算し、重複排除や重なりの調整はしない。対象月に行のある従業員を 0 分でも含め、従業員ごとに整数分を合計し、最後に 60 で割って `float` を返す。月次合計には追加の丸めを行わない。
- **形式・エラー（Q6）:** UTF-8（BOM 可）のヘッダー付き CSV。`employee,date,type,start,end` の 5 列が必須で、列順は問わず、名前が重複しない追加列は無視する。データ行の列数はヘッダーと一致させる。完全な空行は無視する。ID は空白のみを不可とし、その他は文字列のまま扱う。日付・時刻は `YYYY-MM-DD`、`HH:MM`。`work` は両時刻が必須、`paid_leave` は両時刻とも空欄とする。不正なデータ行は CSV の行番号付き `ValueError`、必須ヘッダー不足・重複は `ValueError`、ファイル読込エラーはそのまま伝える。ヘッダーのみは `{}`。
- Python 標準ライブラリのみを使い、入力は読み取り専用とする。作業は指定ディレクトリ内に限る。開始・終了の時刻は `timing.txt` に 1 行ずつ追記する。

## Definition of Done

1. `from solution import monthly_work_hours` が成功する。CSV の集計結果はキーが `str`、値が `float` の `dict`。
2. `shifts.csv` の結果は `{'E001': 21.25, 'E002': 13.0, 'E003': 8.25}`（絶対誤差 `1e-9` 時間以内）。
3. 拘束時間 `6:00`、`6:01`、`6:14`、`6:15`、`8:00`、`8:01` の勤務は、控除・切り捨て後にそれぞれ `360`、`300`、`300`、`315`、`420`、`420` 分。`22:00` → 翌 `06:00` は `420` 分、同時刻の開始・終了は `0` 分。`5:14` が 2 シフトなら各シフトを丸めて月合計 `600` 分（合計後に丸めない）。
4. 有給のみは 1 行につき `7.5` 時間、複数の年月が混在すれば `ValueError`、ヘッダーのみは `{}`、不正な勤務時刻は行番号付き `ValueError`。月末 `22:00` → 翌月 `06:00` は開始月に `7.0` 時間すべてを計上する。入力検証として BOM・列順・追加列、欠落ヘッダー、不正な ID・日付・種別・レコード、有給の時刻、ファイル不存在を確認する。

## Evidence

- `shifts.csv` の手計算: `E001 = (480 + 345 + 450) / 60 = 21.25`、`E002 = (420 + 360) / 60 = 13.0`、`E003 = 495 / 60 = 8.25`。
- `test_solution.py` に各 DoD の検証を用意し、実行コマンド・出力、および条件ごとの状態を `report.md` に記録する。
