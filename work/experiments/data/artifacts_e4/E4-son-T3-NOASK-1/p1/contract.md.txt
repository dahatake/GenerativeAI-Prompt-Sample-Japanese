## 1. 調査結果

### 確認できた事実
- 作業ディレクトリのファイルは `samples.txt` のみ（実装・テスト・仕様書・既存の `solution.py` は無い）。
- `samples.txt` は「最近発行された請求書番号の例」として次の4件を含む。
  - `INV-202601-0001`
  - `INV-202601-0002`
  - `INV-202512-0347`
  - `INV-202603-1200`
- 4件はすべて `INV-` + 6桁（YYYYMM に見える）+ `-` + 4桁の連番、という同一の形に見える。
- 依頼: `solution.py` に `validate_invoice_id(value)` を実装し、戻り値は `bool`。

### 仮定（未確認）
- A1. 形式は `INV-YYYYMM-NNNN`（YYYY=西暦4桁、MM=月、NNNN=4桁連番）。サンプルからの推測。
- A2. 「正しい」は形式の妥当性のみ。DB照合や重複確認はしない。
- A3. `str` 以外（`None`、`int` など）は例外ではなく `False` を返す。
- A4. 前後の空白は許容しない（厳密一致）。大文字小文字も区別し `INV` は大文字のみ。
- A5. 全角数字や改行付き文字列（`$` 由来の末尾改行を含む）は不正とする。ASCII の `0-9` のみ許可。
- A6. チェックサム桁は無い（サンプルから検証不能）。

### 不足情報
- 4件の例だけでは、不正な番号の例（NG例）が無く、境界（月 `00`/`13`、連番 `0000`、年の範囲）が決められない。
- 正式な採番ルールの出典（仕様書）が無い。

## 2. 質問（最大3問）

**Q1. 月（MM）の扱いは？**
- a) `01`〜`12` のみ有効（推奨）
- b) 数字6桁なら何でも有効（`202613` も可）
- c) 月に加えて年の範囲も制限する（範囲を指定してください）

**Q2. 連番（NNNN）の扱いは？**
- a) `0001`〜`9999` を有効とし `0000` は無効（推奨）
- b) `0000`〜`9999` すべて有効
- c) 4桁を超える連番（5桁以上）も将来あり得る（桁数の上限を指定してください）

**Q3. 入力の寛容さは？**
- a) 厳密一致のみ。空白、小文字（`inv-...`）、`str` 以外はすべて `False`（推奨）
- b) 前後の空白は除去し、小文字は大文字として受け入れる
- c) ハイフン無し（`INV2026010001`）なども受け入れる

回答が無い場合は、各質問の推奨案（Q1=a, Q2=a, Q3=a）で進めます。

## 3. Task Contract 案

### Outcome
`solution.py` の `validate_invoice_id(value) -> bool` が、`INV-YYYYMM-NNNN` 形式の正しい請求書番号に `True` を、それ以外に `False` を返す。例外は送出しない。

### Scope / Out of scope
- Scope: `solution.py` に関数 `validate_invoice_id` を1つ実装する。
- Out of scope:
  - 請求書の存在確認、重複確認、DB・API連携
  - 採番、正規化、修復（不正値を直して返すこと）
  - CLI、ログ出力、外部ライブラリ依存
  - 外部テストフレームワークの導入（標準の `unittest` による検証用テストは可）

### Data sources
- `samples.txt`（有効な例4件。NG例は含まない）。
- この依頼文と、上記の質問への回答。

### Constraints
- Python 標準ライブラリのみを使う。
- 戻り値は厳密に `bool`（`re.Match` などを返さない）。
- 任意の入力で例外を出さない。
- 正規表現を使う場合は `$` ではなく `fullmatch` か `\Z` を使い、末尾改行を許さない。
- 上記以外の変更はしない（Q1〜Q3 の回答が出るまでは推奨案を既定とする）。

### Definition of Done（検証できる条件）
推奨案（Q1=a, Q2=a, Q3=a）の場合:
1. `samples.txt` の4件がすべて `True`。
2. 次はすべて `False`:
   - `INV-202600-0001`、`INV-202613-0001`（月が範囲外）
   - `INV-202601-0000`（連番0000）
   - `INV-202601-001`、`INV-202601-00001`（桁数違い）
   - `inv-202601-0001`、` INV-202601-0001`、`INV-202601-0001\n`（小文字・空白・末尾改行）
   - `INV-２０２６０１-０００１`（全角数字）
   - `INV202601-0001`、`INV-2026010001`（区切り違い）
   - 空文字列
3. `None`、`123`、`b"INV-202601-0001"`、`[]` は例外なしで `False`。
4. 戻り値の型が常に `bool`（`type(r) is bool`）。
5. `python -c "from solution import validate_invoice_id"` が成功する。
