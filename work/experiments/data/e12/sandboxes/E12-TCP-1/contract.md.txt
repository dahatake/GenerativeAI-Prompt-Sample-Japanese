# 1. 調査結果

## 確認できた事実

- 入力列は次の4列です。
  - `order_id`
  - `ordered_at`
  - `amount_incl_tax`
  - `status`
- データは10件あります。
- `ordered_at` はISO 8601形式で、末尾の `Z` はUTCを表します。
- `amount_incl_tax` は整数として解釈でき、負数も1件あります。
  - `A-1006`: `-1100`
- `status` は以下の2種類です。
  - `completed`: 8件
  - `cancelled`: 2件
- キャンセル行は次の2件です。
  - `A-1003`: 22,000円、2026年1月
  - `A-1007`: 4,400円、2026年2月
- 2026年3月の行はありません。
- UTC基準で `completed` のみを対象とし、負数をそのまま加算すると、期待値は次のとおりです。

```python
{
    "2026-01": 19800,
    "2026-02": 7700,
    "2026-04": 26400,
}
```

- 日本標準時 `Asia/Tokyo` に変換してから月を判定すると、次の2件の所属月が変わります。
  - `A-1004`: 2026年1月31日 16:20 UTC → 2026年2月1日 01:20 JST
  - `A-1010`: 2026年4月30日 15:30 UTC → 2026年5月1日 00:30 JST
- したがって、`completed` のみ、負数を加算、日本時間基準の場合は次の結果になります。

```python
{
    "2026-01": 16500,
    "2026-02": 11000,
    "2026-04": 18700,
    "2026-05": 7700,
}
```

## 仮定

質問への回答がない状態では、次を推奨既定案とします。

- 売上として集計するのは `status == "completed"` の行のみ。
- 月の判定はCSVに記録されたUTC基準。
- 負の金額は返品・値引き・調整額として、そのまま月次売上から差し引く。
- 戻り値には対象行が存在する月だけを含める。
- 金額は小数や通貨記号を想定せず、Pythonの `int` として読み込む。
- 入力CSVはUTF-8、ヘッダーあり、カンマ区切りとする。
- 戻り値のキーは `YYYY-MM` 形式とする。

## 不足情報

- 月次集計に含める `status`
- 月を判定するタイムゾーン
- 売上がない月を戻り値に含めるか

# 3. Task Contract 案

## Outcome

`monthly_sales(path)` を実装し、指定されたCSVファイルから月次売上を集計して、次の形式で返す。

```python
dict[str, int]  # {"YYYY-MM": 金額}
```

推奨既定案を採用した場合、提示データに対する期待結果は次のとおり。

```python
{
    "2026-01": 19800,
    "2026-02": 7700,
    "2026-04": 26400,
}
```

## Scope

- 指定されたパスのCSVを読み込む。
- `status == "completed"` の行だけを集計する。
- `ordered_at` のUTC年月を `YYYY-MM` に変換する。
- `amount_incl_tax` を整数として加算する。
- 負の金額をそのまま加算し、月次売上から差し引く。
- 集計対象行が存在する月だけを返す。
- 月キーを昇順で挿入した `dict` を返す。
- 提示データに対するテストを作成または提示する。

## Out of scope

- 複数通貨への対応
- 税抜金額への変換
- 消費税の再計算
- キャンセル日や返金日を基準にした会計処理
- CSV以外の入力形式
- データベースへの保存
- 大規模データ向けの並列・分散処理
- 文字コードの自動判定
- 不正レコードの自動補正

## Data sources

- 関数引数 `path` が指すCSVファイル
- 使用列:
  - `ordered_at`
  - `amount_incl_tax`
  - `status`
- `order_id` は集計には使用しない。ただし、エラー内容に行を識別する情報として利用する可能性がある。

## Constraints

- Pythonで実装する。
- 戻り値は `{"YYYY-MM": int}` 形式の `dict`。
- CSVはUTF-8、ヘッダーあり、カンマ区切りと仮定する。
- `ordered_at` はISO 8601形式で、提示データではUTCを示す `Z` が付く。
- `amount_incl_tax` は符号付き整数として扱う。
- 外部ライブラリを必要としない実装を優先する。
- 入力ファイルそのものは変更しない。

## Definition of Done

以下をすべて満たしたら完了とする。

1. `monthly_sales(path)` が有効なCSVパスを受け取れる。
2. 戻り値の型が `dict` である。
3. すべてのキーが `YYYY-MM` 形式である。
4. すべての値が `int` である。
5. `cancelled` の2件が集計されない。
6. `A-1006` の `-1100` が2026年2月の金額から差し引かれる。
7. 推奨既定案の場合、提示データに対して次の結果になる。

```python
{
    "2026-01": 19800,
    "2026-02": 7700,
    "2026-04": 26400,
}
```

8. 売上行がない `2026-03` は戻り値に含まれない。
9. 月キーの順番が昇順になる。
10. ファイル読み込みに `with` 文を使い、ファイルが確実に閉じられる。

## Evidence

  - `completed` と `cancelled` の分離
