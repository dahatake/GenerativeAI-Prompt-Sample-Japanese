# Task Contract 案

## Outcome

`monthly_sales(path)` をPythonで実装し、指定されたCSVを読み込んで月別売上を次の形式で返す。

```python
{
    "YYYY-MM": 金額,
}
```

キーは年月文字列、値はPythonの `int` とする。

推奨既定案を採用した場合、提示データに対する期待値は次のとおり。

```python
{
    "2026-01": 19800,
    "2026-02": 7700,
    "2026-04": 26400,
}
```

## Scope

- `path` で指定されたCSVファイルの読み込み
- `ordered_at` に基づく年月の判定
- 対象ステータスのフィルタリング
- `amount_incl_tax` の整数集計
- `{年月: 月次合計}` 形式の辞書の返却
- 提示データを使った正常系の検証
- 契約で決めた入力不正に対する挙動の実装と検証

## Out of scope

- 消費税の再計算
- 税抜金額への変換
- 通貨換算
- 注文ID単位の重複排除
- キャンセル行と元注文の照合
- CSV内容の書き換え
- データベース、API、Excelファイルへの対応
- 会計基準上の売上認識日の判定

## Data sources

- 関数引数 `path` が指すCSVファイル
- 使用する列:
  - `ordered_at`
  - `amount_incl_tax`
  - `status`
- `order_id` は集計値には使用しない。ただし、エラー内容の特定に利用する可能性がある。

## Constraints

- 標準ライブラリを優先し、外部パッケージを必須にしない。
- 金額は浮動小数点数を経由せず、整数として扱う。
- 入力CSVはUTF-8、カンマ区切り、ヘッダーありとする。
- 日時はISO 8601形式として処理する。
- 戻り値に金額0の月を自動補完しない。
- 辞書は年月の昇順で挿入する。
- ファイルが存在しない場合は、Python標準の `FileNotFoundError` を伝播させる。
- 必須列がない場合は明示的な例外を発生させる。
- 不正な日時または整数化できない金額を黙って無視しない。

## Definition of Done

以下をすべて満たしたとき完了とします。

1. `monthly_sales(path)` が実装されている。
2. 戻り値が `dict[str, int]` 相当である。
3. 契約で確定したステータスだけが集計される。
4. 契約で確定したタイムゾーンで月が判定される。
5. 負額が契約どおりに処理される。
6. 同じ月の複数行が正しく合算される。
7. レコードのない月を含めない。
8. 提示されたCSVに対する結果が確定した期待値と一致する。
9. 少なくとも次の境界条件をテストする。
   - 月末・月初付近のUTC日時
   - 負額
   - 除外対象のステータス
   - レコードのない月
   - 必須列の欠落
   - 不正な日時
   - 不正な金額
   - ヘッダーのみの空データ
10. 実装コードと、そのまま実行できるテスト例を提示する。
