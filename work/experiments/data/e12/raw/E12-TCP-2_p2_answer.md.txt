# 1. 承認済みTask Contract

## Outcome

```python
monthly_sales(path)
```

を実装し、CSVから月次売上を計算して次の形式で返す。

```python
{"YYYY-MM": int}
```

## 確定仕様

- `status == "completed"` の行だけを集計する。
- `cancelled` は除外する。
- `ordered_at` はUTCとして読み込み、日本時間 `UTC+09:00` に変換して月を判定する。
- 最初の売上対象月から最後の売上対象月までを連続して返す。
- 対象行がない途中月は `0` とする。
- 負額はそのまま加算する。
- `amount_incl_tax` は `int` として処理する。
- 正常なヘッダー付きCSVを入力とする。
- 対象となる `completed` 行が1件もない場合は空のdictを返す。

# 2. 実装

```python
from __future__ import annotations

import csv
from collections import defaultdict
from datetime import datetime, timedelta, timezone
from pathlib import Path

JST = timezone(timedelta(hours=9))


def monthly_sales(path: str | Path) -> dict[str, int]:
    totals: defaultdict[str, int] = defaultdict(int)

    with open(path, newline="", encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)

        for row in reader:
            if row["status"] != "completed":
                continue

            ordered_at = datetime.fromisoformat(
                row["ordered_at"].replace("Z", "+00:00")
            )
            month = ordered_at.astimezone(JST).strftime("%Y-%m")
            totals[month] += int(row["amount_incl_tax"])

    if not totals:
        return {}

    first = min(totals)
    last = max(totals)

    year, month = map(int, first.split("-"))
    end_year, end_month = map(int, last.split("-"))

    result: dict[str, int] = {}

    while (year, month) <= (end_year, end_month):
        key = f"{year:04d}-{month:02d}"
        result[key] = totals.get(key, 0)

        if month == 12:
            year, month = year + 1, 1
        else:
            month += 1

    return result
```

# 6. 採用した仮定

1. CSVはヘッダー付き。
2. 必須列は `order_id`, `ordered_at`, `amount_incl_tax`, `status`。
3. `ordered_at` はUTCを示す `Z` 形式。
4. 月判定は日本時間固定の `UTC+09:00`。
5. 日本時間の夏時間は考慮しない。
6. `status` が厳密に `"completed"` の行だけを集計する。
7. 大文字・小文字や前後空白を自動補正しない。
8. 金額は10進整数として読み込む。
9. 負額は返金または調整額として、そのまま加算する。
10. 最初・最後の月は、CSV全体ではなく、売上対象となる `completed` 行を基準に決める。
11. その範囲内の欠損月は `0` にする。
12. `completed` が1件もなければ `{}` を返す。
13. 重複した `order_id` は重複排除しない。
14. 不正日時、欠損列、不正金額に対する回復処理は行わない。
15. ファイル文字コードはUTF-8またはUTF-8 BOM付きとする。

**主な実装上の変更点:** 回答に合わせて、UTC文字列を日時として解析してからJSTへ変換し、単なる文字列切り出しを避けました。また、月を整数の年・月で進めることで、12月から翌年1月への補完にも対応しています。
