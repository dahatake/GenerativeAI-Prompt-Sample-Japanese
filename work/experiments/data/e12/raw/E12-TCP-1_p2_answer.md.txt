## 1. 承認済み Task Contract

### Outcome

`monthly_sales(path)` を実装し、CSVから月次売上を集計して次の形式で返す。

```python
dict[str, int]  # {"YYYY-MM": 金額}
```

承認済み仕様による期待結果：

```python
{
    "2026-01": 16500,
    "2026-02": 11000,
    "2026-03": 0,
    "2026-04": 18700,
    "2026-05": 7700,
}
```

### Scope

- `status == "completed"` の行だけを集計する。
- `ordered_at` をUTCから `Asia/Tokyo` に変換して月を判定する。
- `amount_incl_tax` を符号付き整数として加算する。
- 負の金額は月次売上からそのまま差し引く。
- 最初の集計対象月から最後の集計対象月まで、すべての月を返す。
- 集計対象注文がない月は `0` とする。
- 月キーを昇順で挿入した `dict` を返す。
- 不正なレコードや必須列不足は例外で通知する。

### 更新後のDefinition of Done

1. 有効なCSVパスを受け取れる。
2. 戻り値が `dict` である。
3. キーが `YYYY-MM` 形式である。
4. 値が `int` である。
5. `cancelled` の2件を除外する。
6. `A-1006` の `-1100` を2026年2月から差し引く。
7. 承認済み仕様で、上記の期待結果になる。
8. 注文がない `2026-03` を値 `0` で含める。
9. 月キーが昇順になる。
10. ファイル読み込みに `with` 文を使用する。
11. 月末付近のUTC時刻を日本時間に変換して所属月を決定する。
12. 不正な日付、非整数金額、必須列不足を黙って無視しない。

## 2. 実装

```python
import csv
from collections import defaultdict
from datetime import datetime
from zoneinfo import ZoneInfo


def monthly_sales(path):
    required = {
        "order_id",
        "ordered_at",
        "amount_incl_tax",
        "status",
    }
    totals = defaultdict(int)

    with open(path, "r", encoding="utf-8", newline="") as f:
        reader = csv.DictReader(f)

        missing = required - set(reader.fieldnames or [])
        if missing:
            raise ValueError(
                f"missing required columns: {sorted(missing)}"
            )

        for line_no, row in enumerate(reader, start=2):
            if row["status"] != "completed":
                continue

            try:
                # Pythonのfromisoformatで解釈できるよう、
                # UTCを示すZを明示的なUTCオフセットに変換する。
                ordered_at = datetime.fromisoformat(
                    row["ordered_at"].replace("Z", "+00:00")
                )

                if ordered_at.tzinfo is None:
                    raise ValueError(
                        "ordered_at must include timezone"
                    )

                local_time = ordered_at.astimezone(
                    ZoneInfo("Asia/Tokyo")
                )
                amount = int(row["amount_incl_tax"])

            except (TypeError, ValueError) as exc:
                order_id = row.get("order_id", "")
                raise ValueError(
                    f"invalid record at line {line_no}, "
                    f"order_id={order_id!r}: {exc}"
                ) from exc

            month = local_time.strftime("%Y-%m")
            totals[month] += amount

    if not totals:
        return {}

    first = datetime.strptime(min(totals), "%Y-%m")
    last = datetime.strptime(max(totals), "%Y-%m")

    result = {}
    current = first

    while current <= last:
        key = current.strftime("%Y-%m")
        result[key] = totals.get(key, 0)

        if current.month == 12:
            current = current.replace(
                year=current.year + 1,
                month=1,
            )
        else:
            current = current.replace(
                month=current.month + 1
            )

    return result
```

### 空入力の扱い

`completed` の行が1件もない場合は、開始月と終了月を決定できないため、空の辞書 `{}` を返します。

                and actual["2026-05"] == 7700

            f"{name}: "
            f"{'PASS' if passed else 'FAIL'}"

    bad_path = Path(tmp) / "bad.csv"
    bad_path.write_text(

        "X,not-a-date,100,completed\n",
        encoding="utf-8",

    try:
        monthly_sales(bad_path)
    except ValueError as exc:
        print("不正データ例外: PASS", str(exc))
    else:
        raise AssertionError(
            "invalid data did not raise an exception"

## 7. 採用した仮定

- `status == "completed"` のみを集計する。
- ステータス比較は大文字・小文字を区別する。
- `ordered_at` はタイムゾーン付きISO 8601形式である。
- `Z` はUTCとして扱う。
- 月判定前に `Asia/Tokyo` へ変換する。
- 負の金額は返品・調整額としてそのまま差し引く。
- CSVはUTF-8、ヘッダーあり、カンマ区切りである。
- 最初と最後の月は、`completed` の注文によって決定する。
- その範囲内の欠損月は `0` で補完する。
- `completed` が1件もない場合は `{}` を返す。
- 必須列は4列すべてとする。`order_id` は集計には使わないが、エラー識別に使用する。
- 日付、金額、必須列に問題がある場合は、黙って除外せず `ValueError` を送出する。
- 金額は符号付き整数で、小数、桁区切り、通貨記号には対応しない。
- 外部ライブラリは使用せず、Python標準ライブラリのみを使用する。

主な変更点は、承認回答に合わせて**日本時間での月判定**と**欠損月のゼロ補完**を契約・期待値・検証条件のすべてに反映したことです。また、テストが単に結果を比較するだけにならないよう、型、キー形式、並び順、境界時刻、例外処理を個別に検証しました。
