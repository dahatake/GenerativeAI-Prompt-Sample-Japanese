実装コード

PYTHON
```python
import csv
from collections import defaultdict
from datetime import datetime
from zoneinfo import ZoneInfo

JST = ZoneInfo("Asia/Tokyo")

def monthly_sales(path, tz=JST):
    """completed の注文の税込金額を、指定タイムゾーン(既定: JST)の月ごとに合計する。"""
    totals = defaultdict(int)
    with open(path, newline="", encoding="utf-8") as f:
        for row in csv.DictReader(f):
            if not row.get("order_id"):          # 空行をスキップ
                continue
            if row["status"].strip() != "completed":
                continue
            ts = datetime.fromisoformat(row["ordered_at"].replace("Z", "+00:00"))
            key = ts.astimezone(tz).strftime("%Y-%m")
            totals[key] += int(row["amount_incl_tax"])
    return dict(sorted(totals.items()))
```

実装内容

標準ライブラリだけで CSV を読み、空行は飛ばします。
ordered_at の UTC 時刻を指定のタイムゾーンに直してから YYYY-MM ごとに合計します。結果は月の順に並べて返します。

前提にしたこと(結果が変わるもの)

月は日本時間で区切っています。 日時は UTC なので、どこで区切るかで2件が翌月に移ります。
A-1004(UTC 1/31 16:20)は日本時間で 2/1 なので2月に入ります。
A-1010(UTC 4/30 15:30)は日本時間で 5/1 なので5月に入ります。
UTC で区切る場合は monthly_sales(path, tz=timezone.utc) で、結果は {'2026-01': 19800, '2026-02': 7700, '2026-04': 26400} です。
completed だけを数えています。 cancelled の A-1003 と A-1007 は含めていません。
マイナスの金額も含めています。 A-1006 の -1,100 は返金とみなし、売上から差し引いています。
金額は税込のままです。 列名のとおり amount_incl_tax を使っています。税抜にする場合は税率を決める必要があります。
注文がない月は返しません。 このデータでは 3月がキーに入りません。0 で埋めたい場合はお知らせください。
