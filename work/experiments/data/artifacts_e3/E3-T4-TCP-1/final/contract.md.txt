# Task Contract: `monthly_work_hours(path)`

ステータス: **承認済み / Execution Mode**（answers.md の回答を反映。初版は Spec Mode で作成）

---

## 1. 前提の整理

### 確認できた事実
- 作業ディレクトリの入力は `shifts.csv` だけ。UTF-8 互換の ASCII で、BOM はなく、改行は LF。ヘッダー 1 行とデータ 6 行。
- 列は `employee,date,type,start,end`。全行が 2026-10 のデータ。`type` は `work` と `paid_leave` の 2 種類で、`paid_leave` の行は `start` と `end` が空欄。
- 休憩時間の列はない。日をまたぐ勤務がある（E002 `22:00–06:00`）。
- 関数に対象月を指定する引数はない。Python のバージョンは 3.12.10。

### 回答で確定した仕様（answers.md）
- **Q1 休憩**: 1 シフトの拘束時間（終了 − 開始）が **6 時間を超える場合だけ一律 60 分を控除**する。ちょうど 6 時間は控除しない。
- **Q2 有給**: `paid_leave` の 1 行を所定労働時間 **7.5 時間** として計上する。
- **Q3 丸め**: 1 シフトごとに、**休憩を控除した後の実労働時間を 15 分単位で切り捨て**てから合計する。合計後の丸めはしない。
- **A1**: `end < start` の場合は翌日に終了した勤務として +24 時間で計算し、勤務開始日に計上する。

### 採用した仮定（回答で「推奨案で進めて」とされたもの）
- A2: `start == end` は 0 時間とする。
- A3: 月で絞り込まず、ファイル全体を集計する（1 ファイル = 1 か月分とみなす）。
- A4: 有給の行だけの従業員も結果のキーに含める（値は 7.5 × 日数）。
- A5・A6: 不明な `type`、`work` 行での時刻の欠落、`HH:MM`（00:00–23:59）以外の時刻（`24:00` を含む）、必須列の欠落、空の employee は `ValueError` にする。スキップはしない。
- A7: `utf-8-sig` で読み込み、値の前後の空白を除去し、空行は無視する。
- A8: 同じ従業員・同じ日付の重複行はそれぞれ合算する。
- A9: 標準ライブラリだけを使う。
- 補足（実装上の解釈）: 有給の 7.5 時間は 15 分単位の端数がないため、切り捨ての対象外としてそのまま加算する。

## 2. Task Contract

### Outcome
`solution.py` の `monthly_work_hours(path) -> dict[str, float]` が、勤怠 CSV から従業員ごとの合計労働時間（時間、float）を返す。

### Scope
- CSV の読み込みと検証
- `work` 行: 拘束時間の算出（日またぎを含む）→ 6 時間を超えれば 60 分を控除 → 15 分単位で切り捨て
- `paid_leave` 行: 7.5 時間を加算
- 従業員ごとに合計した分数を 60 で割り、float で返す

### Out of scope
深夜・残業・休日の区分、月の分割や指定、CLI、ファイル出力、外部ライブラリ、`shifts.csv` の変更

### Data sources
引数 `path` で渡す CSV（`shifts.csv` と同じ形式）。サンプルは作業ディレクトリの `shifts.csv`。

### Constraints
Python 3.12 と標準ライブラリだけを使う。作業ディレクトリの外は読み書きしない。戻り値の値は float。

### Definition of Done（検証できる条件）
1. `monthly_work_hours("shifts.csv")` が **`{"E001": 21.25, "E002": 13.0, "E003": 8.25}`** と完全に一致する。
   - E001 = 9:00→控除後 8:00 + 5:50→15 分単位で 5:45 + 有給 7:30 = 21:15
   - E002 = 8:00（日またぎ）→控除後 7:00 + 6:00（ちょうど 6 時間なので控除なし）= 13:00
   - E003 = 9:15→控除後 8:15 = 8.25
2. 戻り値の値がすべて `float` 型である。
3. 日またぎの勤務 `22:00–06:00` が 7.0 時間（8 時間 − 休憩 60 分）になる。
4. 休憩控除の境界: `09:00–15:00`（6 時間ちょうど）は 6.0、`09:00–15:01`（6 時間 1 分）は 5.0（60 分控除後の 5:01 を切り捨てて 5:00）。
5. 15 分単位の切り捨て: `09:00–09:14` は 0.0、`09:00–09:15` は 0.25。休憩控除の後に切り捨てる（例: `09:00–16:29` は 7:29 → 控除後 6:29 → 6.25）。
6. 有給の行だけの従業員は 7.5 × 日数（1 日なら 7.5）で結果に含まれる。
7. 不正な `type`、`work` 行での時刻の空欄、`25:00`、`24:00`、必須列の欠落のいずれかがあれば `ValueError` が送出される。
8. ヘッダーだけの CSV では `{}` が返る。`start == end` は 0.0 になる。
