# report

## 実装
`solution.py` の `monthly_sales(path)` は `sales.csv` を読み、`{"YYYY-MM": 税抜金額(int)}` を月順で返します。

`sales.csv` に対する結果:
`{"2026-01": 15000, "2026-02": 10000, "2026-03": 0, "2026-04": 17000, "2026-05": 7000}`

## 仕様（answers.md の回答を反映）
1. **タイムゾーン (Q1)**: `ordered_at`（UTC）を JST(UTC+9) に変換して月を判定。A-1004 は 2月、A-1010 は 5月に計上。
2. **ステータス (Q2)**: `cancelled` を除外（`exclude_statuses` 引数で変更可）。
3. **金額 (Q3)**: `amount_incl_tax`（税込10%）を月ごとに合算し、**税抜金額 = 税込 / 1.1** を整数で返す。
4. **負の金額 (Q4, 推奨案)**: 返金・値引きとして合算に含める（A-1006: -1100 → 税抜 -1000）。
5. **空き月 (Q5)**: 最初の月〜最後の月の間で注文がない月も 0 で含める（2026-03 = 0）。

変更なし: JST での月判定 (Q1)、負の金額を含める (Q4)。

## 残る前提
- 税抜換算は**月合計**に対して行い、端数は四捨五入（`Decimal` で計算し浮動小数点誤差なし）。現データはすべて 1.1 で割り切れるため、行ごとに換算しても結果は同じです。端数処理（切り捨て／四捨五入、行単位／月単位）の指定があれば変更します。
- データが 0 件の場合は `{}` を返します。
