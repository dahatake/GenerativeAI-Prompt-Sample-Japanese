## 2. 仮定（質問せず既定値で進める点）

- 戻り値のキーは `"YYYY-MM"`（ゼロ埋め 2 桁月）、値は Python `int`。
- 戻り値はキー昇順で構築する（dict の比較には影響しないが可読性のため）。
- **データが 0 件の月（例: 2026-03）はキーを含めない**（0 埋めしない）。
- 負の金額（`A-1006` -1100）は返金・値引きとして **そのまま合算（相殺）** する。
- 入力ファイルは UTF-8（BOM 付きも許容: `utf-8-sig` で読む）、CSV ヘッダ名で列を参照する。
- 標準ライブラリのみ使用（`csv`, `datetime`, `zoneinfo`）。pandas 等は使わない。
- 空ファイル（ヘッダのみ）の場合は `{}` を返す。

## 3. 不足情報

- 「売上」が税込か税抜か。税抜なら丸め方と丸め単位（行ごとか月合計か）。
- `cancelled` 行・未知の status・不正行（日付/金額がパースできない行）をどう扱うか。

## 4. 質問（最大 3 問）

選択肢のどれにも当てはまらない場合は、**具体的な値（タイムゾーン名、税率、丸め方、対象 status の列挙など）で回答してください。**

### Q1. 月の境界はどのタイムゾーンで判定しますか？（A-1004 と A-1010 の帰属月が変わります）
- **A（推奨）: `Asia/Tokyo`（JST, UTC+9）に変換してから `YYYY-MM` を取る**  
  → A-1004 は 2026-02、A-1010 は 2026-05 に計上。
- B: UTC のまま `YYYY-MM` を取る  
  → A-1004 は 2026-01、A-1010 は 2026-04 に計上。
- C: その他（IANA タイムゾーン名で指定してください。例: `America/Los_Angeles`）

### Q2. 集計する金額は税込・税抜どちらですか？
- **A（推奨）: 税込 `amount_incl_tax` をそのまま合算（丸めなし、int 合計）**
- B: 税抜 = 行ごとに `amount_incl_tax / 1.10` を **1 円未満切り捨て** してから月合計  
  （負値は 0 方向へ切り捨て。Decimal で計算し浮動小数誤差を避ける）
- C: 税抜 = 月合計（税込）を `/ 1.10` して **1 円未満切り捨て**
- D: その他（税率と丸め方 [切り捨て/四捨五入/銀行丸め] と丸め単位 [行/月] を指定してください）

### Q3. どの行を集計対象にしますか？（status と不正データの扱い）
- **A（推奨）: `status == "completed"` の行のみ集計。`cancelled` は除外。未知の status は除外。日付・金額がパースできない行は `ValueError` を送出（行番号付き）**
- B: A と同じ対象だが、パース不能行は **スキップ**（例外を出さない）
- C: status に関係なく全行を集計（cancelled も含める）。パース不能行は `ValueError`
- D: その他（対象 status の列挙と不正行の扱い [例外/スキップ] を指定してください）

## 6. Task Contract（承認済み）

### 回答の反映
| 項目 | 決定 |
|---|---|
| Q1 タイムゾーン | `Asia/Tokyo`。`ordered_at`（UTC）を JST に変換して `YYYY-MM` を決める |
| Q2 金額 | 税抜 = 税込 ÷ 1.1。丸めは回答で実装側に委任 → **行ごとに 1 円未満を 0 方向へ切り捨て**（整数演算 `sign × (|税込| × 10 // 11)`、float 不使用）してから月合計 |
| Q3 対象行 | `completed` のみ集計（cancelled・未知 status は除外）。不正行は `ValueError`（行番号付き） |
| 欠損月 | **最初の月〜最後の月の間で集計対象行がない月は 0 で含める**（例: 2026-03 → 0） |
| 負の金額 | 返金として合算（相殺）。税抜換算も 0 方向切り捨て（-1100 → -1000） |
| キー順 | 昇順 |
| 文字コード | UTF-8（BOM 許容、`utf-8-sig`） |
| status 比較 | 前後空白除去・大文字小文字無視 |

### Outcome
`solution.py` の `monthly_sales(path) -> dict[str, int]` が、completed 行の税抜金額を JST 基準の月ごとに合算し、最初の月〜最後の月を欠損なく（0 埋め）昇順で返す。

### Scope
- `solution.py`（`monthly_sales`）の実装、`test_solution.py`（unittest/pytest 互換）の作成。

### Out of scope
- CLI・ファイル出力・グラフ化・通貨換算、order_id 重複排除、外部ライブラリ導入、作業ディレクトリ外の読み書き。

### Constraints

### Definition of Done（検証可能な条件）
1. `monthly_sales("sales.csv") == {"2026-01": 15000, "2026-02": 10000, "2026-03": 0, "2026-04": 17000, "2026-05": 7000}`。
2. 全値が `type(v) is int`、全キーが `^\d{4}-\d{2}$`、キーが昇順。
3. 最初〜最後の月の間の欠損月が 0 で含まれる（`"2026-03": 0`、年跨ぎ 2025-11→2026-02 でも 12・01 が 0）。

6. 税抜換算: 行ごとに 0 方向切り捨て（例: 税込 1000 → 909、税込 -1000 → -909、1000 と 1000 の 2 行 → 1818）。
7. ヘッダのみの CSV（および completed 行がない CSV）で `{}` を返す。
8. 金額が非整数・日付が不正・必須列欠落の行で `ValueError` が送出される。
9. テストがすべて pass（`python -m pytest -q test_solution.py`）。
