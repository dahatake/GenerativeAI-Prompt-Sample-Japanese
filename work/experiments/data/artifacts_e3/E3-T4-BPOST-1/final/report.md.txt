## 実装内容
- `solution.py` の `monthly_work_hours(path, month=None)` は CSV（`employee,date,type,start,end`）を読み込み、`{従業員ID: 労働時間(float, 時間)}` を返します。
- `work` 行の計算手順:
  1. 拘束時間 = `end - start`（`end < start` の場合は日跨ぎとみなし、終了時刻を翌日として扱う）
  2. 拘束時間が6時間を超える場合は60分を控除する
  3. 15分単位で切り捨てる
- `paid_leave` 行は 7.5 時間として計上します。
- 時刻の形式は `HH:MM` と `HH:MM:SS` に対応しています。UTF-8 の BOM と前後の空白も処理します。

## 前提（回答がなかったため、前回の案を継続）
- **月の扱い**: ファイルは1か月分のデータとみなし、全行を合計します。`month="YYYY-MM"` を渡すとその月だけを集計します。日跨ぎ勤務は開始日の月に計上します。
- `start` と `end` が同じ時刻の `work` 行は 0 時間とします。`start` か `end` が空の `work` 行は除外します。
- `work` と `paid_leave` 以外の type は 0 時間とします。ただし、その従業員も結果に含めます（`0.0`）。
- `paid_leave` には休憩控除と丸めを適用しません（7.5時間をそのまま計上します）。
