# monthly_work_hours 実装レポート

## 実装内容
- `solution.py` の `monthly_work_hours(path, month=None)` は CSV（`employee,date,type,start,end`）を読み込み、`{従業員ID: 労働時間(float, 時間)}` を返します。
- 各勤務の時間は `end - start` で計算します。`end < start` の場合は日跨ぎ勤務とみなし、終了時刻を翌日として扱います（例: 22:00–06:00 = 8.0h）。
- 時刻の形式は `HH:MM` と `HH:MM:SS` に対応しています。UTF-8 の BOM と前後の空白も処理します。
- サンプルデータの結果: `{'E001': 14.8333…, 'E002': 14.0, 'E003': 9.25}`

## 前提
- **休憩の控除なし**: CSV に休憩の列がないため、記録された時間をそのまま労働時間とします（法定休憩の自動控除はしていません）。
- **労働時間に数えるのは `type == work` の行だけ**: `paid_leave` などの休暇は実労働時間に含めません。ただし、休暇の行しかない従業員も `0.0` で結果に含めます。
- **月の扱い**: ファイルは1か月分のデータとみなし、全行を合計します。`month="YYYY-MM"` を渡すとその月だけを集計します。日跨ぎ勤務は開始日の月に計上します。
- **丸め処理なし**: 端数は丸めず float のまま返します（例: 5時間50分 = 5.8333…）。
- `start` と `end` が同じ時刻の行は 0 時間とします（24時間勤務とはみなしません）。`start` か `end` が空の勤務行は除外します。
