## 1. 調査結果

### 確認できた事実
- 作業ディレクトリにあったのは `samples.txt` と `timing.txt` だけです（`solution.py`、テスト、仕様書、設定ファイルはありません）。
- `samples.txt`（UTF-8、改行 CRLF）は、1行目が見出し「最近発行された請求書番号の例:」、その後に次の4件が続きます。
  - `INV-202601-0001`
  - `INV-202601-0002`
  - `INV-202512-0347`
  - `INV-202603-1200`
- 4件とも `INV` + `-` + 数字6桁 + `-` + 数字4桁 の形（長さ15文字）です。
- 6桁部分は `202601`, `202512`, `202603` で、YYYYMM（年4桁 + 月2桁、月は 01〜12）と読めます。
- 4桁部分は `0001`, `0002`, `0347`, `1200` で、左を0で埋めた連番に見えます。年月が変わっても続いているのか、月ごとに振り直しているのかは、サンプルからは判断できません。
- サンプルは全部「正しい例」です。**不正な例（False になるべき入力）は1件もありません。**
- 戻り値が `bool` であることは依頼に明記されています。

### 仮定（サンプルからの推測で、確認はできていません）
- A1: 形式は `INV-YYYYMM-NNNN` です。接頭辞は大文字の `INV` だけを受け付けます。
- A2: 区切りは半角ハイフン `-`（U+002D）だけです。全角数字・全角ハイフン・その他の Unicode 数字は不正とします（Python の `\d` は全角数字にも一致するため、`[0-9]` で判定します）。
- A3: 文字列全体が一致する必要があります（`re.fullmatch` を使います）。末尾の改行や前後の空白がある場合は不正です（Q3 で確認します）。
- A4: チェックディジットや外部台帳との突き合わせはしません。番号が実際に発行済みかどうかも判定しません。
- A5: 例外は投げず、どの入力でも `True` か `False` を返します。

### 不足情報
- 年月部分の意味をどこまで確認するか（月の範囲、年の範囲、未来日付の扱い）→ **Q1**
- 連番 `0000` を有効とするか、桁数は4桁固定か → **Q2**
- 入力の正規化（空白・大文字小文字）と、文字列以外の入力の扱い → **Q3**
- 不正な例がないため、境界の判定は契約で決めるしかありません。

## 2. 質問（外れたときの手戻りが大きいもの3問）

選択肢のどれにも当てはまらない場合は、**具体的な値（範囲・桁数・文字種など）で回答してください。**

### Q1. 年月部分 `YYYYMM` をどこまで確認しますか？
| 選択肢 | 内容（実装する値） |
|---|---|
| a | 形式だけ確認する: 数字6桁なら何でも可（`202613` や `000000` も True） |
| **b（推奨）** | 月が `01`〜`12` であることを確認する。年は数字4桁なら制限しない |
| c | 月が `01`〜`12`、かつ年が `2000`〜`2099` |
| d | c に加えて、実行時点の年月（ローカル時刻）より未来なら False |

推奨理由: `202613` を通すのは明らかな誤りです。一方、年の範囲や未来日付の判定は業務ルールに依存し、時刻に依存するとテストも不安定になるため、b にとどめます。

### Q2. 連番 `NNNN` の範囲と桁数は？
| 選択肢 | 内容 |
|---|---|
| **a（推奨）** | ちょうど4桁で `0001`〜`9999`（`0000` は False） |
| b | ちょうど4桁で `0000`〜`9999` |
| c | 4桁以上（`10000` 以上の5桁も可。ただし4桁未満は不可、`0` だけの値は不可） |

推奨理由: サンプルは `0001` から始まり、どれも4桁です。`0000` は「未採番」を表す値であることが多いためです。

### Q3. 入力の正規化と、文字列以外の入力の扱いは？
| 選択肢 | 内容 |
|---|---|
| **a（推奨）** | 厳密に判定する: `str` 以外（`None`、`int`、`bytes` など）は False。前後の空白・改行は除去せず False。小文字の `inv-` も False |
| b | 前後の空白を `strip()` してから判定する。大文字小文字は厳密に区別する。`str` 以外は False |
| c | `strip()` し、大文字小文字も区別しない（`inv-202601-0001` も True）。`str` 以外は False |
| d | a と同じ判定だが、`str` 以外の入力では `TypeError` を送出する |

推奨理由: 戻り値が `bool` と指定されているため、例外を投げない a が素直です。正規化は呼び出し側の責務とします。
