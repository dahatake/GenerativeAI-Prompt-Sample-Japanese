# 実装内容

`solution.py` の `monthly_work_hours(path, month=None)` は CSV（`employee,date,type,start,end`）を読み、従業員ごとの労働時間（時間, float）を `{従業員ID: 時間}` で返します。

`shifts.csv` での結果は `E001: 21.25`、`E002: 13.0`、`E003: 8.25` です。

# 仕様（answers.md の回答を反映済み）

- **`work` 行の計算**: 次の順で計算します。
  1. 拘束時間 = `end - start`
  2. 拘束時間が 6 時間を超える場合は、休憩 60 分を引きます。6 時間ちょうどなら引きません。
  3. 2 の結果を 15 分単位で切り捨てます。
- **`paid_leave` 行**: 1 行につき 7.5 時間（所定労働時間）として計上します。
- **その他の `type`**: 0 時間とします。ただし、その従業員も結果には含めます。
- **日付をまたぐ勤務**: `end < start` のときは翌日に終わった勤務とみなし、24 時間を足します。その勤務は開始日（`date`）の月に計上します。
- **対象月**: ファイル内の全行を合算します。任意引数 `month="YYYY-MM"` で月を絞り込めます。
- **入力の扱い**: 時刻は `HH:MM` 形式（`24:00` も可）とします。`work` 行に開始・終了時刻がない場合や、時刻の形式が不正な場合は `ValueError` を出します。BOM 付き UTF-8 と、前後の空白にも対応しています。
- **`start == end` の場合**: 0 時間として扱います。
