# 実装内容

`solution.py` の `monthly_work_hours(path, month=None)` は CSV（`employee,date,type,start,end`）を読み、従業員ごとの労働時間（時間, float）を `{従業員ID: 時間}` で返します。

`shifts.csv` での結果は `E001: 14.833…`、`E002: 14.0`、`E003: 9.25` です。

# 前提にしたこと（仕様が不明なため仮定した点）

- **集計対象**: `type == "work"` の行だけを数えます。`paid_leave` などの休暇は労働時間に含めません。ただし、休暇の行しかない従業員も `0.0` として結果に含めます。
- **日付をまたぐ勤務**: `end < start` のときは翌日までの勤務とみなし、24時間を足します（例: 22:00–06:00 は 8h）。その勤務は開始日（`date`）の月に計上します。
- **休憩**: CSV に休憩の列がないため、休憩は差し引いていません（例: 9:00–18:00 は 9h）。
- **対象月**: ファイルは 1 か月分のデータという想定で、全行を合算します。複数の月が混じる場合は、任意引数 `month="YYYY-MM"` で月を絞り込めます。
- **端数の扱い**: 丸めは行いません。
- **入力の扱い**: 時刻は `HH:MM` 形式（`24:00` も可）とします。`work` 行に開始・終了時刻がない場合や、時刻の形式が不正な場合は `ValueError` を出します。BOM 付き UTF-8 と、前後の空白にも対応しています。
- **`start == end` の場合**: 0 時間として扱います。
