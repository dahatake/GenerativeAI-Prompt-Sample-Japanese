Q1: 1シフトの拘束時間が6時間を超える場合は、一律で休憩60分を差し引いてください。6時間ちょうどの場合は差し引きません。

Q2: end が start より前の時刻なら、日付をまたいで翌日に終了した勤務として扱ってください。対象月の決め方は特に指定はありません。推奨案で進めてください。

Q3: type が paid_leave の行は、所定労働時間の7.5時間として計上してください。

Q4（丸め規則）: 各シフトの実労働時間は、15分単位で切り捨ててください。

Q5（work / paid_leave 以外の type 値）: 特に指定はありません。推奨案で進めてください。

Q6（不正行の扱い）: 特に指定はありません。推奨案で進めてください。
