## 採用した規則・仮定の一覧

| ID | 内容 | 根拠 |
|---|---|---|
| R1 | `end < start` は翌日終了とみなし +24h | Q2 回答 |
| R2 | 拘束時間が 6h を **超える** シフトは一律 60分控除。ちょうど 6h は控除なし | Q1 回答 |
| R3 | `paid_leave` 行は 7.5h（`start`/`end` は無視） | Q3 回答 |
| R4 | 各シフトの実労働時間（控除後）を15分単位で切り捨て。有給には適用しない（7.5h は15分の倍数） | Q4 回答 |
| A3 | `work`/`paid_leave` 以外の type は 0h。その従業員は `0.0` で結果に含める | Q5 指定なし → 推奨既定 |
| A4 | ファイル全体を1か月分として合算する。月の帰属は勤務開始日。複数月を含んでも検出しない | Q2 対象月の指定なし → 推奨既定 |
| A5 | 内部は整数の分で計算し、`分/60` の float で返す。R4 以外の丸めはしない | 既定 |
| A6 | 標準ライブラリのみ。`utf-8-sig` で読む（BOM 可）。`str` と `PathLike` を受け付ける | 既定 |
| A7 | 従業員 ID・列名・値は前後の空白を除去する | 既定 |
| A8 | 不正行は行番号付きの `ValueError` で止める（スキップしない）。対象: work 行の時刻の欠損や不正（00:00〜23:59 の `H:MM`/`HH:MM` 以外）、employee が空、date が不正、必須列の欠落 | Q6 指定なし → 推奨既定 |
| A9 | `start == end` の work 行は 0h（24h 勤務とはみなさない） | 既定 |
| A10 | 同一従業員・同一日の複数行は別シフトとして合算する | 既定 |
