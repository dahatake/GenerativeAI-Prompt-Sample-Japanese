## 1. 調査結果（Spec Mode から変更なし）

作業ディレクトリのファイル: `shifts.csv`、`answers.md`（回答）、`timing.txt`（計測用）。

`shifts.csv` の内容:

```
employee,date,type,start,end
E001,2026-10-01,work,09:00,18:00
E001,2026-10-02,work,09:00,14:50
E001,2026-10-03,paid_leave,,
E002,2026-10-01,work,22:00,06:00
E002,2026-10-02,work,13:00,19:00
E003,2026-10-01,work,08:30,17:45
```

### 1.1 確認できた事実
- F1: 列は `employee,date,type,start,end` の5列で、ヘッダ行があります。
- F2: UTF-8/ASCII で BOM はありません。改行は CRLF で、最終行も改行で終わっています。
- F3: `type` の値は `work` と `paid_leave` の2種類です。
- F4: `paid_leave` の行は `start` と `end` が空欄です。
- F5: 日付をまたぐ勤務があります（E002 の 22:00〜06:00）。
- F6: 時刻は `HH:MM` 形式で、分単位の端数があります。
- F7: 休憩時間の列はありません。
- F8: データは 2026年10月分だけで、従業員は E001・E002・E003 の3名です。
- F9: 戻り値は `{従業員ID: 労働時間(時間, float)}` です。引数は `path` だけです。

## 2. 決定事項（answers.md の回答）

- **Q1 休憩:** 1シフトの拘束時間（end − start）が**6時間を超える**場合は、一律60分を控除します。6時間ちょうどなら控除しません。
- **Q2 有給:** `paid_leave` の1行を所定労働時間 **7.5時間** として計上します。
- **Q3 丸め:** シフトごとに、**休憩控除後の実労働時間を15分単位で切り捨て**てから合計します。
  - 控除の60分は15分の倍数なので、控除と切り捨ての順序を入れ替えても結果は同じです。
  - 有給の 7.5h はもともと15分の倍数なので、丸めの影響を受けません。

## 3. 仮定（すべて推奨既定案を採用）
- A1: 1ファイルが1か月分です。全行を合計し、月の絞り込みはしません（OQ4 と同じ扱い）。
- A2: end < start は翌日終了とみなし、24時間を足します。勤務はすべて開始日の分として数えます（回答で明示的に承認済み）。
- A3: 1シフトは 0 より大きく 24 時間未満です。start == end は `ValueError` にします。時刻は `H:MM` または `HH:MM` で、時は 0〜23、分は 0〜59 です。
- A4: 標準ライブラリの `csv` を使い、`utf-8-sig` で開きます（BOM の有無どちらでも読めます）。
- A5: ファイルに出てくる従業員はすべて出力に含めます。`paid_leave` だけの従業員は、Q2 に従って 7.5h ×件数になります。
- A6: 次の場合は `ValueError` にします: 未知の `type`、`work` 行の start/end の欠落、時刻の書式エラー、日付の書式エラー（`YYYY-MM-DD` 以外）、必須列の欠落、空の従業員ID。
- A7: 空ファイル、またはヘッダ行だけのファイルは `{}` を返します。
- A8（実装時に追加）: `paid_leave` 行に start/end が書かれていても無視し、7.5h として計上します。
- OQ5: 月末をまたぐ夜勤は、開始日の月にすべて計上します（A1 のとおり月の絞り込みがないので、結果には影響しません）。
- OQ6: 従業員IDと各値は前後の空白を除きます。大文字・小文字は区別します。
- OQ7: 時間帯の重複は検出せず、単純に合計します。

## 4. Task Contract

### Outcome
`solution.py` に `monthly_work_hours(path) -> dict[str, float]` を実装します。勤怠 CSV から、従業員IDごとの月間労働時間（単位は時間）を返します。

### Scope
- `solution.py` を作成する。
- CSV を読み込んで検証する。
- 日付をまたぐ勤務、休憩控除（Q1）、有給の計上（Q2）、15分切り捨て（Q3）を実装する。
- 不正データのときに `ValueError` を出す。
- 検証用テスト `test_solution.py` を作り、結果を `report.md` に書く。

### Out of scope
- 残業・深夜割増・法定超過の判定
- 月の指定と複数月の分割
- タイムゾーンと夏時間
- CLI と外部ライブラリ
- `shifts.csv` の修正

### Data sources
- 引数 `path` で指定する CSV。サンプルは `shifts.csv` です。
- 作業ディレクトリの外は参照しません。

### Constraints
- Python 3 の標準ライブラリだけを使う。
- シグネチャは `monthly_work_hours(path)` に固定し、戻り値は `dict[str, float]` にする。
- 計算は整数の分で行い、最後に時間（float）に変換する。
- 作業ディレクトリの外は読み書きしない。入力ファイルは変更しない。

### Definition of Done（検証できる条件）
1. `from solution import monthly_work_hours` が成功する。
2. `monthly_work_hours("shifts.csv") == {"E001": 21.25, "E002": 13.0, "E003": 8.25}` になる（許容誤差 1e-9）。
   - E001 = 8.0 (9h−1h) + 5.75 (5:50 を切り捨て) + 7.5 (有給)
   - E002 = 7.0 (夜勤 8h−1h) + 6.0 (ちょうど6h なので控除なし)
   - E003 = 8.25 (9:15−1h)
3. 戻り値のキーはすべて `str`、値はすべて `float` である。
4. 日付をまたぐ勤務 22:00→06:00 が 7.0h（8h−1h）になる。
5. `paid_leave` が 1行あたり 7.5h になり、有給だけの従業員も出力に含まれる。
6. 休憩控除の境界: ちょうど6:00 → 6.0、6:01 → 5.0（5:01 を切り捨て）、6:15 → 5.25。
7. 15分の切り捨て: 5:50 → 5.75、5:59 → 5.75、0:14 → 0.0、0:15 → 0.25。
8. ヘッダ行だけの CSV と空ファイルが `{}` を返す。
9. 未知の type、work 行の時刻欠落、時刻の書式エラー（`25:00`、`9-00`、`12:60`）、start == end、日付の書式エラー、必須列の欠落のどれでも `ValueError` になる。
10. BOM 付き UTF-8、LF 改行、CRLF 改行のどれでも同じ結果になる。
11. 上の 1〜10 を `test_solution.py`（unittest）に書き、`python -m unittest -v test_solution` がすべて成功する。
