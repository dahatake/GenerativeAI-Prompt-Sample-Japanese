## 1. 調査結果

作業ディレクトリ内のファイル: `shifts.csv`（224 bytes）、`timing.txt`（計測用）。`solution.py` とテストはまだありません。

### 確認できた事実（`shifts.csv` より）
- ヘッダ: `employee,date,type,start,end`（6 行のデータ）
- `employee` は `E001` 形式の ID。登場するのは E001 / E002 / E003。
- `date` は `YYYY-MM-DD` 形式。全行が 2026-10（1 か月分だけ）。
- `type` は `work` と `paid_leave` の 2 種類。
- `paid_leave` の行は `start` / `end` が空（`E001,2026-10-03,paid_leave,,`）。
- `start` / `end` は `HH:MM` 形式で、分単位の端数があります（`14:50`, `08:30`, `17:45`）。
- 日をまたぐ勤務があります: `E002,2026-10-01,work,22:00,06:00`（end < start）。
- 休憩の列はありません。
- 改行コードが混在しています。最終行だけ CRLF で、ほかは LF です。BOM はありません。
- 同じ従業員・同じ日付の重複行はありません。

### 仮定（確定: すべて採用）
- A1. 文字コードは UTF-8 とします（BOM があっても読めるよう `utf-8-sig` で読みます）。改行コードの混在は `csv` モジュールで吸収します。
- A2. 戻り値は丸めない float です（例: 5時間50分 → 5.8333…）。テストは `pytest.approx` などの許容誤差で比較します。
- A3. 時刻は 1 日の範囲内（00:00〜23:59）で、1 シフトは 24 時間未満とします。
- A4. 「月間」は CSV に入っている対象月の合計を指し、ファイルは 1 か月分だけを含むものとします（Q3 で確定させます）。
- A5. 外部ライブラリは使わず、標準ライブラリ（`csv`, `datetime`）だけで実装します。
- A6. 労働時間が 0 の従業員（例: その月が有給休暇だけの人）も、キーとして `0.0` で返します（Q2 と連動）。

### 不足情報

- `paid_leave`（ほかの休暇種別も含む）を労働時間に数えるかどうか
- 日をまたぐ勤務の扱いと、複数月を含む CSV が来たときの扱い
- 想定外の行（未知の `type`、`work` なのに時刻が空、不正な時刻）をエラーにするか、スキップするか

## 2. 質問（外れたときの手戻りが大きいもの 3 問）

### Q1. 休憩時間の控除
- (a) 控除しない。`end - start` をそのまま労働時間にする ← **推奨（既定案）**。休憩の列がないためです。
- (b) 労基法の最低基準で自動控除する。6 時間を超えたら 45 分、8 時間を超えたら 60 分。
- (c) 固定時間（例: 1 時間）を一律で控除する。

影響（サンプル E001）: (a) 14.8333h / (b) 13.8333h。

### Q2. `paid_leave` の扱い
- (a) 労働時間に数えない。ただし従業員キーは `0.0` 以上で残す ← **推奨（既定案）**
- (b) 所定労働時間（例: 8h）として加算する
- (c) 数えず、`work` の行がない従業員はキー自体を返さない

### Q3. 日をまたぐ勤務と月の境界
- (a) `end <= start` なら翌日の終了とみなし、時間はすべて開始日の月に計上する。ファイルは 1 か月分だけとし、複数月が混ざっていたら `ValueError` にする ← **推奨（既定案）**
- (b) (a) と同じ計上方法で、複数月が混ざっていても全行を合算する（月で区別しない）
- (c) 戻り値を `{(従業員ID, "YYYY-MM"): 時間}` に変えるか、`month` 引数を追加する。シグネチャまたは戻り値の型が変わります。

## 3. Task Contract（確定: 推奨既定案 Q1-a / Q2-a / Q3-a を採用）

### Outcome
`solution.py` に `monthly_work_hours(path) -> dict[str, float]` を実装します。CSV から、従業員ごとの対象月の労働時間（時間単位の float）を返します。

### Scope
- `solution.py` を新規作成し、`monthly_work_hours(path)` を実装する
- CSV の読み込み（UTF-8、BOM 可、改行混在可）
- `type == "work"` の行だけを `end - start` で計算する（Q1-a）
- 日をまたぐ勤務は +24h して開始日の月に計上する（Q3-a）
- `paid_leave` は 0 時間として数え、従業員キーは返す（Q2-a）
- 異常な入力では例外を出す: 必須列の欠落、`work` 行の時刻が空または不正、複数月の混在（`ValueError`）
- 上記の検証用テスト（`test_solution.py` など）を作成する

### Out of scope
- 休憩の自動控除、残業・深夜・休日の区分、割増の計算
- 丸めや端数処理（15 分単位など）
- 複数ファイルの結合、DB 連携、CLI、出力の整形
- タイムゾーンや夏時間の考慮

### Data sources
- 入力: 引数 `path` で渡される CSV（列 `employee,date,type,start,end`）
- 参照用サンプル: 作業ディレクトリの `shifts.csv`
