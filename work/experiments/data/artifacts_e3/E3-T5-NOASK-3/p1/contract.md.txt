## 2. 質問（最大3問・手戻りが大きいもののみ）

### Q1. 日平均出荷（需要）の算出方法は？
C400 は 10-11 以降出荷ゼロのため、この選択で C400 の発注有無が変わります（today=2026-11-10 の例）。

| 選択肢 | 内容 | C400 の結果例 |
|---|---|---|
| **(a) 推奨** | `today` の前日までの**直近30暦日**の出荷合計 ÷ 30（出荷ゼロ日も分母に含む、`today` 当日以降は除外） | 日平均 0 → 発注なし |
| (b) | 出荷履歴の**全期間**（最初の出荷日〜today前日）の合計 ÷ 暦日数 | 日平均 1.25 → 発注 20 |
| (c) | 直近 N 日（N を指定: 7 / 14 / 28 など）、他は (a) と同じ | N による |

### Q2. 発注トリガーと発注数の式は？

| 選択肢 | 内容 |
|---|---|
| **(a) 推奨** | `発注点 ROP = 日平均 × lead_time_days + safety_stock`。`stock + on_order < ROP` のとき発注。`qty = ceil((ROP − (stock + on_order)) / lot) × lot` |
| (b) | (a) と同じだがトリガーを `<=`（在庫ポジション＝発注点でも発注。この場合不足0のため最低 1 lot 発注） |
| (c) | 目標在庫補充型: トリガーは (a) と同じ、`qty = ceil((ROP + 日平均 × lead_time_days − ポジション) / lot) × lot` など別の目標水準（目標水準を指定してください） |

### Q3. 例外・境界の扱い（まとめて確認）

| 項目 | **推奨既定** | 代替 |
|---|---|---|
| 廃番 (`discontinued=true`) | 常に除外 | 在庫が安全在庫を割ったら発注 |
| 日平均の端数 | 小数のまま計算し、最後に lot 切上げ | 日平均を先に切上げ整数化 |
| `today` 当日以降の出荷行 | 需要計算から除外 | 含める |
| 出力 | `qty > 0` のみ、`sku` 昇順 | inventory の行順 / qty 0 も含める |
