# Task Contract: `monthly_work_hours(path)`（承認済み・Execution Mode）

更新日: 2026-11-25。`answers.md` の回答を反映した。Q1〜Q3 にはすべて具体的な値が書かれていたので、追加の確認（followup.md）は作成していない。

## 1. 確認できた事実

- 作業ディレクトリにあった入力は `shifts.csv` だけ。UTF-8（BOMなし）、改行は LF で、列は `employee,date,type,start,end`。
- `type` には `work` と `paid_leave` がある。`paid_leave` の行は `start` / `end` が空。
- 休憩の列はない。日付をまたぐ勤務（22:00–06:00）と、15 分単位で割り切れない勤務（09:00–14:50）がある。
- データはすべて 2026-10 のもの。実行環境は Python 3.12.10。

## 2. 確定した仕様（answers.md の回答）

- **Q1 休憩控除**: 1 シフトの拘束時間が **6 時間（360 分）を超える場合は、一律で 60 分を控除**する。ちょうど 6 時間なら控除しない。
- **Q2 paid_leave**: 1 行につき **7.5 時間（450 分）** を計上する。
- **Q3 丸め**: **シフトごと**に、休憩控除後の実労働時間を **15 分単位で切り捨て**てから合計する。
- **A1**: `end < start` の場合は、翌日の `end` に終了した勤務として扱う。

## 3. 採用した仮定（A2〜A8 は「推奨案で進める」との回答）

- A2: 日付をまたぐ勤務は、全時間を開始日（`date`）の勤務として数える。
- A3: ファイル内の全行を合計する。月でフィルタしたり分割したりはしない。
- A4: `work` と `paid_leave` 以外の `type` は 0 時間とする。その従業員もキーとして返す。
- A5: `start == end` の `work` 行は 0 時間とする。
- A6: 読み込みは `utf-8-sig`。列はヘッダー名で参照し、`employee` は前後の空白を除いた文字列をキーにする。
- A7: `work` 行の `start` / `end` が空、または `HH:MM` として解釈できない場合は `ValueError` を送出する。`employee` が空の場合も `ValueError` とする。
- A8: 標準ライブラリだけを使う。
- 実装上の補足: 計算は整数の分で行い、最後に 60 で割って float を返す（浮動小数の誤差を避けるため）。`paid_leave` 行に `start` / `end` が入っていても無視する。

## 4. Task Contract

### Outcome
`solution.py` の `monthly_work_hours(path) -> dict[str, float]` が、勤怠 CSV から従業員 ID ごとの月間労働時間（時間）を返す。

### Scope
- `shifts.csv` 形式の CSV を読み込み、`work` 行を計算する。計算の順序は「拘束時間 → 6 時間を超えていれば 60 分控除 → 15 分単位で切り捨て」。
- 日付をまたぐ勤務に対応する。
- `paid_leave` は 7.5 時間として計上する。
- 不正な行では `ValueError` を送出する。

### Out of scope
- 月によるフィルタや月ごとの分割。
- 残業・深夜・休日の区分や割増、給与計算。
- 勤務の重複の検出。
- CLI、ファイル出力、外部ライブラリ。

### Data sources
- `path` で指定する CSV（サンプルは `shifts.csv`）。

### Constraints
- Python 3.12、標準ライブラリのみ。作業ディレクトリの外にあるファイルは読み書きしない。入力ファイルは変更しない。

### Definition of Done（検証できる条件）
1. `from solution import monthly_work_hours` が成功する。
2. `monthly_work_hours("shifts.csv") == {"E001": 21.25, "E002": 13.0, "E003": 8.25}`（各値は誤差 1e-9 以内）。
   - E001: 9h→8.0 + 5h50→5.75 + 有給 7.5 = 21.25
   - E002: 8h→7.0 + 6h→6.0 = 13.0
   - E003: 9h15→8h15 = 8.25
3. 戻り値の型が `dict` で、キーは `str`、値は `float`。
4. 日付をまたぐ勤務 22:00–06:00 が 7.0h になる（拘束 8h から 60 分を控除）。
5. `paid_leave` が 1 行につき 7.5h として計上される。有給だけの従業員もキーとして返る。
6. `work` 行の start / end が空、または形式が不正なとき `ValueError` が送出される。
7. BOM 付きの UTF-8 CSV でも同じ結果になる。
8. 休憩控除の境界: 6:00 → 6.0、6:01 → 5.0、7:00 → 6.0、7:15 → 6.25。
9. 15 分単位の切り捨てはシフトごとに行われる（5h50 + 5h44 → 5.75 + 5.5 = 11.25）。
