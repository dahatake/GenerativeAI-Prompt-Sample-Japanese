# 追加確認（1 件のみ）

answers.md の回答で、ほとんどの値が決まりました。ただし **Q2（税抜への換算）の丸め方** だけは具体的な値がなく、実装に必要なため確認させてください。

## 確認が必要な理由
- 回答は「税込額 ÷ 1.1 の整数」でしたが、**割り切れない場合の丸め方** と **丸める単位（行ごとか月合計か）** が決まっていません。
- 浮動小数点の `÷ 1.1` は使えません。たとえば `3300 / 1.1` は `2999.9999999999995` になり、`int()` で `2999` に化けます。そのため、整数演算（`× 10 ÷ 11`）で計算します。
- 現在の `sales.csv` は全件 11 で割り切れるので、どの案でも結果は同じです。
  - 結果（JST 基準、cancelled 除外、0 埋め）: `{"2026-01": 15000, "2026-02": 10000, "2026-03": 0, "2026-04": 17000, "2026-05": 7000}`
  - 割り切れない金額（例: 1000 円）が入ったときに、結果が変わります。

## 質問: 税抜額は、どの単位でどう丸めますか？
- **(a) 推奨: 行ごとに 0 方向へ切り捨てる。** `税抜 = sign(x) × (|x| × 10 // 11)` を行ごとに計算してから月で合計します（例: 1000 → 909、-1000 → -909）。
- (b) 行ごとに四捨五入する（0.5 は 0 から遠い方向へ）。例: 1000 → 909、1006 → 915（914.545… → 915）。
- (c) 月の税込合計に対して、0 方向へ切り捨てる。
- (d) 月の税込合計に対して、四捨五入する（0.5 は 0 から遠い方向へ）。
- どれにも当てはまらない場合は、**丸め方（切り捨て・四捨五入・切り上げ、負数の扱い）と単位（行ごと・月合計）を具体的に** 指定してください。

- Q3: `completed` だけを集計し、負の金額は差し引きます。
