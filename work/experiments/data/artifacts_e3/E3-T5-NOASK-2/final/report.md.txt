## 採用した仮定・決定の一覧
1. **発注点（Q1=a）:** ROP = 日平均需要 × lead_time_days + safety_stock とします。
2. **在庫ポジション（Q1=a）:** stock + on_order とし、発注残を含めます。
3. **発注判定（Q1=a）:** 在庫ポジション <= ROP のときに発注します。等しい場合も発注します。
4. **発注数（Q1=a）:** `max(1, ceil((ROP − ポジション) / lot)) × lot` です。不足が 0 のときも最低 1 lot を発注します。
5. **集計期間（Q2=a）:** 需要は `today-28 <= date < today` の出荷合計を 28 で割った値です。暦日で数え、出荷のない日は 0 として平均に含めます。
6. **廃番品（Q3=a）:** discontinued=true の品目は常に発注しません。
7. **`today` の型（A1）:** `"YYYY-MM-DD"` 文字列、`date`、`datetime` を受け付けます。
8. **当日以降の出荷（A2）:** `today` 当日以降の出荷は需要に含めません。
9. **戻り値（A4・A5）:** qty=0 の品目は戻り値に含めません。並びは sku 昇順で、各要素は `{"sku", "qty"}` のみです。
10. **ライブラリ（A6）:** 標準ライブラリのみを使います。ROP は `Fraction` で厳密に計算し、境界判定で浮動小数誤差が出ないようにしています。
11. **出荷履歴（A7）:** inventory にない SKU の出荷は無視します。出荷履歴のない SKU は需要 0 とします。
12. **文字コード（A8）:** CSV は `utf-8-sig` で読み込むため、BOM の有無に関係なく読めます。
13. **入力検証:** `discontinued` は true/false/1/0/yes/no/空文字を受け付け、それ以外は ValueError です。lot <= 0 も ValueError です。
