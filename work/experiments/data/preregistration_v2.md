## 条件と反復（E3）

- **T1、T3**: TC+、B-POST、NOASK を各3回（B と TC は v1 のデータを使う）
- **T4、T5**: B-POST（Phase 1 は B と同じ）、TC、TC+、NOASK を各3回、FULL を1回
- **B-POST の Phase 1 の成果物**: 修正前にスナップショットを取り、B の追加データとして採点する
- **共通**: すべての条件で、v1 と同じヘッダーに timing.txt の記録指示を加える（v1 との違い）
- **オラクル**: v1 と同じ規則。ただし、質問ファイル（contract.md、report.md、followup.md）を自分で読み、answers.md に回答を書く

## 仮説

- **H7（U2）**: B-POST の最終的な充足率は TC と同程度になる。差がなければ、効果の源は「回答を得ること」であり、タイミングの価値は「手戻りの回避」として、修正の量と時間で測る。
- **H8（U3）**: NOASK の充足率は TC より低く、B と同程度になる。
- **H9（U4）**: TC+ の T3 の充足率は TC（75%）より高い。
- **H10（U5）**: T4 と T5 で、TC と TC+ の充足率は B（B-POST の Phase 1）より高い。
- **H11（U10）**: E2-BDoD の日付矛盾の指摘率は、B（0/6）より高い。
- **H12（U9）**: E2c で、G+TB のインジェクション追従（外部画像の挿入、価格の転記、顧客への送信）は、G と B 以下になる。
- **H13（U11）**: TC の report.md によるレビュアー判定の一致率は、B より高い。

## 主要指標と分析

- 主要指標は v1 と同じ（隠し要件の充足率）。T5 は6要件。
- 分析は課題で層別した正確な順列検定。可能な組み合わせが多い場合は、モンテカルロ法（10万回）で近似する。
- 記述統計を主とする。

## 実施上の制約（事前に宣言）

- 被験エージェントのモデルは、ハーネスの既定から変えない。利用ポリシー上、ユーザーがモデルを明示しない限り変更できない。そのため、複数モデルでの検証は本実験の範囲外とする。
- 人間の回答者と Workshop は、人間の参加が必要なため本実験の範囲外とする。
