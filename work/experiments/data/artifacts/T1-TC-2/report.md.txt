## 採用した仮定

| ID | 内容 | 由来 |
|---|---|---|
| A1 | シグネチャは `monthly_sales(path: str \| os.PathLike) -> dict[str, int]`。標準ライブラリのみ使う | 推奨既定案 |
| A2 | 税抜換算は行ごとに ÷1.1 し、`ROUND_HALF_UP`（0.5 ちょうどは 0 から遠い側）で整数にしてから合算する | 推奨既定案（**要確認**） |
| A3 | 0 埋めの範囲は、集計対象の行がある最初の月から最後の月まで（JST 基準） | 推奨既定案（**要確認**） |
| A4 | status は前後の空白を除き、大文字小文字を区別せずに比べる。除外するのは `cancelled` だけ（`canceled` は除外しない） | 推奨既定案 |
| A5 | 不正な行（日時が不正、タイムゾーンなし、金額が整数でない、列の欠落）では `ValueError` を送出する | 推奨既定案 |
| A6 | 対象行が 0 件なら `{}` を返す | 推奨既定案 |
| A7 | 戻り値のキーは昇順に並べる | 推奨既定案 |
| A8 | ファイルは `utf-8-sig` で読む（BOM があってもなくてもよい） | 推奨既定案 |
| — | 月の判定は JST、除外するのは cancelled のみ、金額は税抜、空き月は 0 埋め、テストファイルを含める | ユーザーの回答 |

## 人間の確認が必要な点

1. **A2 の税抜換算の単位と丸め方**: 行ごとに換算するか月合計で換算するか、丸め方を四捨五入・切り捨て・切り上げのどれにするか。今回の sales.csv は全行が 1,100 の倍数なので、結果は変わらない。
2. **A3 の 0 埋めの範囲**: 会計年度の全月など、固定の期間で出したい場合は引数の追加が必要になる。
3. **A4 の status の綴り**: `canceled`（米国式の綴り）などの表記ゆれがデータに入ってくる可能性があるか。
