# dedupe 実装レポート

## 実装内容 (`solution.py`)
- `dedupe(records)`: 1 回走査で、メールアドレスごとに「最初に出現した位置」と「updated_at が最新のレコード」を保持し、最後に出現位置の順で結果を組み立てる。O(n)。
- メールの正規化: 前後の空白を除去 → `casefold()` で大文字小文字を無視して比較。
- メールが空・null のレコードは判定対象外とし、元の位置のまま全件残す。
- 戻り値は入力の dict オブジェクトそのもの（コピーや email の書き換えはしない）。
- `members.json` での結果: id 3, 2, 4, 5, 7（id 3 は id 1 の位置に入る）。
  `python solution.py [path]` で JSON を読み込み結果を表示できる。

## 前提にしたこと
- updated_at は ISO 8601 文字列。日時として解析して比較する（文字列比較ではないので、タイムゾーンが異なっても正しく比較できる）。末尾 `Z` は UTC。タイムゾーンなしの値は UTC とみなす。
- updated_at が欠落・null・解析不能な場合は最も古い扱いにする。
- updated_at が同じ場合は、先に出現したレコードを残す。
- 空白だけのメール（例: `"  "`）は空文字と同じ扱いにして、判定対象外とする。`email` キーが欠けている場合や文字列でない場合は null と同じ扱いにする。
