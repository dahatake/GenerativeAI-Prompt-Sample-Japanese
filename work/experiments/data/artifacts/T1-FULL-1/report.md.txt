# monthly_sales 実装レポート

## 実装内容
- `solution.py` の `monthly_sales(path)` が `{"YYYY-MM": 税抜金額(int)}` を返します。
- `status` が `cancelled` の行は除外します（前後の空白・大文字小文字は無視）。
- `ordered_at`（UTC）を JST（UTC+9）に変換してから月を判定します。
  - 例: `A-1004 2026-01-31T16:20Z` → JST 2/1 なので 2月、`A-1010 2026-04-30T15:30Z` → JST 5/1 なので 5月。
- 月ごとに税込額を合計し、`税込合計 / 1.1` を `Decimal` で計算して整数化します（float だと `11000 / 1.1 = 9999.99…` になる誤差を回避）。
- 最初の月から最後の月まで、注文がない月は 0 で埋めます（例: 2026-03）。

sales.csv での結果:
`{'2026-01': 15000, '2026-02': 10000, '2026-03': 0, '2026-04': 17000, '2026-05': 7000}`

## 前提にしたこと（要確認）
- **税抜換算のタイミング**: 注文ごとではなく、月合計（税込）に対して 1.1 で割っています。
- **端数処理**: 割り切れない場合は 0 方向への切り捨て。今回のデータはすべて 11 の倍数なので端数は出ません。
- **マイナス金額**（`A-1006 -1100`、返金・値引きと推測）: そのまま売上から差し引いています。
- **月の範囲**: キャンセルを除いた注文の最初の月から最後の月までです。キャンセル注文だけの月は範囲の決定に使いません。対象注文が 0 件なら `{}` を返します。
- タイムゾーン表記のない日時は UTC とみなします。CSV は UTF-8（BOM 付きも可）とみなします。
