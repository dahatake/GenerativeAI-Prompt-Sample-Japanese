# Task Contract: validate_invoice_id(value) -> bool

## 1. 調査結果

### 確認できた事実
- 着手時の作業ディレクトリには `samples.txt` しかなかった（`solution.py`、テスト、仕様書、README、依存定義はなし）。
- `samples.txt`（UTF-8・BOMなし・CRLF、113 bytes）の内容:
  - 1行目は見出し「最近発行された請求書番号の例:」
  - `INV-202601-0001` / `INV-202601-0002` / `INV-202512-0347` / `INV-202603-1200`
- 4例とも `INV-` + 数字6桁 + `-` + 数字4桁（全15文字、ASCII、大文字）の形をしている。
- 6桁部分は `YYYYMM` と読める（2025-12, 2026-01, 2026-03）。
- 不正な番号の例はない。番号体系の公式仕様も見当たらない。
- 実行環境は Python 3.12.10。

### 仮定（回答と既定案で確定したもの）
- A1. 形式は `INV-YYYYMM-NNNN`（固定長15文字、ASCII の大文字・数字だけ）。
- A2. 6桁部分は発行年月 `YYYYMM`、4桁部分は月内の連番（ゼロ埋め4桁）。
- A3. 「正しい」は形式上・日付上の妥当性を指し、実在確認は含まない。
- A4. 年の下限は **2000**（Q1(c) で範囲を指定されなかったため、提示した例を既定値として採用）。上限は「未来の年月は不可」で決まる。
- A5. 「未来」は **基準日（既定は呼び出し時の日本時間 JST = UTC+9 の現在日付）の年月より後**を指す。基準日と同じ月は有効とする。
- A6. 決定的にテストできるよう、キーワード専用のオプション引数 `today: datetime.date | None = None` を追加する。`validate_invoice_id(value)` という呼び出し方は変わらない。
- A7. Python 3.8 以上、標準ライブラリのみ。
- A8. 検証用テストは、ユーザーの指示に従い `test_solution.py`（unittest）として作業ディレクトリに残す。

## 3. Task Contract

### Outcome
`solution.py` に `validate_invoice_id(value, *, today=None) -> bool` を実装する。請求書番号が形式・日付ともに正しければ `True`、それ以外は `False` を返す。

### Scope
次の条件をすべて満たすときだけ `True` を返す。
1. `value` が `str` である（それ以外は `False`）。
2. 全体が `INV-[0-9]{4}[0-9]{2}-[0-9]{4}` に一致する（`re.fullmatch`。全角数字と末尾の改行は不可）。
3. 月が `01`〜`12`。
4. 年が 2000 以上。
5. `(年, 月)` が基準日の `(年, 月)` 以下（未来の年月は不可）。
6. 連番が `0001`〜`9999`。

成果物は `solution.py`（実装）と `test_solution.py`（検証テスト）。

### Out of scope
- 実在確認・重複チェック・DB/API 連携。
- 入力を整えること（空白除去、大文字化、全角→半角）。
- `samples.txt` の変更、外部ライブラリの導入。

### Data sources
- `samples.txt`（正例4件）。
- 本契約の Q1〜Q3 の回答と既定案（A1〜A8）。

### Constraints
- Python 3 標準ライブラリのみ（`re`, `datetime`）。
- 戻り値は常に `bool`。例外は送出しない。
- 現在日時に依存するのは「未来の年月」判定だけ。`today` 引数を渡せば結果は決定的になる。
- 作業ディレクトリ外のファイルは読まない・書かない。

### Definition of Done（検証可能な条件）
- **DoD1** `from solution import validate_invoice_id` が成功する。
- **DoD2** `samples.txt` の4件がすべて `True`（`today=2026-11-25` の場合と、`today` 省略時の両方）。
- **DoD3** 形式・入力の不正がすべて `False`:
  `""`, `"inv-202601-0001"`, `" INV-202601-0001"`, `"INV-202601-0001 "`, `"INV-202601-0001\n"`,
  `"INV-20261-0001"`, `"INV-202601-00001"`, `"INV202601-0001"`, `"ABC-202601-0001"`,
  `"INV-２０２６０１-0001"`（全角数字）, `"ＩＮＶ-202601-0001"`（全角英字）, `None`, `202601`, `b"INV-202601-0001"`。
- **DoD4** 値の範囲外がすべて `False`: 月 `13`・`00`、連番 `0000`、年 `1999`。
- **DoD5** 未来判定（`today=2026-11-25`）: `INV-202611-0001` は `True`（当月）、`INV-202612-0001` と `INV-202701-0001` は `False`。
- **DoD6** 境界の `True`: `INV-200001-0001`（年の下限）、`INV-202601-9999`（連番の上限）、`INV-202512-0001`（12月）。
- **DoD7** `today` 省略時は JST の現在日付を基準にする。例: `INV-209912-0001` は `False`。現在時刻を固定した場合、UTC 2026-11-30 15:00（JST 12-01 00:00）では `INV-202612-0001` が `True` になる。
- **DoD8** 上の全ケースで戻り値が `bool` 型。
- **DoD9** `python -m unittest -v test_solution` が全件成功して終了する。
