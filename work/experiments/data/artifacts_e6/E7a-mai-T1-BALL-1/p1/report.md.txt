# 実装内容

- `solution.py` に `monthly_sales(path)` を実装した。
- CSV を読み、完了済み売上を `ordered_at` の年月ごとに集計し、`{"YYYY-MM": 金額(int)}` の辞書を返す。
- 月は辞書で昇順に並べる。

# 確認事項（前提）

1. 対象の売上は `status` が（空白や大小文字の違いを除いて）`completed` の行のみとする。
2. `cancelled` を含むそれ以外のステータスは集計対象外とする。
3. 負数の金額（例: 返金）は有効な売上調整額として合計に加算する。
4. CSV の列名は `ordered_at`、`amount_incl_tax`、`status` を使用する。
5. 必須列が欠けている場合は `ValueError` を発生させる。
6. `ordered_at` は `YYYY-MM-DD` で始まり、その後に `T` または空白が続く ISO 形式の日付/日時、または日付のみを想定する。
7. 年月キーは `ordered_at` の値に含まれる暦年月をそのまま使用し、タイムゾーン変換やローカル時刻への変換は行わない。
8. 日付の年月・日が妥当な形式かを簡易確認し、月が 1～12 の範囲でなければ `ValueError`、日付形式が一致しなければ `ValueError` とする。
9. `amount_incl_tax` は整数文字列として `int()` に変換する。小数や通貨記号付き文字列は対象外とする。
10. 売上が存在しない月は辞書に作成しない。
11. CSV は UTF-8（BOM 付き UTF-8 を含む）で読み込む。
12. CSV の各行は既定のカンマ区切りとし、前後の空白は年月・ステータス・金額の解析時に除去する。
13. ステータス判定は大小文字を区別せず行う。
14. 同一CSV内の同月売上は合計し、各月の総額は Python の `int` とする。
