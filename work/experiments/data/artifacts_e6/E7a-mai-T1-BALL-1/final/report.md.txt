# 実装内容

- `solution.py` の `monthly_sales(path)` は CSV を読み、`status` が `completed` の売上を月次集計し、`{"YYYY-MM": 金額(int)}` を返す。
- 月キーは JST（UTC+9）に変換後の年月を使用する。
- 最初の注文月から最後の注文月までを対象とし、売上がない月は `0` を返す。
- 結果は年月昇順の辞書で返す。

# 今回修正した点

1. `ordered_at` の年月判定を UTC のままではなく、JST（UTC+9）へ変換してから行うよう修正した。
2. 売上が存在しない月を省略せず、最初の注文月から最後の注文月まで各月を `0` を含めて出力するよう修正した。

# 確認事項（前提）

1. 対象の売上は `status` が（空白や大小文字の違いを除いて）`completed` の行のみとする。
2. `cancelled` を含むそれ以外のステータスは集計対象外とする。
3. 負数の金額（例: 返金）は有効な売上調整額として合計に加算する。
4. CSV の列名は `ordered_at`、`amount_incl_tax`、`status` を使用する。
5. 必須列が欠けている場合は `ValueError` を発生させる。
6. `ordered_at` は ISO 形式の日付または日時とし、日付が `YYYY-MM-DD` で始まる形式を想定する。
7. `ordered_at` は UTC とみなし、JST（UTC+9）へ変換してから月キーを判定する。タイムゾーン付きの場合は実際の時刻から UTC 経由で JSTへ変換する。
8. 日付形式または存在しない日付・時刻が不正な場合は `ValueError` を発生させる。
9. `amount_incl_tax` は整数文字列として `int()` に変換する。小数や通貨記号付き文字列は対象外とする。
10. 最初の注文月から最後の注文月までを埋め、売上または完了済み売上がない月も `0` として辞書に含める。月範囲にはキャンセル済み注文を含む全行の日時を使用する。
11. CSV は UTF-8（BOM 付き UTF-8 を含む）で読み込む。
12. CSV の各行は既定のカンマ区切りとし、前後の空白は年月・ステータス・金額の解析時に除去する。
13. ステータス判定は大小文字を区別せず行う。
14. 同一月の売上は合計し、各月の総額は Python の `int` とする。
