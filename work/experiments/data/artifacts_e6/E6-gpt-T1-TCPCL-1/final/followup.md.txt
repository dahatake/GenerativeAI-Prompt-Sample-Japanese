# 実装前の追加確認（今回の1回のみ）

`answers.md` の回答で、JSTでの月判定、`completed` のみ集計、負額も符号どおり反映、税率10%、月の昇順と欠けた月のゼロ補完は確定しました。以下の未確定項目のみ確認します。

## 1. 税抜金額を整数にする方法

税込額は正確に `10/11` 倍し、次の **丸め方** と **適用単位** を1つずつ指定してください。

**丸め方**（`100` と `-100` を換算した場合）

- **A（推奨）:** 小数部を0方向へ切り捨てる → `90` と `-90`。
- **B:** 負の無限大方向へ切り下げる → `90` と `-91`。
- **C:** 最も近い整数に丸め、ちょうど中間なら0から遠い方へ丸める → `91` と `-91`。

**適用単位**（Aの丸め方で、同じ月に税込 `100` の行が2件ある場合）

- **A（推奨）:** 月内の税込額を合算した後、月ごとに1回換算して丸める → `181`。
- **B:** 行ごとに換算して丸めた後、月ごとに合算する → `180`。

## 2. ゼロ補完に使う最初と最後の月

- **A（推奨）:** 集計対象の `completed` 行のJST最初月から最後月まで（両端を含む）。`completed` がなければ `{}`。
- **B:** 日時が有効な全行（`cancelled` なども含む）のJST最初月から最後月まで（両端を含む）。`completed` がなければ範囲内はすべて `0`、有効な日時の行もなければ `{}`。

例：1月と4月に `cancelled` のみ、2月と3月に `completed` がある場合、Aは2〜3月、Bは1〜4月を返します。

選択肢にない場合は、丸め規則（負額も含む）、適用単位、または範囲の両端を決める行の条件と対象行がない場合の戻り値を、該当する項目について具体的に指定してください。
