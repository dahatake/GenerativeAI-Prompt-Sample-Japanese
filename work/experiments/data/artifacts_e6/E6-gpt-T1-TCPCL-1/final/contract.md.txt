# Task Contract（承認済み）

## 確認できた事実

- `sales.csv` の列は `order_id,ordered_at,amount_incl_tax,status`。10件中 `completed` は8件、`cancelled` は2件。`completed` に負額 `-1100` が1件ある。
- 日時は全件、秒精度のUTC表記（末尾 `Z`）。`A-1004` と `A-1010` はJSTへの換算で翌月になる。金額は全件が整数表記。
- `answers.md` で固定UTC+09:00、`completed` のみ、負額の反映、税率10%の税抜換算、月の昇順とゼロ補完が確定した。`answers2.md` は、月合計後に0方向へ切り捨て、補完の両端は `completed` 行で決める推奨案を採用した。

## Outcome

`solution.py` の `monthly_sales(path)` が指定CSVを読み、月別の税抜売上を `{"YYYY-MM": 金額(int)}` の辞書で返す。

## Scope・Out of scope

- **対象:** CSVの読み取りと検証、固定JSTでの月判定、対象行だけの税込月合計、税抜換算、内部の欠落月のゼロ補完。
- **対象外:** 入力ファイルの編集、集計結果ファイルの出力、税率の推定、通貨・数量・時間の換算、追加の値引き・控除、注文IDによる照合や重複排除。

## Data sources

- `sales.csv`: 集計・検証用データ。`ordered_at`、`amount_incl_tax`、`status` を使い、`order_id` は集計には使わない。
- `answers.md`、`answers2.md`: 採用する業務ルール。`followup.md`: `answers2.md` が参照する選択肢。外部データは参照しない。

## Constraints

- Python標準ライブラリのみを使い、指定ファイルを読み取り専用で開く。カンマ区切り・ヘッダー付きのUTF-8 CSV（BOM可）を受け付け、未使用列は無視する。
- 日時は `YYYY-MM-DDTHH:MM:SSZ` の実在するUTC日時。UTCとJSTの両方で年は `0001`〜`9999`、秒は `00`〜`59`。固定JST（UTC+09:00）の月初 `00:00:00` 以上、翌月月初未満で月を割り当てる。入力全期間を対象とする。
- `status` は大文字小文字を区別して `completed` と完全一致する行のみを集計する。負額を符号どおり含め、`0` も有効とする。金額はASCII数字の10進整数（先頭の `+` / `-` は任意）とし、小数・桁区切り・通貨記号は不可。業務上の上下限は設けない。
- 必須列は `ordered_at`、`amount_incl_tax`、`status`。必須列の欠落、空欄・空白のみの `status`、対象行の日時・金額の欠損や不正値は `ValueError`。対象外の行の日時・金額は検証しない。
- 月ごとに税込の整数値を先に合算し、正確に `10/11` 倍して小数部を0方向に切り捨てる。明細単位では丸めず、浮動小数点数は使わない。
- `completed` 行のJST最初月から最後月まで両端を含めて月の昇順に並べ、対象行がない月の値は `0`。対象行が一件もなければ `{}`。合計が `0` の対象月も残す。

## Definition of Done（検証条件）

1. `sales.csv` の戻り値が `{"2026-01": 15000, "2026-02": 10000, "2026-03": 0, "2026-04": 17000, "2026-05": 7000}` と一致する。反復順は記載どおり、値はすべて `int`。
2. JSTの月境界（例：`2026-01-31T14:59:59Z` は1月、`2026-01-31T15:00:00Z` は2月）と年境界で正しく振り分ける。入力が時系列順でなくても、出力は月の昇順。
3. 税抜換算は正負とも月合計後に一度だけ0方向へ丸める（たとえば同月2件の税込 `100` または `-100` は `181` または `-181`）。対象外の行は合計や範囲の両端に影響しない。対象行がある月の `0` や範囲内の空き月の `0` を残す。ヘッダーのみ・全行対象外の入力は `{}`。
4. 必須列の欠落、空欄・空白のみの `status`、対象行の日時・金額の欠損や不正値（例：存在しない日付、JST換算で対応年を超える日時、金額 `1.5`）で `ValueError` を送出し、部分結果を返さない。

## Evidence

- `A-1004` の `3300` はJSTの2月、`A-1010` の `7700` はJSTの5月。`A-1006` の `-1100` は2月の減額。`A-1003` と `A-1007` は除外し、3月を `0` で補完する。
- DoDの実行コマンド、出力、各条件の状態は `report.md` に記録する。
