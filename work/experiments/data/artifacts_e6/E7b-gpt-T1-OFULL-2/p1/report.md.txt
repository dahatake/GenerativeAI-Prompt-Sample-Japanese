# 月次売上集計

`solution.py` の `monthly_sales(path)` は、CSV の `status` が `completed` の行だけを対象に、税込金額 `amount_incl_tax` を月ごとに整数で合計し、`{"YYYY-MM": 金額}` の辞書を返します。負の金額はそのまま差し引きます。

入力はヘッダー付きの UTF-8 CSV（BOM 可）とし、`ordered_at` はタイムゾーン付きの ISO 8601 日時、金額は整数を前提とします。月の区切りは日本標準時（UTC+09:00）とし、対象行がない月は辞書に含めません（合計が 0 でも対象行があれば含めます）。
