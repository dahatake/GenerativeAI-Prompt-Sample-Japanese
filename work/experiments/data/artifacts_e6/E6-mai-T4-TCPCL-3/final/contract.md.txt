# Task Contract（承認済み・Execution Mode）

## Outcome
- `solution.py` の `monthly_work_hours(path)` は、勤怠CSVを読み、従業員ごとの労働時間を `{従業員ID: 労働時間（時間・float）}` のdictとして返す。

## Scope・Out of scope
### Scope
- CSVヘッダー `employee,date,type,start,end` を標準ライブラリで読む。
- CSV内の全行を集計対象期間として合算し、年月ごとの分割は行わない。
- `type == "work"` は開始時刻と終了時刻から実効果時間を計算する。
- 終了時刻が開始時刻より前なら翌日またぎの勤務として計算する。
- 各シフトの実労働時間（分）は15分単位で切り捨てる。
- `type == "paid_leave"` は所定労働時間7.5時間として計上する。
- 欠損・不正なwork行および未知typeはスキップする。
- タイムゾーンは使わず、ローカル時刻として扱う。
- 出力は従業員ごとの `{文字列: float}`、キー順序は先頭出現順を推奨するが保証しない。

### Out of scope
- 金額、税、税込／税抜、通貨、給与計算。
- 月ごとのネストした出力、データベース、画面、CLI。
- paid_leave以外の休暇種別の所定換算（未知typeはスキップ）。

## Data sources
- 作業ディレクトリ直下の `shifts.csv`。
- 確認ヘッダー: `employee,date,type,start,end`。
- サンプルはE001/E002/E003と、`work`/`paid_leave`を含む。
- サンプルには日付またぎ勤務とpaid_leaveの時刻欠損がある。

## Constraints
- 戻り値の値はfloat。
- 時刻は `HH:MM` の24時間表記。`00:00`は有効、`24:00`は無効としてスキップする。
- work行の開始時刻と終了時刻が同じ場合は0時間。
- work行の終了が開始より前なら翌日またぎとして計算する。
- 15分切り捨ては各シフトごとに適用する（合算後ではなく各シフトの実効果時間を切り捨てる）。
- CSV内の全行を合算し、従業員ごとに1つのfloatを返す。
- work行の従業員・開始時刻・終了時刻が欠損、または時刻形式が不正ならその行をスキップ。
- paid_leaveは従業員が空でなければ時刻欠損／不正時刻に関係なく7.5時間を加算。
- 欠損employeeを持つ行、未知typeを持つ行はスキップ。
- ファイルが存在しない場合は標準の `FileNotFoundError`、必須ヘッダー欠落は `ValueError` とする。

## Definition of Done（検証できる条件）
1. `solution.py` に `monthly_work_hours(path)` が存在する。
2. サンプルCSVに対し、切り捨て後の値を返す:
   - E001 = 22.25（9:00-18:00は9.0、9:00-14:50は5.75、paid_leaveは7.5）
   - E002 = 14.0（8.0 + 6.0）
   - E003 = 9.25（8:30-17:45の555分を15分単位で切り捨て、9.25）
3. paid_leaveは除外せず7.5時間として計上する。
4. 戻り値の各値はfloat。
5. 日付またぎの22:00-06:00は8.0時間。
6. 複数行を合算できる。
7. 欠損・空白・不正なwork行は推奨既定に従いスキップできる。
8. 境界として、開始=終了は0、通常勤務は正しく計算する。
