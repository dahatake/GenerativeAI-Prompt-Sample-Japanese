# 確認（1 回のみ）— 税抜金額の整数化

`answers.md` の指定どおり、税率は 10% とし、税抜額を `税込額 ÷ 1.1` で求めます。**どの単位で、どの方法で整数に丸めますか？** 負の金額も対象なので、丸め方によって結果が変わります。

- **丸める単位:** A（推奨）= 月ごとに税込額を合計し、税抜に換算してから月 1 回丸める。B = 注文行ごとに税抜に換算して丸め、その整数を月ごとに合計する。
- **丸め方:** 1（推奨）= 最も近い整数（ちょうど中間ならゼロから遠い方）。2 = ゼロ方向に小数部を捨てる。3 = 負の無限大方向に切り下げる。例えば税込 `2` と `-1` をそれぞれ税抜に換算して丸めると、1 は `2` と `-1`、2 は `1` と `0`、3 は `1` と `-1` になります。

推奨案は **A・1** です。`A・1` のように回答してください。選択肢にない場合は、丸める単位と、正額・負額の両方に適用する具体的な丸め規則を指定してください。
