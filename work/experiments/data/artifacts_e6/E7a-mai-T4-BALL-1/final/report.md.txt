# 実装内容

`solution.py` の `monthly_work_hours(path)` は、ヘッダー付きCSVを読み、従業員ごとの1か月分労働時間を集計して `{従業員ID: 労働時間（時間・float）}` を返します。

# 今回修正した点

1. `paid_leave` 行を集計対象外にせず、従業員ごとに所定労働時間7.5時間として加算するよう変更しました。
2. `end` が `start` より前の時刻だけを日付またぎとして扱い、終了時刻が開始時刻と同じ場合は0時間として計算するよう変更しました。
3. 休憩列を参照せず、拘束時間が6時間を超える各シフトから一律60分を控除するよう変更しました。拘束時間がちょうど6時間の場合は控除しません。
4. 各シフトの実労働時間を計算した後、15分単位で切り捨てるよう変更しました。切り捨て後のシフト時間を従業員ごとに合計します。
5. 有給休暇行は開始・終了時刻がなくても7.5時間を加算します。

# 確認事項（前提・既定値）

- 回答がある点は回答に従いました。
- 回答がない点は、従来の推奨案を維持しました。
- CSVはUTF-8（BOM付きUTF-8を含む）で、ヘッダー付きとします。
- 本CSVは対象月のデータとして扱い、ファイル内の全行を対象月の勤務として合計します。
- 従業員ID列は `employee_id`、`employee`、`employeeid`、`emp_id`、`staff_id`、`worker_id`、`従業員ID`、`従業員` 等から判定します。該当列がなければ `ValueError` とします。
- 開始・終了列は `start`/`end`、`start_time`/`end_time`、`clock_in`/`clock_out` 等から判定します。
- 勤務区分列がない場合は全行を勤務として扱います。
- 勤務区分列がある場合、`work`、`worked`、`working`、`shift`、`出勤`、`勤務` を勤務として集計し、`paid_leave` は7.5時間として集計します。
- `paid_leave` 以外の勤務でない区分は集計しません。従業員IDが登場した時点で結果には含めます。
- 開始・終了時刻は `HH:MM`、`HH:MM:SS`、ISO形式の日時を受け付けます。
- 終了時刻が開始時刻より前なら翌日に終了した勤務として24時間分の差を加算します。終了時刻と開始時刻が同じ場合は0時間です。
- 休憩列は使用しません。拘束時間が6時間を超える場合だけ、実労働時間から60分を差し引きます。
- 従業員IDが空欄の行は無視します。
- 開始・終了時刻が空欄または不正な勤務行は無視します。
- 各シフトの実労働時間を15分単位で切り捨て、その切り捨て結果を合計して `float` として返します。有給休暇の7.5時間は切り捨て対象外の固定値です。
