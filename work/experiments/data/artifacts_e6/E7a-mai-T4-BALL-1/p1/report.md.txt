# 実装内容

`solution.py` の `monthly_work_hours(path)` を実装した。CSVを読み、従業員ごとに勤務区分が稼働日の行だけの労働時間を合計し、`{従業員ID: 労働時間（時間・float）}` を返す。深夜勤務（終了時刻が開始時刻以前）は翌日の時刻として計算し、休憩分列があれば差し引く。

# 確認事項（前提・既定値）

- CSVはUTF-8（BOM付きUTF-8を含む）で、ヘッダー付きとする。
- 本CSVは対象月のデータであるため、ファイル内の全行を対象月の勤務として合計する（単一ファイルに複数月が混在する場合の月別分割はしない）。
- 従業員ID列は `employee_id`、`employee`、`employeeid`、`emp_id`、`staff_id`、`worker_id`、`従業員ID`、`従業員` 等から判定する。該当列がなければエラーにする。
- 開始・終了列は `start`/`end`、`start_time`/`end_time`、`clock_in`/`clock_out` 等から判定する。
- 勤務区分列がない場合は全行を勤務として扱う。勤務区分列がある場合は `work`、`worked`、`working`、`shift`、`出勤`、`勤務` のみ稼働として集計し、有給休暇等のその他区分は集計しない。
- 有給休暇など勤務でない行のみの従業員も、従業員IDが登場した時点で結果へ `0.0` として含める。
- 開始・終了時刻は `HH:MM` または `HH:MM:SS`、ISO形式の日時を受け付ける。
- 終了時刻が開始時刻以下なら夜間勤務として翌日にまたがるとみなし、24時間分を加算して計算する。
- 休憩列が存在し、数値（分）として読める場合は労働時間から休憩分を差し引く。休憩列名は `break_minutes`、`break_min`、`break`、`break_time`、`休憩`、`休憩分` を判定対象とする。数値でない休憩値や休憩列がない場合は差し引かない。
- 休憩を差し引いた結果が負の場合は0時間として扱う。
- 従業員IDが空欄の行、開始・終了時刻が空欄または不正な行は無視する。
- `HH:MM:SS` は秒まで計算し、合計結果は丸めずに `float` として返す。深夜や秒を含む時刻による浮動小数点誤差は四捨五入しない。
