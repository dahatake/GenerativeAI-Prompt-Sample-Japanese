# Task Contract 案：月次売上集計（確認前・実装なし）

## Outcome
合意後、`solution.py` に `monthly_sales(path)` を実装する。指定された CSV の税込売上を合意した暦月・対象条件で集計し、キーが `YYYY-MM`、値が Python の `int` の `dict` を返す。

## Scope・Out of scope
- **Scope:** CSV の読み込み、対象行の選別、集計用タイムゾーンへの変換、月次の整数合計、欠けた月の扱い。今回は仕様案の作成まで。
- **Out of scope:** 元 CSV の更新、通貨換算・税の再計算、注文の重複排除、CLI・グラフ等の別出力。

## Data sources
依頼文（関数名・戻り値）と、作業ディレクトリ内の `sales.csv`（観測した入力と計算例）。

### 確認できた事実
- CSV のヘッダーは `order_id,ordered_at,amount_incl_tax,status`。データは10行で、`completed` が8行、`cancelled` が2行。
- すべての日時は `YYYY-MM-DDTHH:MM:SSZ` の UTC 表記。A-1004 の `2026-01-31T16:20:00Z` は JST では2月1日、A-1010 の `2026-04-30T15:30:00Z` は JST では5月1日になる。
- 税込金額欄は全行が整数表記で、`completed` に `-1100`（A-1006）が1件ある。正の金額が入った `cancelled` が2件ある。3月の取引行はない。
- 調査開始時に `solution.py` やテストはなかった。CSV には通貨コードや業務上の集計ルールの記載がない。

## Constraints
この段階では `contract.md` と `timing.txt` のみ作成・変更する。作業ディレクトリ外のファイルは対象外。実装時は以下の「仮定」と合意した選択肢に従う。

1. **仕様確認の段階:** 本案に観測事実・仮定・不足情報と確認事項を記載する。実装や入力の変更はせず、開始・終了時刻を `timing.txt` に1行ずつ追記する。
2. **合意後の実装段階:** `solution.monthly_sales(path)` が指定ファイルを読み、`YYYY-MM` の文字列キーと `int` の値で、合意した例の辞書に完全一致する。キーの順序は問わない。
3. 境界例として A-1004 / A-1010 の月、A-1006 の寄与、取消2件の寄与、`2026-03` キーの有無を、選んだルール通りと確認する。採用対象行が0件（ヘッダーのみ、または選別後0件）なら `{}` を返す。採用行の合計が0の月はキーを残す。
4. 例えば必須列のない CSV、`2026-02-30T00:00:00Z` または `1.5` を含む行は、仮定どおり `ValueError` になる。月次集計の呼び出しで入力 CSV を変更しない。

## Open questions

### 不足情報（要確認）
月境界に用いるタイムゾーン、売上に算入する行、取引のない月を出力するかは、CSV の値だけでは確定できない。各問で選択肢のどれでもない場合は、括弧内の項目を具体的な値で回答してください。

1. **Q1：どのタイムゾーンの暦月で集計しますか？**（その他：IANA タイムゾーン名または固定 UTC オフセット）
   - **A（推奨）:** UTC（`+00:00`）。A-1004 は1月、A-1010 は4月。入力に明示されたタイムゾーンをそのまま使う。
   - **B:** JST（`Asia/Tokyo`、このデータでは UTC `+09:00`）。A-1004 は2月、A-1010 は5月。
2. **Q2：どの行を税込売上に算入しますか？**（その他：採用する `status` の値、負額・ゼロの扱い）
   - **A（推奨）:** `status == "completed"` のみ。税込金額は負額・ゼロを含め符号どおりに加算する。取消を除外しつつ、完了行に記録された減額を保持できる。
   - **B:** `status == "completed"` かつ `amount_incl_tax >= 0` のみ。負額とそれ以外のステータスは除外する。
   - **C:** `status` を問わず、全データ行の税込金額を負額・ゼロも含め符号どおりに加算する。取消行も含む。
3. **Q3：採用対象行がない月のキーはどうしますか？**（その他：補完する開始月・終了月を `YYYY-MM` で指定し、埋める値も指定）
   - **A（推奨）:** 採用対象行が1件以上ある月だけを返す。例：`2026-03` はキーなし。データのない月に数値を補わない。
   - **B:** 採用対象行の最初の月から最後の月までを両端込みで返し、途中の対象行がない月を `0` で埋める。例：`"2026-03": 0`。対象行が0件なら `{}`。

### 仮定（質問しない項目）
以下は、回答で変更の指定がなければ **この仮定で進めます**。
- `path` は文字列または `os.PathLike`。CSV は UTF-8（BOM ありも可）のヘッダー付きカンマ区切りとし、観測した4列を列名で参照する（列順は任意、追加列は無視）。Python 標準ライブラリのみ使用する。
- 日時は観測した `YYYY-MM-DDTHH:MM:SSZ` 形式の実在する UTC 日時のみ受け付ける。金額は符号付き10進整数（ASCII 数字、先頭の `+` / `-` は省略可）として入力と同じ単位で加算し、丸め・小数・桁区切り・単位変換は行わない。
- 1データ行を1件と数え、`order_id` による重複排除は行わない。空行は読み飛ばす。必須の列・値の欠落や不正な日時・金額は、行を黙って捨てず `ValueError` にする（集計対象外になる行も書式は検証する）。ファイルがない場合などの I/O 例外はそのまま伝える。
