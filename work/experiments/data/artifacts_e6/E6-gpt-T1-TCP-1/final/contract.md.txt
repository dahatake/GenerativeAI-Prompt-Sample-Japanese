# Task Contract：月次売上集計（承認済み）

## Outcome
`solution.py` の `monthly_sales(path)` は、指定された CSV から月ごとの税抜売上を計算し、キーが `YYYY-MM` の文字列、値が Python の `int` の辞書を返す。

## Scope・Out of scope
- **Scope:** CSV 読み込みと検証、UTC 日時の `Asia/Tokyo` への変換、完了注文の税込月合計、税抜換算・丸め、欠けた月のゼロ補完、テスト・結果報告。
- **Out of scope:** 元 CSV の更新、通貨換算、注文の重複排除、CLI・グラフ等の別出力。

## Data sources
- `sales.csv`: `order_id,ordered_at,amount_incl_tax,status` の4列、データ10行。`completed` が8行、`cancelled` が2行。A-1006 は完了行で税込 `-1100`。3月に取引行なし。
- `answers.md`: JST（Q1=B）、`completed` のみ・符号付き（Q2=A）、採用行の最初から最後の月までゼロ補完（Q3=B）、税込金額の税率10%。
- `followup.md` / `answers2.md`: 推奨の A・1 を採用。月内の税込金額を先に合計し、`× 10 ÷ 11` で換算して月に一度だけ最も近い整数へ丸める。ちょうど中間なら絶対値の大きい方。負額にも同じ規則を適用する。

## Constraints
- `path` は文字列または `os.PathLike`。CSV は UTF-8（BOM 可）・カンマ区切り・ヘッダー付き。必須の4列は列名で一意に参照し、列順は任意、追加列は無視する。
- 日時は `YYYY-MM-DDTHH:MM:SSZ` の実在する UTC 日時。金額は入力と同じ通貨単位の10進整数（ASCII 数字、先頭の `+` / `-` は省略可）。小数、桁区切り、通貨換算なし。税抜換算に浮動小数点数は使わない。
- 1データ行を1件と数え、重複排除はしない。空行は無視。`status` は `completed` と完全一致する行だけ採用し、負額とゼロはそのまま集計する。採用対象外の行も書式は検証する。
- CSV の構文不正、必須列・必須値の欠落、不正な日時・金額は `ValueError`。採用行の変換結果が4桁年に収まらない場合も `ValueError`。ファイルがない場合など、I/O 例外はそのまま伝える。
- 実装とテストは Python 標準ライブラリを使う。作業は指定ディレクトリ内で行い、実行段階の開始・終了時刻を `timing.txt` に1行ずつ追記する。

## Definition of Done
1. `monthly_sales(path)` は指定ファイルを読み、サンプルの辞書に完全一致する。キーは `YYYY-MM` の文字列、値は `int`、キー順は不問。
2. JST の月境界で集計し、完了行の負額を含めて取消行を除外する。A-1004 は2月、A-1010 は5月。取消のみの月も含め、採用対象の最初から最後の月までの空白月を `0` で補完し、範囲の外は補完しない。
3. 月の税込合計を `10/11` 倍してから一度だけ丸める。同月に税込 `6` が2行なら `11`、`-6` が2行なら `-11`。整数演算で精度を保つ。
4. ヘッダーのみ、または採用行が0件なら `{}` を返す。採用行の合計が0の月はキーを残す。
5. 必須列・必須値の欠落、不正日付（例：`2026-02-30T00:00:00Z`）、小数（例：`1.5`）などは `ValueError`。UTF-8 BOM、列順変更、追加列、重複行を規定どおり扱い、集計の呼び出しで入力 CSV を変更しない。

## Evidence
- `sales.csv` の完了行を JST 月別に集計した税込額は1月 `16500`、2月 `11000`、4月 `18700`、5月 `7700`。ゼロ補完と税抜換算後の期待値は `{"2026-01": 15000, "2026-02": 10000, "2026-03": 0, "2026-04": 17000, "2026-05": 7000}`。
- 実行証拠（コマンド、出力、各 DoD の結果）は `report.md` に記録する。

## Open questions
なし。`answers.md` の選択と `answers2.md` の推奨案 A・1 で確定した。明示的に変更されなかった入力・検証上の仮定は Constraints のとおり採用する。
