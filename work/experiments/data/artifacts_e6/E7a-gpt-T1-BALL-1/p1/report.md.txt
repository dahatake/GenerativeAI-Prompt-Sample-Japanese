# 月次売上集計

## 実装内容
`solution.py` の `monthly_sales(path)` は、指定された CSV を読み、`completed` の税込金額を注文日時の UTC 月ごとに整数で合計します。結果は `{"YYYY-MM": 金額}` の辞書です。同梱の `sales.csv` では `{"2026-01": 19800, "2026-02": 7700, "2026-04": 26400}` を確認しました。

## 確認事項（実装で置いた前提）
- 入力は UTF-8（BOM は任意）のカンマ区切り CSV で、見出し `ordered_at`、`amount_incl_tax`、`status` がある想定でよいか。列順は問わず、`order_id` など他の列は使用しません。
- 集計対象は `status` が大文字小文字・空白も含めて厳密に `completed` と一致する行だけでよいか。`cancelled`、空欄、未知のステータスなどは除外します。
- 売上月は `ordered_at` を UTC に換算して決めてよいか。日時は ISO 8601 形式で `Z` または UTC オフセットが必須です。日本時間で締める場合、サンプルの月末の一部の注文は翌月に入ります。
- 金額は `amount_incl_tax` を Python の `int` で10進整数として読み、元の単位のまま合計してよいか。負数は差し引き、小数の丸めや通貨換算は行いません。
- 1行を1件として扱い、同じ注文 ID が複数行にあっても重複排除しなくてよいか。
- 対象行のある月だけを年月順に返し、合計がゼロの月は残してよいか。対象行がなければ空の辞書を返します。
- 必須見出し・必須フィールドの欠落や、対象行の日付・金額の形式不備は、補正せずエラーとしてよいか。見出しだけの CSV は有効ですが、空ファイルはエラーです。対象外の行の日付・金額の形式は検証しません。
