# 月間労働時間の集計

`solution.py` の `monthly_work_hours(path)` は、CSVから従業員別に労働時間を分単位で合計し、時間に換算した `float` を返します。`shifts.csv` での集計結果は E001 が約 14.83 時間、E002 が 14.0 時間、E003 が 9.25 時間です（関数内では丸めません）。

## 確認事項（実装で採用した前提）

- 入力は UTF-8（BOM は任意）のカンマ区切り CSV。ヘッダーに `employee,date,type,start,end` が必要で、列順は任意、追加列は集計に使いません。ヘッダー名は完全一致とし、重複は認めません。データがないファイル（空ファイルまたは有効なヘッダーのみ）は `{}` を返します。
- `employee` は空でない文字列 ID とし、先頭のゼロと大文字・小文字を保持します。必須列の値の前後の空白は除きます。
- `date` は `YYYY-MM-DD` 形式の実在日付です。ファイル全体（有給休暇を含む）が同じ暦年・月に属する前提で、複数月を含む入力はエラーにします。日またぎの勤務は、月末でも全時間を行の `date`（勤務開始日）の月に計上します。
- `type` が `work` のときだけ勤務時間を計上します。`paid_leave` は実労働に含めず、開始・終了欄の値を無視します。有給休暇だけの従業員も `0.0` 時間で返します。それ以外の種別はエラーにします。
- `work` の開始・終了は24時間制の `HH:MM`（`00:00`～`23:59`）とします。終了が開始より早ければ翌日、同時刻なら勤務時間はゼロとします。タイムゾーンや夏時間は考慮しません。
- 打刻間の時間をそのまま計上し、CSVに休憩の情報がないため休憩は自動控除しません。重複・重なりのある勤務行も自動補正せず、各行を加算します。
- ヘッダー以降の完全な空行は無視し、列数の不一致や無効な項目がある行は読み飛ばさずエラーにします。ファイルが開けない場合もエラーになります。
