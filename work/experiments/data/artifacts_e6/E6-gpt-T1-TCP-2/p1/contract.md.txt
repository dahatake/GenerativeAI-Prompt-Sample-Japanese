# Task Contract 案：月次売上集計

## Outcome
後続の実装段階で `solution.py` に `monthly_sales(path)` を実装する。指定された CSV の税込金額を、合意したルールで暦月ごとに集計し、キーが `YYYY-MM`、値が `int` の辞書を返す。今回は契約案の作成までとし、実装しない。

## Scope・Out of scope
- 対象：`path` で指定された CSV の読み込み、注文日時の月への割り当て、集計対象行の選定、整数での加算、行のない月の扱い。
- 対象外：入力 CSV の更新、税額や為替の再計算、CLI・帳票の作成、今回のフェーズでの実装やテストファイルの作成。

## Data sources
### 確認できた事実
- 調査時、作業ディレクトリ内には `sales.csv` と、開始時刻を追記した `timing.txt` のみがあり、`solution.py` や既存テストはなかった。入力例は `sales.csv` のみ。
- `sales.csv` のヘッダーは `order_id,ordered_at,amount_incl_tax,status`。10 行すべての日時に UTC を表す `Z` があり、金額は整数表記。`completed` が 8 行、`cancelled` が 2 行で、`completed` の `A-1006` に `-1100` がある。
- `A-1004`（`2026-01-31T16:20:00Z`, `3300`）は UTC で 1 月、JST で 2 月。`A-1010`（`2026-04-30T15:30:00Z`, `7700`）は UTC で 4 月、JST で 5 月。3 月の入力行はない。

## Constraints
- 今回の読み書きは指定された作業ディレクトリ内に限る。作成・変更は `contract.md` と `timing.txt` のみ。開始・終了時に指定の Python コマンドの出力を `timing.txt` に 1 行ずつ追記する。
- 後続実装は Python 標準ライブラリのみとし、`path` が指すファイルを読み取り専用で扱う。金額は `amount_incl_tax` の記録単位のまま、換算・丸めなしで整数加算する。

## Definition of Done
- 今回：`contract.md` に確認済みの事実・仮定・不足情報と検証条件があり、`timing.txt` に開始・終了の 2 行が追記され、他のファイルは変更されていない。
- 後続実装（推奨案を採用した場合）：`monthly_sales('sales.csv') == {'2026-01': 16500, '2026-02': 11000, '2026-04': 18700, '2026-05': 7700}`。値はすべて `int`。選択が異なる場合は、その選択に合わせて期待値を更新する。
- 後続実装（境界条件）：ヘッダーだけなら `{}`。推奨案ではキャンセル行だけの場合も `{}`、集計対象行の合計が 0 の月はキーを残す。不正な日時・整数金額は例外として検証する。

## Evidence
- 入力の境界例は `A-1004` と `A-1010`、負額は `A-1006`、キャンセルは `A-1003`（`22000`）と `A-1007`（`4400`）。
- 読み取った行から、推奨案の合計を確認：1 月 `11000 + 5500`、2 月 `3300 + 8800 - 1100`、4 月 `16500 + 2200`、5 月 `7700`。これは入力から算出した期待値であり、実装の実行結果ではない。

## Open questions
### 不足情報（要確認）
1. **月を判定するタイムゾーンはどれですか？** A（推奨）：UTC から JST（固定 `UTC+09:00`）に変換してから年月を取る。B：変換せず UTC（`UTC+00:00`）の年月を取る。
2. **どの注文を売上に含めますか？** A（推奨）：`completed` のみ、負額も符号どおり加算。B：`completed` のみ、`amount_incl_tax < 0` の行は除外。C：`completed` と `cancelled` の両方、負額も符号どおり加算。D：`completed` と `cancelled` の両方、`amount_incl_tax < 0` の行は除外。
3. **集計対象行がない月はどう表しますか？** A（推奨）：キーを作らない。B：集計対象行の最初の月から最後の月まで（両端含む）の空き月を整数 `0` で埋める。集計対象行が 0 件ならどちらも `{}`。推奨の Q1・Q2 を採用すると、B では `2026-03: 0` を追加する。

各問、選択肢のどれでもない場合は、具体的な値・規則（タイムゾーン名または UTC オフセット、対象ステータスと負額の扱い、補完の開始月・終了月と値など）で回答してください。

### 仮定（質問しない点）
- この仮定で進めます：入力は UTF-8（先頭 BOM 可）のカンマ区切り CSV。列は名前で特定し、必要列は `ordered_at`、`amount_incl_tax`、`status`。日時は実在する日付の `YYYY-MM-DDTHH:MM:SSZ`、金額は符号付き可の十進整数とする。
- この仮定で進めます：完全な空行は無視し、必須列の欠落、不正な行・日時・金額、未定義の `status` は `ValueError`。読めないファイルの I/O エラーは呼び出し元に伝える。
- この仮定で進めます：1 行を 1 件として扱い、`order_id` による重複排除はせず、辞書のキー順は要件としない。
