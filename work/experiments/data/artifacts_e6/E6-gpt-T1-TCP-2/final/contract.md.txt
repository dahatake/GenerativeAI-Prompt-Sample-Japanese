# Task Contract：月次売上集計（承認済み）

## Outcome
`solution.py` の `monthly_sales(path)` は、指定した CSV の税込売上を JST の暦月で集計し、`{"YYYY-MM": 金額(int)}` を返す。

## Scope・Out of scope
- 対象：CSV の読み込みと検証、JST への変換、対象行の選定、月次集計と空き月の補完。
- 対象外：入力 CSV の更新、税額・為替の再計算、CLI・帳票の作成、注文 ID による重複排除。

## Data sources
### 確認できた事実
- `sales.csv` の列は `order_id,ordered_at,amount_incl_tax,status`。10 行すべての日時は UTC の `Z` 表記で、`completed` が 8 行、`cancelled` が 2 行。`completed` の `A-1006` に `-1100` がある。
- `A-1004`（`2026-01-31T16:20:00Z`, `3300`）は JST で 2 月、`A-1010`（`2026-04-30T15:30:00Z`, `7700`）は JST で 5 月。3 月の入力行はない。
- `answers.md` で Q1=A、Q2=A、Q3=B および入力・エラー処理・重複の既定案を確認した。

## Constraints
- Python 標準ライブラリのみ使用し、指定の作業ディレクトリ内で作業する。`path` が指す CSV は読み取り専用。開始・終了時刻は指定の Python コマンドで `timing.txt` に追記する。
- 日時は UTC から JST（固定 `UTC+09:00`）に変換してから年月を取る。
- `completed` のみ集計し、`cancelled` は集計から除外する。負額を含め `amount_incl_tax` を記録単位のまま符号どおりに加算し、換算・丸めはしない。
- 集計対象行の最初の JST 月から最後の JST 月まで（両端含む）のすべての月を返す。対象行のない月は整数 `0`、対象行が一件もなければ `{}`。

### 採用した仮定
- UTF-8（先頭 BOM 可）のカンマ区切り CSV。列は名前で特定し、必要列は `ordered_at`、`amount_incl_tax`、`status`。日時は実在する日付の `YYYY-MM-DDTHH:MM:SSZ`、金額は符号付き可の十進整数。
- 完全な空行は無視する。必須列の欠落、不正な行・日時・金額、未定義の `status` は `ValueError`。読めないファイルの I/O エラーは呼び出し元に伝える。
- 1 行を 1 件として扱い、`order_id` で重複排除しない。辞書のキー順は要件としない。

## Definition of Done
1. `monthly_sales('sales.csv')` は `{'2026-01': 16500, '2026-02': 11000, '2026-03': 0, '2026-04': 18700, '2026-05': 7700}` を返し、値はすべて `int`。入力を変更しない。
2. 未整列の入力でも UTC→JST の月・年またぎを正しく処理し、年をまたぐ空き月を整数 `0` で補完する。キャンセルは範囲を広げず、合計が 0 になった対象月は残す。
3. ヘッダーのみ、またはキャンセルのみの有効な CSV なら `{}` を返す。
4. UTF-8 BOM、列順の違い、空行を処理でき、同じ注文 ID の複数行も個別に加算する。
5. 必須列の欠落、不正な行・日時・金額、未定義のステータスで `ValueError`。存在しないファイルでは `FileNotFoundError` を伝える。

## Evidence
- `sales.csv` の計算根拠：1 月 `11000 + 5500`、2 月 `3300 + 8800 - 1100`、3 月 `0`、4 月 `16500 + 2200`、5 月 `7700`。
