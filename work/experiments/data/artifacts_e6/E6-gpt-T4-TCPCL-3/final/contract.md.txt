# Task Contract（承認済み）— 月間労働時間の集計

`answers.md` の回答を反映済み。追確認が必要な値はないため、Execution Mode に移行する。

## 確認できた事実

- 入力例 `shifts.csv` は `employee,date,type,start,end` の5列と6行。`2026-10-01`〜`2026-10-03` の3人分で、`work` が5行、`paid_leave` が1行。
- データには `22:00` → `06:00` の夜勤と、開始・終了の差がちょうど6時間の勤務がある。有給行の開始・終了はともに空欄。
- サンプルに `status`・休憩・金額・タイムゾーン・対象月の列はない。

## 確定した回答と採用した仮定

- **Q1（推奨案Aを採用）：** 有効なデータ行の `date` の年月が1種類ならその月を集計する。`paid_leave` も含めて年月が2種類以上なら `ValueError`。データ行がなければ `{}`。
- **Q2（回答の指定値）：** `work` 1行の控除前の経過時間が0〜360分なら控除0分。361〜1439分なら一律60分を控除する。複数行を合算した時間にはこの控除を適用しない。
- **Q3（回答の指定値）：** `paid_leave` は1行につき450分（7.5時間）を計上する。時刻欄は無視し、休憩控除はしない。
- **日時・期間：** `date` はJST（UTC+09:00固定）での勤務開始日。暦月は月初 `00:00` 以上・翌月初 `00:00` 未満。終了が開始より早ければ翌日終了、同時刻なら0分。月をまたぐ勤務は分割せず、開始日の月に全時間を計上する。
- **対象・除外：** `type` は前後の空白を除いて大小文字を区別し、`work` と `paid_leave` のみ受理する。未知の種別は `ValueError`。`status` による除外はせず、重複・重なりを補正せずに1行ずつ別シフトとして扱う。
- **欠損・ゼロ・上下限：** `employee,date,type` と、`work` の `start,end` は必須。値の前後の空白を除く。日付は実在する `YYYY-MM-DD`、勤務時刻は `00:00`〜`23:59`（両端含む）の `HH:MM`。`paid_leave` の時刻欄は空欄でも、値が入力されていても検証・集計に使わない。勤務1行の控除前の上限は1439分、従業員の月合計に上限は設けない。ヘッダーだけなら `{}`。空行は無視し、空ファイル・必須列不足・重複ヘッダー・列数不一致は `ValueError`。ファイルを開けなければ元のファイル例外を送出する。
- **控除・換算・金額：** `work` は経過時間から休憩を控除した後、**1行ごとに15分単位で切り捨てる**。`paid_leave` は固定450分。従業員ごとに整数分で合算し、最後に60で割る。月合計の追加丸めはしない。金額を扱わないため、税込・税抜や金額の端数処理は適用しない。
- **形式・順序：** 従業員IDは前後の空白を除いた文字列のまま（先頭ゼロと大小文字を保持）。キーは文字列の昇順に挿入し、値はすべて時間単位の `float`。集計対象の行がある従業員は月合計が0分でも `0.0` として残す。

## Outcome

`solution.py` の `monthly_work_hours(path)` が、指定されたCSVの1か月分の労働時間を従業員別に `dict[str, float]` で返す。

## Scope・Out of scope

- **Scope:** CSV検証、対象月の確認、夜勤の経過時間計算、休憩控除・勤務ごとの切り捨て・有給の換算、従業員別合算。
- **Out of scope:** 金額・給与・消費税、法令適合の判定、残業・割増の内訳、勤怠の重複修正、従業員マスター、CLIやファイル出力。

## Data sources

- 入力：呼び出し元が `path` で指定する `shifts.csv` と同じ列構成のCSV。
- 仕様の根拠：依頼、`shifts.csv`、`answers.md`。別ファイルの従業員・休憩・対象月情報は使わない。

## Constraints

- UTF-8（BOM可）、ヘッダー付きのカンマ区切りCSV。必須の5列は順不同。余分な名前付き列は無視する。
- Python標準ライブラリのみ。入力は変更せず、実行日の年月やマシンのタイムゾーンに依存しない。
- 関数の引数は `path` のみ。出力に金額や月を含めない。

## Definition of Done

1. `monthly_work_hours` を `solution.py` から読み込め、`shifts.csv` から `{'E001': 21.25, 'E002': 13.0, 'E003': 8.25}` をこのキー順で返し、値はすべて `float`。列順変更、BOM、余分な列、IDの前後空白・先頭ゼロを上記のルールどおり扱う。
2. `2026-10-31` の `22:00` → `06:00` は控除前480分、控除・切り捨て後420分（7.0時間）の全量が10月に帰属する。10月始まりと11月始まりの行が混在する場合は、11月の行が `paid_leave` だけでも `ValueError`。
3. 控除前の勤務が359・360・361・480・481分なら、控除・切り捨て後の分数はそれぞれ345・360・300・420・420。14分の勤務は0分、15分の勤務は15分。1人に14分の勤務が2行あっても先に各行を切り捨てるため月合計は0分。
4. 開始・終了が空欄の `paid_leave` だけを持つ従業員も出力し、1行7.5時間を計上する。同時刻の `work` は `0.0` としてキーを残す。ヘッダーのみは `{}`。
5. 空ファイル、必須列・必須値不足、重複ヘッダー、列数不一致、存在しない日付、範囲外の勤務時刻、未対応の種別は `ValueError`。`00:00` → `23:59` は有効で、控除前1439分から60分を控除し15分単位で切り捨てた結果は1365分（22.75時間）。ファイルを開けない場合は元のファイル例外を送出する。
