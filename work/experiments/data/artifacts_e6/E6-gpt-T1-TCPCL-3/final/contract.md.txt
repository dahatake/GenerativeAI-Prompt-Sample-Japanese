# Task Contract：月次売上集計（承認済み / Execution Mode）

## Outcome

`solution.py` の `monthly_sales(path)` は、指定された CSV の `completed` の売上を日本時間の暦月ごとに集計し、税抜額を `{"YYYY-MM": 金額(int)}` の Python `dict` で返す。

## Scope・Out of scope

- 対象：CSV の読み込みと必須値の検証、対象行の選別、JST への換算、月次の税込合計、税抜換算・丸め、欠け月の 0 補完。
- 対象外：個別行ごとの税抜換算・丸め、税率の推定や変更、通貨換算、数量による乗除、時間・数量の控除、注文 ID による重複排除、期間指定の追加、入力の更新と結果のファイル出力、外部データ参照。

## Data sources

- `sales.csv`：ヘッダーは `order_id,ordered_at,amount_incl_tax,status`。10 行のうち `completed` が 8 行、`cancelled` が 2 行。日時は UTC の `Z` 付き。金額は整数で、`completed` の `A-1006` は `-1100`。通貨・税率・数量・控除・種別の独立列はない。3 月の行はない。
- `answers.md`：Q1（JST）、Q2（`completed` のみ、負額・ゼロを含む）、Q3（対象行がある最初と最後の月の間を 0 補完）はすべて A。金額は税込 10% で記録され、出力は税抜整数。その他は推奨既定案。
- `answers2.md`：追加確認は推奨案 A1 + B1。月ごとの税込合計を `1.1` で割って月に 1 回丸める。最も近い整数にし、ちょうど中間の場合は 0 から遠い方へ丸める。

## Constraints

- Python 標準ライブラリで完結し、引数で渡したファイルを読む。入力ファイルや外部状態を変更しない。
- 日時は `YYYY-MM-DDTHH:MM:SS` に `Z` または `±HH:MM`（オフセットの時は `00`～`23`、分は `00`～`59`）が付いた形式。秒の小数部は 1～6 桁まで任意。入力日時と JST 換算後の暦年は `0001`～`9999`。JST は固定 UTC+09:00（夏時間なし）。月初 `00:00:00` は含み、翌月初 `00:00:00` は含まない。任意の期間フィルターは設けない。
- `amount_incl_tax` は任意の先頭符号 `+` / `-` に続く ASCII 十進数字。入力の小数は丸めず不正値として扱う。業務上の金額上限・下限は設けない。金額の単位は入力通貨と同じ（通貨名は未確認）。月次の税抜換算は `10 / 11` の比を浮動小数点なしで適用する。
- CSV は UTF-8（BOM は任意）のヘッダー付き。`ordered_at`・`amount_incl_tax`・`status` は各 1 列が必須。余分な列や `order_id` は無視し、同じ注文 ID の行でもそれぞれ独立に集計する。完全な空行は無視し、必須値は前後空白を除いて検証する。必須列の欠落・重複や必須値の欠損・不正値は、ステータスで除外する前に `ValueError` とする。
- `status` は大文字・小文字を区別して `completed` のみを採用し、それ以外の非空値の行は除外する。取引種別による追加選別や時間・数量の控除はしない。対象行のない月は最初と最後の対象月の間のみ `0` で補完し、対象行があって合計が 0 の月は省略しない。キーは年 4 桁・月 2 桁とし、月の昇順で `dict` に挿入する。

## Definition of Done

- **D1 実データと出力形式**：`monthly_sales('sales.csv')` は `{'2026-01': 15000, '2026-02': 10000, '2026-03': 0, '2026-04': 17000, '2026-05': 7000}`。`dict` のキーは記載の月順で、値の型はすべて `int`。
- **D2 月境界**：`2026-01-31T14:59:59Z` は 1 月、`2026-01-31T15:00:00Z` は 2 月。同じ瞬間の `2026-02-01T00:00:00+09:00` も 2 月。
- **D3 選別・負額・ゼロ**：`cancelled` とその他のステータスを除外し、`completed` の負額は差し引く。金額が `0` の対象行しかない月と、加減算の結果が `0` の月も残す。対象外の行があるだけの月まで補完範囲を広げない。
- **D4 空の集計**：ヘッダーのみ、または有効な対象行がゼロ件の場合は `{}`。
- **D5 入力エラー**：必須列の欠落や、除外ステータスの行も含めた必須値の欠損・不正値は `ValueError`。小数金額、タイムゾーンなし、実在しない日時、JST 換算で範囲外になる日時を検証する。
- **D6 税抜換算**：同月の税込 `6` と `6` は合計して換算するので `11`（行ごとの丸めなら `10`）。別々の月の税込 `100` と `-100` は `91` と `-91`。大きな整数でも浮動小数点に起因する誤差を生じない。
- **D7 欠け月の補完**：対象の初月・終月を含め、年をまたぐ場合も月順で途中の欠け月を `0` にする。年 `0001` と `9999` も範囲内の日時なら月キーを 4 桁の年で返す。

## Evidence

- `A-1004`（税込 3300）は UTC 1 月 31 日 `16:20:00` から JST 2 月 1 日 `01:20:00` へ、`A-1010`（税込 7700）は UTC 4 月 30 日 `15:30:00` から JST 5 月 1 日 `00:30:00` へ移る。
- 独立計算の税込合計は 1 月 `16500`、2 月 `3300 + 8800 - 1100 = 11000`、4 月 `18700`、5 月 `7700`。税抜では順に `15000`、`10000`、`17000`、`7000`。3 月を `0` で補完する。
- `test_solution.py` を実行したコマンド、出力、D1～D7 の確認結果は `report.md` に記載する。
