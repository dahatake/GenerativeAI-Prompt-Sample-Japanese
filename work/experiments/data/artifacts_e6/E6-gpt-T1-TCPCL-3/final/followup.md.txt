# 追加確認：税抜金額を整数にする方法

税率は 10%（税込額 ÷ 1.1）、Q1〜Q3 はすべて A と確認できました。「整数」だけでは、端数を処理する段階と丸め方が決まりません。

**税抜額はどの段階で、どの方法で整数に丸めますか？** 下の 2 項目を組み合わせて、`A1 + B1` のように回答してください。

- **段階**
  - **A1（推奨）**：対象行の税込額を月ごとに合計し、その合計を `1.1` で割って月に 1 回だけ丸める。
  - **A2**：対象行ごとに税込額を `1.1` で割って丸め、その整数を月ごとに合計する。
- **丸め方**（税込 `100` / `-100` の換算例）
  - **B1（推奨）**：最も近い整数に丸める。ちょうど中間の場合は 0 から遠い方へ丸める（`91` / `-91`）。
  - **B2**：小数部分を捨てて 0 に近い方へ丸める（`90` / `-90`）。
  - **B3**：常に結果以下で最大の整数に丸める（`90` / `-91`）。

たとえば同じ月に税込 `6` の対象行が 2 件ある場合、`A1 + B1` では `11`、`A2 + B1` では `10` です。選択肢にない場合は、丸める段階と正負それぞれの端数処理を具体的に指定してください。
