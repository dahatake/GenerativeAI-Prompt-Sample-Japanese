# 実装内容

- `solution.py` に `monthly_sales(path)` を実装した。
- CSV の `status` が `completed` の行だけを売上として集計し、キャンセル済み等は除外した。
- 完了済み売上の `amount_incl_tax` を整数として月ごとに加算した（負数もそのまま返金等として加算）。
- 月キーは `ordered_at` の ISO 日付部分から `YYYY-MM` として作成した。

# 前提にした確認事項

1. 入力CSVはUTF-8（BOMありでも可）で、ヘッダーは `ordered_at`、`amount_incl_tax`、`status` を含む。
2. 実装時点では、売上として数えるステータスは `completed` のみである。ステータス比較では前後空白を除去し、大文字小文字を区別しない。
3. `completed` 以外の行は金額・日付が不正でも集計前にスキップする。
4. 月は `ordered_at` の先頭10文字をISO日付 `YYYY-MM-DD` として解釈し、タイムゾーン変換は行わない（オフセット付き時刻でもローカル表記の日付を使用する）。
5. `amount_incl_tax` は符号付きの整数文字列であり、小数・カンマ区切り・通貨記号は前提としない。負数は加算に含める。
6. 必須ヘッダーの欠落時は `ValueError` を送出する。空のCSVはヘッダーがなくても `{}` を返す。
7. `completed` 行の `ordered_at` は先頭10文字が有効なISO日付である必要があり、不正な場合は `ValueError` を送出する。
8. `completed` 行の金額が空または整数以外の場合は `int()` の変換規則に従い、整数変換に失敗した場合はエラーを送出する。
9. 月ごとの集計は返金等で合計が0になっても、該当する月のキーを合計0として辞書に含める。
