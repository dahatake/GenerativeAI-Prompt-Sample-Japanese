# 月次売上集計

`solution.py` の `monthly_sales(path)` は、ヘッダー付きの UTF-8 CSV（BOM あり・なし）を読み込み、月ごとの税抜売上合計を `{"YYYY-MM": 金額(int)}` の辞書で返します。

## 今回の修正点

- `status` が `cancelled` の注文だけを除外し、それ以外の注文を集計します。
- 月ごとに税込金額 `amount_incl_tax` を合計（負額も加算）し、その合計を 1.1 で割って税抜金額にします。小数部分は 0 に向けて切り捨てます。
- 集計対象の最初の月から最後の月までを含め、対象注文がない月は `0` を返します。対象注文が一件もない場合は空の辞書を返します。

`ordered_at` は従来どおりタイムゾーン付きの ISO 8601 日時として読み込み、UTC から日本標準時（UTC+09:00）に変換して月を判定します。
