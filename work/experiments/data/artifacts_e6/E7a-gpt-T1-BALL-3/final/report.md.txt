# 月次売上集計

## 実装内容
`solution.py` の `monthly_sales(path)` は、`completed` の取引を日本標準時（JST）の月ごとに集計し、税抜金額を `{"YYYY-MM": 整数}` の辞書で返します。提供された `sales.csv` の結果は `{"2026-01": 15000, "2026-02": 10000, "2026-03": 0, "2026-04": 17000, "2026-05": 7000}` です。

## 今回修正した点
- 月ごとの税込合計を `1.1` で割って税抜額に変更しました。変換は月ごとに一度行い、正負ともに小数部分をゼロ方向に切り捨てます。
- 集計対象の最初の月から最後の月まで、途中に対象取引がない月も `0` で埋めるようにしました。

## 確認事項（現在の既定値・前提）
- 入力：`path` で指定された UTF-8（BOM は任意）のカンマ区切り CSV。ヘッダーに `ordered_at`、`amount_incl_tax`、`status` が必要で、列順は任意。他の列は使いません。
- 対象：`status` が完全一致で `completed` の行だけを計上します。`cancelled`、その他の値、空欄は対象外です。`order_id` による重複排除は行いません。
- 計上月：`ordered_at` は UTC の `Z` または明示的な UTC オフセット付きの ISO 8601 日時とし、JST（UTC+09:00）への変換後の暦月で計上します。タイムゾーンがない日時は対象行ではエラーにします。
- 金額：同じ通貨・単位で記録された税込（税率 10%）の `amount_incl_tax` を月ごとに合計し、`1.1` で割って正負ともにゼロ方向に切り捨て、税抜の整数に変換します。前後の空白や符号付きの十進整数を許容し、負数は計上月の合計から差し引きます。入力に小数・桁区切りは許容せず、通貨換算もしません。
- 出力：対象行の最初の月から最後の月までを年月順で返し、対象行がない月の金額は `0` とします。対象外の行は範囲の判定に使いません。空ファイル、ヘッダーのみ、対象行なしの場合は空の辞書です。
- エラー：必要な列がない場合や、対象行の日時・金額が欠損または不正な場合は `ValueError` にします。対象外の行の日時・金額は検証せず、ファイル読み込み・CSV の構文エラーは呼び出し元に伝えます。
