# Task Contract 案 — 従業員別の月間労働時間

## 確認できた事実

- 作業開始時に確認できた入力は `shifts.csv`。`solution.py`、テスト、業務ルールを記したファイルは見当たらない。
- ヘッダーは `employee,date,type,start,end`。データは従業員3名・6行で、すべて `date` は2026年10月。日付は `YYYY-MM-DD`、時刻がある行は `HH:MM`。タイムゾーン、対象月、休憩実績、金額の専用列はない。
- `work` は5行。打刻から計算した休憩控除前の長さは、E001が9時間と5時間50分、E002が22:00〜翌06:00の8時間とちょうど6時間、E003が9時間15分。E001の `paid_leave` 1行は開始・終了とも空欄。
- 依頼の公開インターフェースは `monthly_work_hours(path)`。返すのは従業員IDをキー、時間単位の `float` を値とする `dict`。

## 不足情報

有休を労働時間に含めるか、休憩を何分引くか（特に6時間・8時間ちょうど）、対象月の決め方と月をまたぐ勤務の帰属は、CSVから確定できない。以下の Q1〜Q3 で確認する。その他の未確定事項は末尾の「仮定」に明記する。

## Outcome

`solution.py` に `monthly_work_hours(path)` を実装し、指定CSVから対象月の労働時間を従業員別に返す。

## Scope・Out of scope

- 対象: CSV読み込み、種別による抽出、シフト時間・休憩の計算、対象月への帰属、従業員別集計。
- 対象外: 給与・割増賃金・税額の算定、勤怠の修正、従業員台帳との突き合わせ、出力ファイルやCLIの提供。

## Data sources

- `path` が指すCSVが集計元。`shifts.csv` は入力例と検証基準であり、実装にファイル名や対象月を固定しない。
- `employee` は従業員ID、`date` は開始日の現地日付、`type` は行の種別、`start` と `end` は開始・終了の現地時刻として扱う案（詳細は下記）。

## Constraints

- 引数は `path` のみ。入力は読み取り専用、結果は戻り値のみ。Python標準ライブラリで対応する案とし、外部サービスや依存パッケージは使わない。
- この段階では `contract.md` と `timing.txt` のみ作成・変更し、実装・テストは行わない。

## Open questions

### 確認したいこと（3問）

**Q1. `paid_leave` を労働時間に含めますか？** CSVには打刻が空の有休行が1行あります。どちらの案でも、`work` と選択された `paid_leave` 以外の種別は除外します。

- **A（推奨）:** `work` のみ集計。`paid_leave` は打刻の有無にかかわらず除外。
- **B:** `work` に加え、`paid_leave` を1行につき480分として `date` に計上。打刻は参照せず、休憩は引かない。
- どちらでもなければ、対象とする種別名、有休1行あたりの分数または算定式を具体的に指定してください。

**Q2. `work` から引く休憩は何分ですか？** CSVには専用列がなく、ちょうど360分と480分の勤務があります。`m` は日またぎ補正後・控除前の1行の勤務分数です。

- **A（推奨）:** `0 ≤ m ≤ 360` は0分、`360 < m ≤ 480` は45分、`480 < m` は60分を控除。ちょうど6時間は控除なし、ちょうど8時間は45分控除。
- **B:** `0 ≤ m < 360` は0分、`360 ≤ m < 480` は45分、`480 ≤ m` は60分を控除。ちょうど6時間は45分、ちょうど8時間は60分控除。
- **C:** 全範囲で0分。打刻差をそのまま集計。
- いずれでもなければ、閾値（分）、ちょうどの値を含む側、各範囲の控除分数を具体的に指定してください。

**Q3. 引数が `path` だけの場合、どの月を集計し、月をまたぐ勤務はどこに計上しますか？** CSVには対象月を指定する列がありません。

- **A（推奨）:** 集計対象行の `date` は同じ暦月でなければ `ValueError`。その月に1行の控除後全時間を計上する。たとえば10/31 22:00〜11/1 06:00は全量を10月分に計上。
- **B:** 集計対象行の `date` のうち最新日の暦月を採用し、その月の1日 00:00 以上・翌月1日 00:00 未満を集計。前月開始の勤務もこの範囲との重なり分だけを含める。休憩はシフト全体から算定し、シフト末尾にまとめて引いた後で月境界を適用する。有休を含める場合は日付の属する月に全量計上。
- どちらでもなければ、対象月の決め方、開始・終了境界とその包含、月またぎの時間と休憩の配分を具体的に指定してください。

### 仮定 — この仮定で進めます

- **金額:** 入力・出力に金額がないため、税込・税抜、通貨、金額の丸めはいずれも適用しません。この仮定で進めます。
- **日時・上下限:** タイムゾーンは日本標準時（UTC+09:00、夏時間なし）。有効な暦日と `00:00`〜`23:59` の分単位の時刻を受け付け、`24:00` と秒は不可。終了が開始より前なら翌日、同時刻なら0分（24時間とはみなさない）。1行の控除前の時間は0〜1439分とし、集計の月間上限は設けません。この仮定で進めます。
- **入力・欠損・除外:** UTF-8のカンマ区切り（BOM可）、必須ヘッダーは上記5列で列順不問。追加列は無視し、空行は読み飛ばします。必須列の欠落や行の列数の不一致、空の `type`、集計対象行の空のID・不正な日付・必要な打刻の欠損や不正は `ValueError`（行のエラーはCSV行番号を示す）。種別は前後空白を除いたうえで大文字小文字を区別して判定し、対象外行のID・日付・打刻は検証しません。独立した `status` による絞り込みや重複・重なりの補正は行いません。この仮定で進めます。
- **控除・単位と丸め:** Q2の控除は勤務1行ごとに1回、整数分で行い、控除後は最小0分。従業員別に分数を合計し、最後に60で割って `float` の時間に換算。行別・月計とも表示桁への丸めはしません。この仮定で進めます。
- **出力:** 前後空白を除いた文字列の従業員IDをキーとし、先頭のゼロは保持。辞書の挿入順はIDの文字列昇順。対象月に計上される有効行があれば合計0分でも `0.0` を返し、対象行がない従業員は含めません。この仮定で進めます。
