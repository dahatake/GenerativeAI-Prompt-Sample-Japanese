# 実装内容

- `solution.py` に `monthly_sales(path)` を実装した。
- `cancelled` の行だけを集計から除外し、それ以外の `status` は集計対象に含めた。
- `ordered_at` を UTC とみなし、日本時間（JST, UTC+9）へ変換してから `YYYY-MM` を判定した。
- `amount_incl_tax` を税込金額として扱い、税抜金額（税込 / 1.1 を整数化）で加算した。
- 負数は推奨案に従い集計対象から除外した。
- 最初の対象月から最後の対象月までを順に補完し、注文がない月は 0 として返した。

## 前提

- 入力CSVは `ordered_at, amount_incl_tax, status` の列を持つ。
- 日時は ISO 形式で UTC を示す。タイムゾーン情報がない場合は UTC とみなす。
- 金額は整数表記である。
- サンプル実行では次の結果を確認した。

```python
{
    '2026-01': 15000,
    '2026-02': 11000,
    '2026-03': 0,
    '2026-04': 17000,
    '2026-05': 7000,
}
```

## 今回修正した点

- `completed` のみを対象とする処理を、`cancelled` のみ除外する処理に変更した。
- CSV の月判定を JST（UTC+9）へ変換する処理に変更した。
- 税込金額を税抜金額へ変換してから加算する処理を追加した。
- 負数を集計から除外する処理を追加した。
- 欠損月を 0 で埋める処理を追加した。
