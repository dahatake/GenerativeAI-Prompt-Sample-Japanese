# 実装内容

`solution.py` に `monthly_sales(path)` を実装した。

- `csv.DictReader` で CSV を読み込む。
- `status == "completed"` の行だけを売上として集計する。
- `ordered_at` の先頭7文字を `YYYY-MM` として使用する。
- `amount_incl_tax` を整数として加算する。
- 集計結果を `{"YYYY-MM": 合計額(int)}` の dict として返す。
- 入力は UTF-8（BOM 可）、ヘッダーは `ordered_at`、`amount_incl_tax`、`status` を想定する。

検証では `sales.csv` に対し、次の結果を確認した。

```text
{'2026-01': 19800, '2026-02': 7700, '2026-04': 26400}
```

# 確認事項（前提）

1. 確認対象の売上は `status == "completed"` の行とし、`cancelled` は除外する。
2. `status` の大小文字や前後空白は正規化して判定する。
3. 明示的なステータス以外の行も売上から除外する。
4. 完了済みかつ負数の `amount_incl_tax` は、返金・調整として有効な金額として加算する。
5. 金額は整数として扱い、丸めや通貨変換を行わない。
6. 月区分は `ordered_at` の先頭を `YYYY-MM` とみなし、タイムゾーン変換は行わない。
7. 売上がない月は結果のキーに含めず、ゼロ埋めしない。
8. 同じ月の金額は、完了済み行の合計として足し合わせる。
9. CSV は UTF-8（BOM を含む場合を含む）で保存され、ヘッダー名は指定された列名である。
10. `ordered_at` は先頭7文字が `YYYY-MM` の形式であることを前提とし、形式が不正な場合は `ValueError` とする。
11. `amount_incl_tax` は空白除去後に `int()` で変換可能な整数であることを前提とし、不正な場合は例外をそのまま発生させる。
