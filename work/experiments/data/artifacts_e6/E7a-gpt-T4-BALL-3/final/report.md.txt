# 月間労働時間の集計

`solution.py` の `monthly_work_hours(path)` は、CSV を読み、従業員 ID ごとの実労働時間と有給休暇の所定労働時間を分単位で加算し、時間（`float`）の辞書にして返します。付属の `shifts.csv` では、E001 は21時間15分、E002 は13時間、E003 は8時間15分です。

## 確認事項（現行仕様・既定値）

- 入力は UTF-8（BOM の有無は不問）のカンマ区切り CSV。ヘッダーに `employee,date,type,start,end` が必要です。順序は任意、追加列は無視し、列名の重複は認めません。空行は無視し、空ファイル・ヘッダーのみは `{}` を返します。
- 必須列のデータの前後空白は除きます。従業員 ID は空でない文字列として扱い、先頭のゼロと大文字・小文字はそのまま保持します。日付は `YYYY-MM-DD`、勤務時刻はタイムゾーンなしの24時間表記 `HH:MM` とします。
- 対象はファイル内の単一の暦月です。有給休暇を含む全行の `date` が同じ年月である必要があり、複数月を含む場合はエラーとします。
- `work` の拘束時間は開始から終了までの経過時間です。終了が開始より早ければ翌日退勤、同じ時刻なら0分とします。月をまたぐ勤務も、全時間を開始日の月に計上します。
- `work` は拘束時間が6時間を超える場合に休憩60分を控除します。6時間ちょうどは控除しません。休憩控除後の実労働時間をシフトごとに15分単位で切り捨ててから加算します。割増計算や重複・重なりの補正は行いません。
- `paid_leave` は時刻を参照せず、1行あたり所定労働時間の7.5時間を計上します。有給休暇しかない従業員も集計対象とし、入力に登場しない従業員は含めません。
- `work` と `paid_leave` 以外の種別、必須値の欠落、不正な日付・勤務時刻、列数の不一致、不正なCSV構文は、無視せずエラーとします。

## 今回修正した点

- 拘束時間が6時間を超える勤務に限り、休憩60分を控除するように変更しました。
- 控除後の実労働時間を、月間合計ではなくシフトごとに15分単位で切り捨てるように変更しました。
- 有給休暇を0時間ではなく1行あたり7.5時間で計上するように変更しました。
