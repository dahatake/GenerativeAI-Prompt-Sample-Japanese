# 月間労働時間の集計

`solution.py` の `monthly_work_hours(path)` は、CSV を読み、従業員 ID ごとの実労働時間を分単位で加算し、時間（`float`）の辞書にして返します。付属の `shifts.csv` では、E001 は14時間50分、E002 は14時間、E003 は9時間15分です。

## 確認事項（今回の前提・既定値）

- 入力は UTF-8（BOM の有無は不問）のカンマ区切り CSV。ヘッダーに `employee,date,type,start,end` が必要です。順序は任意、追加列は無視し、列名の重複は認めません。空行は無視し、空ファイル・ヘッダーのみは `{}` を返します。
- 必須列のデータの前後空白は除きます。従業員 ID は空でない文字列として扱い、先頭のゼロと大文字・小文字はそのまま保持します。日付は `YYYY-MM-DD`、勤務時刻はタイムゾーンなしの24時間表記 `HH:MM` とします。
- 対象はファイル内の単一の暦月です。有給休暇を含む全行の `date` が同じ年月である必要があり、複数月を含む場合はエラーとします。
- `work` は開始から終了までの経過時間です。終了が開始より早ければ翌日退勤、同じ時刻なら0分とします。月をまたぐ勤務も、全時間を開始日の月に計上します。
- 休憩データがないため、休憩の自動控除や割増計算、時間の丸めは行いません。各勤務行を独立に加算し、重複・重なりの補正はしません。
- `paid_leave` は実労働に含めず、時刻は読み取り対象外です。有給休暇しかない従業員も `0.0` で返します。入力に登場しない従業員は含めません。
- `work` と `paid_leave` 以外の種別、必須値の欠落、不正な日付・勤務時刻、列数の不一致、不正なCSV構文は、無視せずエラーとします。
