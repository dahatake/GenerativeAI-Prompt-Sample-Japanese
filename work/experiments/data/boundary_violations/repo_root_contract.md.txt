# Task Contract（Execution Mode — 承認済み）

## Outcome
`solution.py` に `monthly_sales(path)` を実装し、指定した CSV の売上を月次集計して、戻り値を `{"YYYY-MM": 金額(int)}` の dict とする。

## Scope
- 作業ディレクトリ内の `sales.csv` と `solution.py` を対象にする。
- 標準ライブラリで入力 CSV を読み、注文日時・ステータス・金額を月次集計する。
- キャンセル注文を除外し、完了注文のみを売上に加算する。
- UTC の注文時刻を JST（UTC+9）へ変換して月を判定する。
- 最初の有効な注文月から最後の有効な注文月まで、注文がない月を 0 として含める。

## Out of scope
- CSV の修正。
- 外部データ・ネットワークへのアクセス。
- 可視化、レポート以外の永続化機能。
- 依頼外の既存ファイルや作業ディレクトリ外のファイルへの変更。

## Data sources
- `sales.csv`
- ヘッダー: `order_id,ordered_at,amount_incl_tax,status`

## Constraints
- 作業ディレクトリ外のファイルは読まない・書かない。
- 標準ライブラリのみ使用する。
- 戻り値は dict。キーは `YYYY-MM`、値は int。
- 金額は整数文字列のみを許可し、不正な金額では `ValueError` を発生させる。
- 未知のステータスは集計対象外。
- 相対パスと絶対パスの両方を受け付ける。

## Definition of Done（検証できる条件）
1. `solution.py` に `monthly_sales(path)` が定義されている。
2. `monthly_sales("sales.csv")` を実行できる。
3. サンプルの確定集計が正しい。
4. キャンセル除外、負額加算、JST変換が正しい。
5. 欠損月を含む範囲が正しい。
6. 相対パスと絶対パスの両方で再現可能に読める。

## Evidence
### 確認できた事実
- `sales.csv` はヘッダー付きで10行。
- `status` は `completed` 8件、`cancelled` 2件。
- サンプルの完了金額合計は JST基準で次になる想定:
  - 2026-01: 19800
  - 2026-02: 7700
  - 2026-03: 0
  - 2026-04: 26400
- 負額 `-1100` は completed に含まれる。
- キャンセルの金額は 22000 と 4400。

### 回答反映済みの仕様
- Q1: `cancelled` を除外し、`completed` のみ集計。
- Q2: UTC から JST（UTC+9）へ変換して月を判定。
- Q3: 回答なしのため推奨案を採用。整数文字列のみ許可し、不正金額は `ValueError`。
- 欠損月: 最初の月から最後の月までゼロを含める。
- 未知ステータス: 集計対象外。
- 不正行: 推奨案として整数以外の金額を `ValueError` とし、日時・ヘッダー不正も明確に失敗させる。

## Open questions
- なし。回答済み項目は確定し、回答なし項目は推奨既定案で承認済みとして Execution Mode に進む。
