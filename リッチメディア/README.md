# リッチメディア

主にHTMLになりますが、CSSやJavaScriptを組み合わせてリッチな表現を実現することができます。

Microsoft Coworkであれば、動画作成ができます。
Microsoft 365 Chatでも、HTMLの作成を指定すれば、リッチな表現を実現することができます。

## 3D アニメーションビデオ

何らかのPowerPointかWordなどのファイルを添付したうえで行います。


```prompt
[添付の資料}の内容をもとに、まず、興味を引く魅力的な脚本を書いてください。
次に、その脚本の内容を生き生きと表現する、3Dアニメーションのシネマティックなハリウッド風ムービーを作成してください。
明るく、開放的で、希望に満ちた雰囲気にしてください。
長さは2分以内にし、MP4形式での出力は不要です。

次のような参考サイトを参考にしてください。
https://orpetron.com/blog/innovative-examples-of-three-js-in-action/;
https://labs.lusion.co; 
https://discourse.threejs.org/t/interactive-3d-animated-short-film-built-with-three-js-r3f/92270 
```

## シュミレーター

```prompt
F1の鈴鹿GPにおける全F1ドライバーのテレメトリデータを添付しました。
ドライバーの順位に基づく、縦型のランキングシミュレーションを作成してください。
--------------------------------------------------------------
シミュレーションのランキング行にセクター列（S1/S2/S3）を追加してください（セッションベストは紫、自己ベストは緑で表示）。
シミュレーションはラップ単位ではなく、セクター単位で進行させてください…
```
