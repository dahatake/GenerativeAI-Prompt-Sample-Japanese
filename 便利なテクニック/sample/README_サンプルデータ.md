# 共通シナリオ

- 題材企業: 北辰ファクトリーソリューションズ株式会社
- 題材業務: 製造業向けSaaS `LunaPlant` の導入、保守、研修
- 目的: Promptの効き方を比較しながら、より安定した入力設計を学ぶ

## 1. GPT の思考の方向性を調整する

### 1-1. CoT 比較に使う巡回問題

```text
次の6点をちょうど1度ずつ訪問して出発点に戻る順回路のうち、最短距離のものとその距離を教えてください。

(0,0), (1,3), (2,1), (4,0), (4,3), (5,1)
```

### 比較時の観点

- CoTなし/ありで経路候補がどう変わるか
- 途中計算を見せるかどうか
- 近似解ではなく全探索に近い説明が出るか

### 1-2. 「不足情報を質問してください」用の曖昧依頼

```text
依頼内容:
- 10月の顧客説明会で使う案内メールを作ってほしい
- ただし、宛先の役職、参加形式、締切日、申込URLはまだ未確定
- 外部共有できない情報は含めたくない
```

## 3. 主語と述語の関連性を強調する

```text
テーマ:
- 生成AI利用ガイドラインの「やってよいこと / だめなこと」を、現場責任者に分かりやすく説明したい

盛り込みたい事実:
- 個人情報は伏字化を基本とする
- 顧客に送る文章は人間レビュー必須
- 未確認情報は「未確認」と明示する
- 実験用途と本番用途で扱えるデータが違う
```

## 4. 思考の方向性を示す言葉たち

### ベース課題

```text
課題:
- 既存顧客向けのFAQ更新フローが遅い
- 担当者ごとに書き方が違う
- 月末に問い合わせが集中する
```

### 試す思考方向の候補

```text
【クリエイティブ寄り】
- 多角的思考
- アウトオブザボックス思考
- 発散思考

【問題解決寄り】
- システム思考
- 仮説思考
- プロセス思考

【戦略寄り】
- イシュードリブン思考
- レバレッジ思考
- DX思考
```

### 出力制約

- 各思考方向ごとに施策案を3件
- すぐ試せる短期策と、設計変更が必要な中期策を分ける

## 5. 敵対的レビュアーPrompt用サンプル

```text
レビュー対象の成果物:
- 顧客説明会用の1ページ要約メモ

成果物本文:
北辰ファクトリーソリューションズは、生成AIを使ってどの顧客でも週次レポートを完全自動で作成できます。個人情報のマスクは今後対応予定ですが、まずはスピードを優先します。FAQの更新はAIが自動で承認するため、担当者は最終確認不要です。10月から全顧客へ展開し、問い合わせ一次回答時間を50%削減します。

本来の目的:
- 顧客向け説明会で「今できること」と「安全策」を誤解なく説明する

気になっている点:
- 断定表現が多い
- 承認フローの説明が抜けている
- 展開範囲が広すぎるかもしれない
```

## 6. 曖昧な点についての質問票作成用サンプル

```text
雑な依頼:
来月から、会議メモとメールをうまく使って、部長向けの週次まとめを自動化したいです。できれば顧客ごとにも使えて、営業にもCSにも役立つ形にしてください。急ぎです。

分かっていること:
- 読み手は部長と営業企画
- 元データは会議メモ、問い合わせ一覧、案内メール
- 個人名は伏字にしたい

未確定:
- 週次まとめの長さ
- 顧客ごとに分けるか、全体版のみか
- どの部署が最終確認するか
- いつまでにPoCを見せるか
```
