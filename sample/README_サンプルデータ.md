## 4. 「複数案を出してみる」用サンプル

### 3案比較に向いた意思決定テーマ

```text
テーマ：10月説明会までに Partner Console の検索機能を改善する方法

現状:
- 代理店一覧検索の平均応答が 1.8秒
- 利用者から「社名の表記ゆれで検索できない」と苦情が月14件
- 検索インデックス基盤の刷新案はあるが、9月中に本番投入できるか不明

比較したい案:
1. 既存DBのクエリ最適化を先に行う
2. Elastic系の検索基盤をPoC導入する
```

### 出力条件

- 利点・懸念点・必要リソースを案ごとに分ける
- コスト感は `小 / 中 / 大` で表現
- 10月説明会に間に合うかを比較する
