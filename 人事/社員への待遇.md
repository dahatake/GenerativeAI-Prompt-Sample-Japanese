# ツール

# Prompt

```text
あなたは人事コンサルタントです。IT業界の社員向け報酬を、公開情報で確認できる範囲で調査してください。売上上位のIT企業10社について、社名、従業員数、平均年齢、平均給与、平均勤続年数、退職率、大卒人気度の確認可能な指標を表形式で作成してください。各項目の出典または確認範囲を添え、確認できない項目は「不明」としてください。
```

```text
外資でクラウドサービスを提供している企業について、公開情報で確認できる範囲で、社名、従業員数、平均年齢、平均給与、平均勤続年数、退職率、大卒人気度の確認可能な指標を表形式で作成してください。各項目の出典または確認範囲を添え、確認できない項目は「不明」としてください。
```

```text
日本のIT企業と外資クラウド企業について、従業員が感じている働く魅力と退職理由の傾向を比較してください。公開情報で確認できる範囲で、それぞれ3名を目安に事例を集め、働く魅力、退職理由、確認できた出典または確認範囲をリストアップしてください。確認できない情報は「不明」としてください。
```
