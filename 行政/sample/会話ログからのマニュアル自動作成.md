# 会話ログからのマニュアル自動作成 — 研修用サンプルデータ

> **注意**：このファイルに記載する自治体名、施設名、システム名、連絡先、業務ルールはすべて研修用の架空データです。実在の個人・団体・業務とは関係ありません。

## 業務名

公園使用許可申請の受付・審査準備

## 想定読者

初めて公園使用許可の受付を担当する、みどり野市公園管理課（架空）の一般職員

## 会話ログ・文字起こし

```text
**前任者**：申請が来たら、まず受付印ですね。電子申請には自動で受付日時が付くので、紙で来たものだけ表紙の右上に押します。

**後任者**：受付したら、すぐ施設予約システムに入れるんですか。

**前任者**：その前に、場所と日時が埋まっているかを見てください。あと、申請者の連絡先、催しの内容、参加予定人数。紙申請なら署名欄もです。足りない場合は正式受付にせず、「補正待ち」にします。

**後任者**：「補正待ち」はどこに記録しますか。

**前任者**：共有フォルダーの「公園使用申請受付台帳」です。年度ごとにExcelが分かれています。受付番号は台帳で採番しますが、補正待ちでも番号だけは先に取ります。

**後任者**：正式受付にしないのに番号は付けるんですね。

**前任者**：問い合わせと書類を結び付けるためです。ただ、受付日は書類が全部そろった日です。最初に届いた日は「初回到達日」の列に入れます。この区別を忘れやすいです。

**後任者**：メールで不足を連絡した場合はどうしますか。

**前任者**：送ったメールを案件フォルダーへPDFで保存して、台帳の対応履歴にも日付と「不足資料を依頼」と書きます。電話だけで済ませた場合も、相手の個人名は必要最小限にして、話した要点を履歴へ残します。

**後任者**：施設予約システムでは何を確認しますか。

**前任者**：同じ公園・同じ時間帯に、別の予約や工事予定がないかです。空いていても、申請を確認するまでは「仮押さえ」にしてください。「確定」にできるのは許可決裁の後です。

**後任者**：システム上で空いていれば、基本的には受け付けてよいですか。

**前任者**：普通の地域行事ならそうですが、火気使用、車両の乗り入れ、物品販売、大きな音を出す催しは担当だけで判断しません。係長へ回してください。公園によって禁止事項が違うので、「公園別利用条件一覧」も見ます。

**後任者**：キッチンカーは物品販売ですか、それとも火気使用ですか。

**前任者**：両方に当たることがあります。申請書だけでは設備が分からないので、配置図と出店内容を出してもらいます。消防への届出が必要かは、この課では断定せず、係長から関係部署へ確認します。

**後任者**：添付書類は毎回同じですか。

**前任者**：通常利用なら位置図だけです。参加者が100人を超える予定なら会場配置図と安全管理計画も確認しています。ただし、この「100人」の基準が要綱にあるのか課内運用なのか、私は確認できていません。

**後任者**：審査にどのくらいかかると案内すればよいでしょうか。

**前任者**：書類がそろってから原則7開庁日を目安と案内しています。ただ、特別な設備がある場合や関係部署への照会が必要な場合は延びることがあります。「必ず7日で出ます」とは言わないでください。

**後任者**：同じ日時に申請が重なったら、先に届いた方が優先ですか。

**前任者**：そこが注意で、初回到達順ではなく、必要書類が全部そろって正式受付になった順として扱ってきました。でも、明文化した資料を見たことがないので、競合したら係長に確認してください。

**後任者**：使用料は受付時に計算しますか。

**前任者**：概算は計算します。料金表の区分、利用時間、占用面積を入力すると台帳に概算額が出ます。ただし、減免申請が付いている案件は金額を確定させず、減免の決裁と一緒に回します。

**後任者**：決裁には何を付けますか。

**前任者**：申請書、位置図、必要な追加資料、審査チェック票、使用料の計算票です。電子申請は一式を案件フォルダーに保存して、文書管理システム「DocFlow」の起案にリンクを付けます。

**後任者**：ファイル名に決まりはありますか。

**前任者**：`受付番号_書類名_受領日` です。例えば `P26-0142_位置図_20260803.pdf`。差し替えが来たら末尾に `_差替1`、次は `_差替2` と付けています。

**後任者**：許可になった後は何をしますか。

**前任者**：決裁日を台帳に入れて、施設予約システムを「仮押さえ」から「確定」にします。それから許可書を送付します。メール送付なら送信記録を案件フォルダーへ保存します。紙で渡したときは受領日を台帳に入れます。

**後任者**：不許可の場合も同じですか。

**前任者**：不許可は担当者の判断で通知しません。理由の書き方も含めて課長決裁です。過去文書のコピーだけで作らず、今回の根拠を確認してください。

**後任者**：申請者からキャンセルの電話が来た場合は、予約を消せばよいですか。

**前任者**：先に取消しの意思と対象案件を確認し、できれば書面かメールをもらいます。すぐ削除すると履歴が残らないので、システムは「取消」に変更します。使用料を納付済みの場合の還付は別手続です。担当だけで案内せず会計担当へつないでください。

**後任者**：年度末に台帳を閉じる作業はありますか。

**前任者**：ありますが、それは別の「年度更新メモ」にしか書いていません。今回の受付手順には入れてもよいと思いますが、保管年限も含めて文書管理担当に確認してください。

**後任者**：最初にやることをもう一度確認すると、受付印、台帳採番、書類確認、システム仮押さえ、という順ですか。

**前任者**：だいたいそうです。ただし電子申請は受付印不要ですし、不足があれば正式受付日をまだ入れません。最後に審査チェック票を必ず使ってください。口頭だけで確認を終えないことが大事です。
```

## 補足情報

### 使用する資料・システム

| 名称 | 用途 | 備考 |
|---|---|---|
| 公園使用申請受付台帳（Excel） | 受付番号、進捗、対応履歴、概算使用料の管理 | 年度ごとにファイルを分ける。 |
| 施設予約システム | 予約状況の確認、仮押さえ、確定、取消 | 決裁前は「確定」にしない。 |
| DocFlow（架空） | 許可・不許可の電子決裁 | 案件フォルダーへのリンクを付ける。 |
| 公園別利用条件一覧 | 公園ごとの禁止事項・設備条件の確認 | 最新版の保管場所は要確認。 |
| 審査チェック票 | 必須項目と添付書類の確認 | 様式番号は要確認。 |
| 使用料計算票 | 使用料の概算・確定 | 減免案件は別途決裁。 |

### 関係者と判断区分

- 通常案件の受付・形式確認：担当職員
- 火気、車両、販売、騒音、競合案件：係長へ相談
- 許可：課内決裁後に確定
- 不許可：課長決裁
- 納付済み使用料の還付：会計担当へ引継ぎ

### 期限・保管

- 標準処理期間の案内：必要書類がそろってから原則7開庁日を目安とするが、保証はしない。
- 案件フォルダー：年度別共有フォルダー内に受付番号で作成する。
- 保管年限：会話ログからは確認できない。
