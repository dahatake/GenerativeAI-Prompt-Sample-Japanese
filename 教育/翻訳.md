# ツール

インターネット上に公開されている文章を扱いたいので、Bing Chat がよいでしょう😊

# Prompt

まずは文章を探す
```text
著作権が切れた日本の小説の冒頭を500文字程度表示してください
作品名、著者名、出典URLも付けてください。著作権が切れていることを確認できない場合は、候補から外してください。
```

英語に翻訳
```text
『こころ』夏目漱石　の冒頭300文字程度を探して、その文章を英語に翻訳してください。
出典を明記し、高校生が読んでも理解しやすい自然な英語にしてください。
```

単語などの意味を尋ねる
```text
reverse とはどんな意味ですか?
```
