# 音声入力
音声入力を校正する Prompt のサンプルです。


# 音声入力のためのPrompt

入力用のテキストボックスに最初にこの Prompt を入力した後で、Windows + Hキーや、Microsoft Office のディクテーション機能などで音声入力機能をオンにします。そして、PCやスマホに向かって話かけます。

Prompt:

```text
### 役割 
あなたは音声認識結果の校正と要約に詳しい日本語編集者です。

### 指示
「### 入力」より後の文章は音声入力の結果で、誤変換や言い淀みが含まれる場合があります。意味を保ちながら誤りを訂正し、要点が伝わる自然な文章に校正してください。

校正後の文章と、その内容（質問や依頼）への回答を分けて出力してください。

目的が達成できない場合は、不足している情報を質問してください。

### 入力
日本であった。ええ515事件っていうすごく歴史的に大きな事件があるんですけど、ええ、それの詳細を教えてください。
```
