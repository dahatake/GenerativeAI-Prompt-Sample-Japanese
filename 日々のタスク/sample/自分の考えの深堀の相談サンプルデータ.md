# 自分の考えの深堀の相談 サンプルデータ

## 1. 対話型 Prompt 用

### 最初に貼る入力

```text
やりたいことは、医療機器卸向けに「営業案件メモ・会議録・在庫データ」をまとめて扱える生成AIアシスタントを社内で事業化することです。

現時点の背景:
- 私は東央ソリューションズ株式会社の営業兼事業開発担当です
- 既存の売上はSI案件中心で、AI関連売上は全社の8%しかありません
- 北辰メディカル流通株式会社とのPoCが通れば、初年度売上7,200万円、2年目以降保守含め年1.1億円を見込んでいます
- ただし、営業部は「受注優先」で短期案件に寄りがちで、プロダクト化への投資判断が揺れています
- プロダクト開発部は3名しかおらず、他案件と競合しています

見込む効果:
- 既存案件の議事録作成時間を月180時間削減
- 提案書流用率を25%から55%へ改善
- 営業案件レビューの準備時間を1案件あたり90分削減
- 在庫欠品に関する顧客からの緊急問い合わせを15%削減できる可能性

関係者とビジョン共有の状況:
- 直属上司とは共有済みで「面白いが、営業が売り切れるか不安」と言われています
- CTOとは未共有です
- カスタマーサクセス部は興味を示していますが、運用負荷の見積もりがありません

意思決定権:
- 私に最終決裁権はありません
- 新規プロダクト投資の決裁者は執行役員(事業担当)の神谷さんです
- セキュリティ要件の承認はCISO室長の加納さんが持っています

悩み:
- これは本当に「私がやるべき仕事」なのか、自分の営業KPIから外れてしまうのではないか迷っています
- PoCを取ってから考えるべきか、先に社内合意を固めるべきか判断できていません
- 顧客価値と社内都合のどちらを優先して整理するべきかも曖昧です
```

### 追加で返答するときの材料

```text
- 予算上限の仮説: 初年度の社内投資は2,500万円までなら役員会に上げやすい
- 成功の最低条件: 3社でPoC、うち1社で有償化、粗利率35%以上
- 自分が苦手なこと: 開発ロードマップを引くこと、法務・セキュリティの論点整理
- 自分が得意なこと: 顧客課題の聞き出し、役員向けストーリーづくり、社内巻き込み
- 未確認事項: 実装方式(SaaS/専有環境)、サポート体制、海外リージョン不使用の担保方法
```

## 2. 5 Why Prompt 用

### 最初の一言

```text
私は、営業案件の情報整理をAIで自動化する社内プロダクトをどうしても立ち上げたいです。
```

### 途中で順番に貼れる想定回答

```text
1回目の回答:
毎週の案件会議に向けて、営業がメール・チャット・議事録を人力で読み直しており、準備に時間がかかりすぎているからです。

2回目の回答:
準備時間が長いせいで、顧客と向き合う時間より社内調整の時間が増え、提案の質も担当者ごとにばらついているからです。

3回目の回答:
提案の質がばらつくと、顧客ごとの重要論点やリスクが埋もれ、意思決定者に刺さる提案ができず失注率が上がると感じているからです。

4回目の回答:
私は大型案件で「あと一歩で決まらなかった」経験が3件続き、その原因の一つが情報整理不足だと考えているからです。

5回目の回答:
結局、自分は単なる営業成績だけでなく、再現性のある勝ちパターンを会社に残したいと思っているからです。

止める時の一言:
ここで止めます。ここまでの議論を整理してください。
```
