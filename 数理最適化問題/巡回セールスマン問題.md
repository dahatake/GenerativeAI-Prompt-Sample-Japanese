# 巡回セールスマン問題

複数のポイントを最短距離で巡回する、という問題です。セールスマンと名称がついていますが、経路最適化問題として広く知られています。

# Prompt

```text
### 問題
次の5点をちょうど1度ずつ訪問する順回路のうち最短距離のものとその距離を考えてください。

(1,0), (2,2), (2,1), (0,0), (2,0)

### 進め方
距離計算の前提、候補ルートの比較、最短ルート、総距離を示してください。
同じ距離の候補が複数ある場合は、その扱いを明記してください。
```
