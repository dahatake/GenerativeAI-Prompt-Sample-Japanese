## 10. 「クレーム対応・理不尽対応」用サンプル

### Step 1 の DATA

```text
- 相手（顧客/患者/住民/取引先/他部署）：顧客 {A社} 情報システム課 課長
- 何が起きた（時系列で簡単に）：9/1 18:40 に障害通知メール誤送信 → 19:05 に顧客から電話 → 19:20 に担当が一次謝罪 → 9/2 朝に「役員にも誤送信された」と追加連絡
- 相手の主張・感情（怒り/不安/不信など）：個人宛の文面が他部署に届き、情報管理に不信感。怒りと不安が強い
- こちらの現状（分かっている事実/未確認/制約）：誤送信対象は18件まで確認、役員到達有無は未確認。原因は宛先CSVの列ずれ疑い。個人名は伏字対応が必要
- 相手の要求（追加要求含む）：原因説明、再発防止策、正式なお詫び文、今後の通知停止可否
- こちらが提供可能なこと（返金/再対応/説明会/交換など。なければ「未定」）：正式文書、電話説明、通知設定の一時停止、再発防止策の後日共有
- 期限（いつまでに何を）：本日17:00までに一次報告、3営業日以内に正式文書
- NG（言えないこと/やれないこと）：原因未確定の断定、補償確約、他顧客情報の開示
- 社内規程・テンプレ（要点だけ。なければ空欄）：重大インシデントは法務と情報セキュリティ責任者レビュー必須
```

### Step 2 で返す追記例

```text
- 前ターン質問への回答：役員宛到達は2件確認済み。暴言や脅迫は無し
- 事実の訂正：誤送信件数は18件ではなく19件
- 新しい制約/NG/期限：本日15:30に部長レビュー。顧客への再電話は16:00以降のみ可
- 追加の参考（要点だけ。全文貼付は不要）：過去6か月で同様事故は初。CSV出力担当は委託先
- モード（1/2/3）＝1
```

## 13. 「社会やビジネスについての調査」用サンプル

```text
調査テーマ:
- 日本、ドイツ、アメリカの会社員が、会議・資料作成・メール対応・分析作業に使う時間の比較

見たい切り口:
- 直近5年推移
- 製造業と情報サービス業の差
- 出典は政府・大学・業界団体を優先

研修用の架空出典:
- 青葉労働政策研究所「2026年 日独米ホワイトカラー業務時間調査」
  - URL: https://research.aoba.example/reports/2026-office-work-time
- 国際業務生産性機構「Cross-country Digital Work Survey 2026」
  - URL: https://idwp.example/publications/digital-work-survey-2026
- 未来製造業協会「間接業務の生産性白書 2026」
  - URL: https://fmia.example/whitepapers/indirect-work-2026

選択したページの本文（研修用の架空ページ）:
タイトル: 2026年 日独米ホワイトカラー業務時間調査
発行者: 青葉労働政策研究所
公開日: 2026年8月18日
調査期間: 2026年4月1日〜5月31日
調査対象: 従業員300人以上の製造業・情報サービス業で働く正社員
有効回答: 2,400人（日本、ドイツ、米国 各800人。各国で製造業400人、情報サービス業400人）
調査方法: 10営業日の業務日誌とオンライン質問票を併用。数値は1人1日当たりの平均。

主要結果:
- 会議時間は日本96分、ドイツ71分、米国84分。
- メール・チャット対応は日本78分、ドイツ54分、米国69分。
- 資料作成は日本64分、ドイツ51分、米国58分。
- 分析・判断業務は日本49分、ドイツ67分、米国73分。
- 日本の製造業では会議と社内申請を合わせて132分、情報サービス業では104分。
- 2022年の同種調査と比べ、日本の会議時間は8分減ったが、メール・チャット対応は11分増えた。

留意事項:
- 自己申告を含むため、実測値とは差があり得る。
- 管理職比率は国ごとに異なり、単純な国別比較には限界がある。
- 「社内申請」は各社の制度差が大きいため、参考値として扱う。
```
