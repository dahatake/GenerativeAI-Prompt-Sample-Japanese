# データ分析に必要なデータソースや項目の洗い出し サンプルデータ

## 役割・背景

- あなたの立場: 旭嶺自動車株式会社 国内商品企画部の製品担当
- 相談先の想定: データ分析支援AI
- 決めたいこと: コンパクトEV「Aster Mini」の2027年モデルの仕様改善と販売計画
- 分析で知りたいこと:  
  1. 販売動向はどの顧客層・地域で伸びているか  
  2. 値引き・補助金・納期が成約率にどれだけ効いているか  
  3. 試乗〜見積〜成約のどこで離脱しているか  
  4. 競合車に流れている要因は何か

## ステークホルダー

| 部門 | 期待する判断 |
|---|---|
| 商品企画部 | 次期モデルの装備・価格帯の見直し |
| 国内営業本部 | 地域別の販促投資配分 |
| 生産管理部 | 納期短縮の優先対象車種 |
| 販売金融部 | 残価設定ローン施策の見直し |
| 経営会議 | 2027年度の販売・利益計画 |

## 仮説

1. 若年ファミリー層では補助金より「納期の短さ」が成約率に効いている。  
2. 都市部では試乗予約率は高いが、駐車場事情で離脱している。  
3. 地方では充電設備不足より販売店説明品質のばらつきの影響が大きい。  
4. 値引き額の増加が利益率悪化を招いているが、必ずしも成約率改善に結びついていない。

## 参考になる現場メモ

- 関東の大型店は「住宅の充電設備相談」が商談メモに多い。
- 九州は自治体補助金の更新タイミングが月中で変わることがある。
- 競合車種は `Eagle-e`, `Lumo Compact`, `Kaze Lite EV` が多いが、CRMでは `Lumocompact`, `KAZE-lite` の表記ゆれがある。
- 商談担当者が退職すると、失注理由欄が空欄の案件が増える。
- 納期遅延理由は `半導体`, `輸送`, `仕様変更`, `部品待ち`, `部品待` が混在。

## 求める出力の形

- 「分析に必要なデータ項目」をカテゴリ別の表で列挙する
- 各項目について、想定データソース、主キー候補、更新頻度、欠損リスク、個人情報区分も付けたい
- 追加で「今すぐ取得可能」「他部門調整が必要」「新規収集が必要」に分類したい

## 制約・未解決事項

- 氏名、電話番号、住所、VINは分析基盤に直接持ち込めない。匿名化前提。
- 自治体補助金の粒度が自治体ごとに異なり、比較しにくい。
- 商談IDとWebログの visitor_id は直接結合できず、予約フォームID経由になる見込み。
- 試乗実績は紙台帳入力の販売店が一部残っている。
