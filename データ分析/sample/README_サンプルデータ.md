# README サンプルデータ

## 分析の背景

- 依頼部門: 北辰デリバリー株式会社 事業企画部
- ステークホルダー: 事業本部長、マーケティング責任者、物流責任者、CS責任者、データ分析担当
- 意思決定目的: 2026年上期に「解約率が上がっているか」「広告費増加が利益改善につながっているか」「どの地域・顧客セグメントの改善優先度が高いか」を判断する
- 対象期間: 2025-10〜2026-09（月次）
- 主なKPI: 売上高、粗利率、解約率、新規顧客数、リピート率、苦情件数、広告費回収率、配送遅延率
- 必要な出力形:  
  1. 記述的分析  
  2. 解約率上昇要因の仮説  
  3. 次四半期の重点施策候補  
  4. グラフ付きの経営説明用サマリー

## 品質・論点メモ

- 2026-04-01 関西/単身若年層が完全重複しているため、重複排除ロジック確認が必要。
- `campaign_code` に `SPRING26` と `Spring-26` の表記ゆれあり。
- 2026-08 首都圏の `gross_margin_pct` はERP更新遅延で欠損。
- 2026-09 関西の `complaints` はCS集計未完了。
- 2026-07 北海道の法人まとめ買いは単発案件で、通常消費者分析から除外するか別管理するか要判断。
- 2026-01〜03 関西は配送委託先変更とアプリ障害が重なり、解約率悪化要因が混在。
- 顧客レベルの個票は別系統で保管。ここでは `analyst_contact_masked` のみダミー値として残している。

## 補足の運用メモ

| 項目 | 内容 | 信頼度 |
|---|---|---|
| 売上高 | DWH月次確定値 | 高 |
| 広告費 | 広告運用管理表 | 中 |
| 苦情件数 | CS手入力集計 | 中 |
| 配送遅延率 | 物流ベンダー週報の月次集約 | 中 |
| 粗利率 | ERP月次締め値 | 高（欠損月あり） |

## 制約・前提

- 北海道法人案件は外れ値として注記しつつ、除外・含有の両面で見たい。
- 解約率は当月末ベースで、翌月初の取消は反映されていない。
- 地域再編により 2026-05 から首都圏拠点コードが `TK-01` から `TK-02` に変わる。
- 出力では「増えているかどうか」を時系列で示すこと。
