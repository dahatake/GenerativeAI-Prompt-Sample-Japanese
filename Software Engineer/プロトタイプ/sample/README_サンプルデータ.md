# 共通シナリオ
- アプリ名: `こおりやま旅メイト`
- 目的: 郡山観光者向けに、食事・景色・移動・支払い・予約を1つのWebアプリで支援する
- 対象ユーザー:
  - 首都圏から1泊2日で来る個人旅行者
  - レンタカーなしの鉄道移動者
  - 30〜50代スマホ中心ユーザー
- 主要ステークホルダー:
  - 郡山観光協会
  - 市内飲食店 15店舗
  - 交通事業者 2社
  - プロダクト責任者: 架空の山岸 由香
- 技術方針:
  - Web: Vue.js 3 / Vite / TypeScript 5.6
  - API: Azure Functions v4
  - DB 候補: Azure SQL Database または Azure Cosmos DB for NoSQL
  - 非本番のみで試作。本番資格情報は扱わない
- 非機能:
  - p95 1.5秒以下
  - 休日ピーク同時利用 300人
  - 可用性 99.5%
  - 日本語のみ、将来多言語拡張余地あり
- セキュリティ:
  - 氏名、メール、予約番号を保持するため暗号化・最小権限
  - 決済は外部事業者へ委譲しカード情報は保持しない
