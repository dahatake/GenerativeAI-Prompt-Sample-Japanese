## 1. 初期プロンプトに追加する業務前提
```text
# 利用DB
- Microsoft SQL Server 2022
- 文字コード: UTF-8

# 表構造
create table sales (
customer varchar(20),
sales_date date,
sales_qty int
)

# 別名
- Sales: 日次売上実績
- customer: 顧客名
- sales_date: 売上日
- sales_qty: 販売数量

# サンプルレコード
- ('東北マート', '2026-08-01', 120)
- ('東北マート', '2026-08-02', 95)
- ('関東ドラッグ', '2026-08-01', 42)
- ('みなみストア', '2026-08-03', 188)
- ('東北マート', '2026-09-01', 131)

# 業務ルール
- 返品は別テーブル管理のため sales には含まれない
- 数量は日次の確定値
- 回答は SQL 文のみ欲しい
```
