## 1. 初期プロンプトに追加する業務前提
```text
# 利用DB
- Microsoft SQL Server 2022
- 日本語の顧客名を扱うため、customer は nvarchar(Unicode)

# 表構造
create table sales (
customer nvarchar(20),
sales_date date,
sales_qty int
)

# 別名
- Sales: 日次売上実績
- customer: 顧客名
- sales_date: 売上日
- sales_qty: 販売数量

# サンプルレコード
- ('東北マート', '2026-08-01', 120)
- ('東北マート', '2026-08-02', 95)
- ('関東ドラッグ', '2026-08-01', 42)
- ('みなみストア', '2026-08-03', 188)
- ('東北マート', '2026-09-01', 131)

# 業務ルール
- 返品は別テーブル管理のため sales には含まれない
- 数量は日次の確定値
- 回答は SQL 文のみ欲しい
```

## 2. 質問例: 月次集計
```text
Q: 2026年8月の顧客ごとの販売数量合計を教えて
```

## 3. 質問例: 上位顧客
```text
Q: 2026年8月に販売数量が最も多かった顧客を上位3件で教えて
```

## 4. 質問例: 期間比較
```text
Q: 東北マートの2026年8月と2026年9月の販売数量合計を月別に比較したい
```

## 実ファイル（フルボリューム版）

本文のサンプルレコード5件では集計・上位N件・期間比較の結果が検証できないため、[sales_sample.sql](./sales_sample.sql) を用意しています。8顧客 × 2026年7〜9月（649行）の `sales` テーブルを作成するT-SQLで、本文の5件はそのまま含まれます（`東北マート` の8月合計などを手計算で確認できます）。

### 検証用の期待値（sales_sample.sql 投入後）
- Q2「2026年8月の顧客ごとの販売数量合計」: みなみストア 5,095 / 関西スーパー 4,002 / 中部ホームセンター 2,935 / 東北マート 2,859 / 瀬戸内マート 2,330 / 北陸ストア 1,939 / 九州ドラッグ 1,772 / 関東ドラッグ 1,367（8月全体 22,299）
- Q3「8月の上位3件」: みなみストア 5,095、関西スーパー 4,002、中部ホームセンター 2,935
- Q4「東北マート 8月 vs 9月」: 8月 2,859、9月 2,815
- 全期間の合計: 65,186

注: 本文の `customer` は日本語を扱うため nvarchar(20) にしています(元Promptの varchar(10) だと、日本語の顧客名は環境の照合順序によって文字化けや切り捨てが起こり得ます)。
