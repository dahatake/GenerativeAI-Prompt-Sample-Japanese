## 1. Prompt に追加する前提条件
```text
# 研修の目的
社内ワークショップ「Prompt Craft Lab」で、GitHub Copilot を使った Web アプリ生成とバグ修正の流れを90分で体験させたい。

# 受講者
- 対象: 新任アプリ開発者 18名
- 前提スキル: HTML/CSS/JavaScript の基礎は理解、Vue/React は未経験者が半数
- 使用端末: Windows 11 / macOS Sonoma 混在

# 作成対象アプリ
- テーマ: 展示会ブースの案内文を生成・分析する「Prompt Art Sample」
- 画面:
  - Builder画面: 入力テキスト、用途選択、トーン選択、プレビューCanvas、保存ボタン
  - Analyzer画面: 保存済みデータ一覧、統計カード、エラー表示領域、再分析ボタン
- 共通ロジック: `app.js` のみ

# 技術・実行条件
- HTML5 / Vanilla JavaScript / LocalStorage
- Node.js 20 系で `npx serve .` できれば十分
- 外部API呼び出しは禁止
- アクセシビリティ: キーボード操作、ラベル関連付け、エラー文言の aria-live 対応必須

# 意図的バグの補足
- Storage キー不一致により Analyzer に一覧が表示されない
- ボタン ID 不一致により 再分析ボタンが反応しない
- 追加で、Analyzer がデータ0件の時に `Cannot read properties of undefined` を出しやすい

# 必要な成果物
- サンプルHTML/JSコード
- バッチ型 Prompt 集
- インタラクティブ型 Prompt 集
- Mermaid による構造図
- 不完全入力時のエラー出力例
- 初学者向けの説明文

# 研修運営上の制約
- 研修責任者の承認なく npm パッケージ追加しない
- 個人情報を入力させない
- 受講者がコピペで再現できること
```
