## 1. スクリーンショットの代わりに渡す画面仕様データ
```text
# 画面名
在庫調整申請システム Top 画面

# 利用目的
倉庫担当者が在庫差異を確認し、調整申請を登録・検索・承認依頼する

# 画面サイズ想定
- 標準: 1440 x 900
- 最小サポート: 1280 x 720

# 画面レイアウト
- ヘッダー:
  - 左上ロゴ: `StockPilot`
  - 右上: ログインユーザー `仙台第2倉庫 / 佐藤 真由`
  - 通知ベル: 未読2件
- 左ナビ:
  - `Top`(選択中)
  - `調整申請一覧`
  - `差異レポート`
  - `承認待ち`
  - `設定`
- メイン領域上部:
  - パンくず: `ホーム > Top`
  - 見出し: `在庫調整申請`
  - 説明文: `差異が確認された在庫を申請してください`

# 入力項目
1. 倉庫
   - 種別: プルダウン
   - 初期値: `仙台第2倉庫`
   - 選択肢: `仙台第2倉庫 / 郡山センター / 宇都宮DC`
   - 必須
2. 商品コード
   - 種別: テキストボックス
   - プレースホルダー: `例: SKU-45820`
   - 半角英数字とハイフンのみ
3. 差異区分
   - 種別: ラジオボタン
   - 選択肢: `棚卸差異 / 破損 / 期限切れ / 仕入先返品`
   - 初期値なし
4. 差異数量
   - 種別: 数値入力
   - 最小値: 1
   - 最大値: 9999
5. 調整理由
   - 種別: 複数行テキスト
   - 文字数上限: 400
   - 50文字未満なら警告表示
6. 添付写真
   - 種別: ファイルアップロード
   - 許可形式: jpg/png
   - 最大10MB

# ボタン
- `下書き保存` : 入力途中でも押下可
- `承認依頼` : 必須項目が揃うと活性化
- `入力内容をクリア` : 押下時に確認モーダル表示

# テーブル(画面下部)
- 見出し: `本日の差異速報`
- 列: `受付時刻 / 商品コード / 商品名 / 差異数量 / 状態 / 担当者`
- 初期表示件数: 5件
- 行サンプル:
  - `09:12 / SKU-45820 / 防水ヘッドライト / 3 / 承認待ち / 佐藤`
  - `10:48 / SKU-77501 / 非常食セット / 1 / 下書き / 高橋`

# 状態・メッセージ
- 初期表示時にインフォバー: `本日の未承認件数は 4 件です`
- 商品コードが未入力で `承認依頼` を押すと、項目下に赤字 `商品コードを入力してください`
- `差異数量` に 0 を入れると `1以上を入力してください`
- ファイル形式不正時はトースト `アップロードできるのは JPG / PNG のみです`

# アクセシビリティ
- タブ順は左ナビ → 倉庫 → 商品コード → 差異区分 → 差異数量 → 調整理由 → 添付写真 → ボタン
- 必須項目には `aria-required=true`
- エラー領域は `aria-live=polite`
- 色だけに依存せず、エラーアイコンと文言を併記

# 利用権限
- 倉庫担当者: 登録・下書き保存まで可
- リーダー権限: 承認依頼可
- 管理者: すべて可
```
