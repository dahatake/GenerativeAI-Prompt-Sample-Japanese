# requirements_v0_9(MallConcierge 要求定義 抜粋・架空)

研修用の架空文書です。RFI撲滅委員会_サンプルデータ.md の「添付あり版」で添付するファイルの内容です(元は .docx 想定)。

## 1. 目的
ECサイトと LINE 公式アカウントの2チャネルで、約85万件の商品情報から、利用者の相談内容に合う商品候補と要約を返す。

## 2. 利用者
| 利用者 | 規模の目安 | 主な利用 |
| --- | --- | --- |
| EC利用者 | 月間 約 38,000 セッション(想定) | 商品相談、ギフト相談 |
| LINE利用者 | 月間 約 9,000 トーク(想定) | 配送条件確認、返品可否照会 |
| 運用担当 | 3名 | 回答品質の確認、ナレッジ更新、利用分析 |

## 3. ユースケースと目標
| ID | ユースケース | 目標 |
| --- | --- | --- |
| UC-01 | 商品相談 | 3ターン以内で解決率 60% 以上 |
| UC-02 | ギフト相談(予算・相手・用途から候補提示) | 候補提示までの平均 2 ターン以内 |
| UC-03 | 配送条件確認 | FAQ に基づく回答、根拠 FAQ タイトルの表示 |
| UC-04 | 返品可否照会 | 返品規定に基づく回答、判断できないときは有人窓口へ誘導 |

## 4. 機能要件(抜粋)
- FR-01: 曖昧な相談文から意図を推定し、必要なら確認の質問を返す
- FR-02: 商品マスタ、レビュー、FAQ を横断検索して回答を生成する
- FR-03: 回答に根拠(商品URL、FAQタイトル)を付ける
- FR-04: 管理者向けに利用件数、応答速度、不適切入力件数、根拠表示率を表示する
- FR-05: 在庫情報を回答に反映する(要件: 10分以内の遅延)

## 5. 非機能要件(抜粋)
- 応答速度 p95 4秒以内 / 月間可用性 99.5% 以上 / 日本国内リージョン / 監査ログ365日保持 / PII マスキング率 100%
