# security_policy_excerpt(架空・抜粋)

研修用の架空文書です。RFI撲滅委員会_サンプルデータ.md の「添付あり版」で添付するファイルの内容です(元は .pdf 想定)。

1. 顧客データは日本国内リージョンに保管する。
2. 生成AIへ投入する前に、氏名・電話番号・住所をマスキングする。マスキングできないデータは投入しない。
3. プロンプトと回答の監査ログを 365 日保持する。ログ内の個人情報は、保存前にマスキングする。
4. 外部サービスへ接続するシークレットは、シークレット管理サービスに保管し、ソースコードに置かない。
5. 利用者向けの回答には、根拠を確認できる情報(商品URL、FAQタイトル)を含める。
6. 重大インシデント(個人情報の漏えいの疑い)は、検知から 1 時間以内に情報セキュリティ責任者へ報告する。
