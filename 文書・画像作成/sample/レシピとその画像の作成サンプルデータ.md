# レシピとその画像の作成 サンプルデータ

## 共通条件
- 想定する食卓: 平日夜の家庭料理
- 人数: 大人2人 + 小学生1人
- 制約:
  - 1人が軽い減塩中
  - ピーナッツ禁止
  - 子どもは強い辛味が苦手
  - 翌日のお弁当に一部取り分けたい
- 使える調理器具:
  - IHコンロ2口
  - 電子レンジ
  - オーブントースター
  - 26cmフライパン
  - 18cm片手鍋

## 1. 食材からレシピを作る 用

```text
### 役割
家庭料理と和食の調理設計に詳しい料理人として回答してください。

### 指示
以下の食材を使って、家庭で再現しやすいレシピを作成してください。味付け、食感、調理時間、主菜・副菜の組み合わせが分かるようにしてください。

### 食材
鶏むね肉 320g
鶏ひき肉 180g
木綿豆腐 150g
卵 4個
しめじ 120g
エリンギ 100g
キャベツ 1/4玉(約300g)
かぼちゃ 300g
なす 4本
トマト缶 1缶(400g)
しょうが 20g
白だし 40ml
味噌 30g
醤油 15ml
みりん 20ml
片栗粉 15g
オリーブオイル 15ml

### 追加条件
- 35分以内で完成
- 主菜1品、副菜1品、汁物1品の構成
- 翌日のお弁当に主菜を1人分残せる量
```

## 2. レシピを教えてください 用

```text
### 指示
レシピを教えてください。

### 出力してほしい形式
1. 料理名
2. 何人前か
3. 材料一覧(グラム・mlつき)
4. 下ごしらえ
5. 調理手順
6. 失敗しやすいポイント
7. 減塩対応の工夫
```

## 3. どの様に調理しますか 用

```text
### 指示
どの様に調理しますか?

### 追加条件
- 18:30調理開始、19:05配膳希望
- 洗い物を増やしたくない
- フライパンと鍋を同時進行で使いたい
- 子ども向けだけ、なすの皮の苦味を少し抑えたい
```

## 4. 調理と器の回答を英語にしてください 用

```text
### 指示
調理と器の回答を英語にしてください。

### 器・盛り付け条件
- 主菜: 紺色の楕円皿
- 副菜: 白い小鉢
- 汁物: 木目のお椀
- 写真映えするよう、かぼちゃの黄色とトマトの赤を見せたい
```

## 5. その回答を英語に翻訳してください 用

```text
### 指示
その回答を英語に翻訳してください。

### 翻訳トーン
- 海外の料理ブログに載せられる自然な英語
- 分量と手順は省略しない
- 盛り付けと器の説明も含める
```
